忘了签证到期日，或者延期材料没准备好就过了期限，这种情况并不少见。大家最先关心的往往是"要罚多少钱"和"还能不能继续留在韩国"。这篇文章按条文顺序整理超期居留的罚款标准和后续流程。

## 核心要点

- 外国人只能在居留资格和居留期限范围内停留（第17条第1款）；想继续停留，必须在**居留期限届满前**取得延期许可（第25条第1款）。
- 未经延期许可超期继续停留，可处3年以下徒刑或3000万韩元以下罚金（截至2026年10月，第94条第17项）。
- 实务上，多数情况下经调查后会通告缴纳相当于罚金的**罚款**，基准额按超期时间从50万韩元到3000万韩元不等（截至2026年10月，施行规则附表7）。
- 缴纳罚款之后，强制驱逐、出境命令以及日后的居留审查仍需另行留意。

## 1. 居留期限届满后适用哪些条文？

关键是两条。第25条第1款规定，想超过居留期限继续停留，须在**期限届满前**取得法务部长官的延期许可；施行令第31条第1款同样要求在居留期限届满前提出延期申请。违反此义务、未经延期许可超期继续停留的人，依第94条第17项可处3年以下徒刑或3000万韩元以下罚金（截至2026年10月）。

期限一旦过去，就不再是"延期"，而是已经处于违法状态，之后补交材料也不会抹去违法事实。所以发现过期后，建议尽快向管辖的出入境·外国人机关确认情况。

## 2. 罚款是多少？

出入境事犯案件经调查确认犯罪事实后，出入境·外国人机关负责人可以书面通告缴纳相当于罚金的金额，即罚款（第102条第1款）。罚款基准额由施行规则[附表7]按超期时间规定（截至2026年10月）。

| 超期时间 | 罚款基准额 |
|---|---|
| 不满1个月 | 50万韩元 |
| 1个月以上不满3个月 | 100万韩元 |
| 3个月以上不满6个月 | 200万韩元 |
| 6个月以上不满1年 | 500万韩元 |
| 1年以上不满2年 | 1000万韩元 |
| 2年以上不满3年 | 1500万韩元 |
| 3年以上不满5年 | 2000万韩元 |
| 5年以上不满7年 | 2500万韩元 |
| 7年以上 | 3000万韩元 |

以上是**基准额**。机关负责人可综合年龄与环境、违法动机与结果、罚款承受能力、违法次数等，在基准额的二分之一范围内减轻或加重（施行规则第86条第2款）；法务部长官也可以考虑同样情况免除通告处分本身（第103条第2款）。因此，从到期日次日起算到实际出境或获得许可之日的期间，要准确整理。

## 3. 收到通告书之后会怎样？

自收到通告书之日起15天内须缴纳罚款（第105条第1款）。逾期未缴，机关负责人应当告发；在告发前缴纳则不告发（同条第2款）。按通告缴纳后，同一案件不会再被处罚（第106条）。

相反，如果调查认为情节属于禁锢以上刑罚，可能不经通告处分直接告发（第102条第3款）。出入境事犯案件没有出入境·外国人机关负责人的告发，不能提起公诉（第101条第1款）。

## 4. 缴了罚款就结束了吗？

不是。刑事层面的罚款与居留相关的行政程序是分开进行的。

- **强制驱逐事由**：违反第25条属于第46条第1款第8项规定的强制驱逐对象事由。永久居留资格者原则上不被强制驱逐，但有例外（第46条第2款）。
- **出境命令**：即使可能符合第46条第1款各项，对愿意自费自愿出境的人也可以作出出境命令（第68条第1款第1项）；通告处分后适合出境措施的情形见同条第5项。自愿出境的利弊另见[外国人自愿出境指南](/zh/blog/foreigner-voluntary-departure-2026)。
- **能否继续居留**：由机关综合超期时间、违法经过、家庭与工作情况后判断，同样的超期时间结果也可能不同。

## 5. 对之后的签证审查有什么影响？

法务部居留指南（2026年9月版）中，有些内容会把罚款记录和非法滞留期间反映到之后的审查里。

- 求职（D-10）限制对象：依出入境管理法被处罚款、且按《居留许可限制统一标准》受限的人。指南例举为初犯500万韩元以上、再犯3年内合计700万韩元以上（截至2026年10月）。
- 其他长期居留（F-2-99）变更：计算居留期间时扣除非法滞留（违反第25条）或非法就业（违反第18条）期间，非法滞留者也在居留资格变更的限制对象之列。

各资格的标准不同，如果以后计划延期、变更或申请永居，建议先整理好罚款金额和日期。

## 6. 发现已经超期时的处理顺序

1. **先确认日期。**记下获批的居留期限届满日以及实际出境（或计划出境）的日期，罚款档位由这段期间决定。
2. **向管辖的出入境·外国人机关咨询情况。**是否有继续居留的理由、是否需要出境，方向会不同。
3. **收到出席要求书或通告书要守住期限。**出席要求书会写明目的、日期和地点（施行令第58条），罚款通告书以收到之日起15天为准。
4. **整理说明材料。**住院、材料延误等延迟原因及证据，以及家庭、工作情况，如实整理会让说明更清楚。与事实不符的内容反而可能不利。

## 7. 可以委托行政士办理哪些事项？

可以委托办理居留相关申请材料的填写与代为提交、撰写说明违规经过的陈述书·意见书，以及整理并翻译证明材料。被告发后的侦查·刑事审判辩护不属于行政士的业务范围，我们不承接。

如果期限已经过去，时间拖得越久，基准额档位可能越高。若已收到通告书或出席要求书，请先核对上面的日期，再一起检查剩余期限和说明材料。
