未在法定期限内办理外国人登记事项变更申报、居留地变更申报、工作单位变更·追加申报等,可能会收到出入境·外国人厅(事务所)发出的**罚款通知书**。若抱着"缴了罚款就没事了"的心态轻视处理,今后在滞留期限延长或资格变更审查时,违法记录可能反过来成为不利因素。

本文以《出入境管理法》及官方罚款基准表为依据,整理了收到通知书后应确认的事项及应对程序。

> **本文所载罚款基准额以内部整理资料(基准日2026-09-22)及国家法令信息中心(law.go.kr)确认的现行规定为依据。** 实际处罚金额与程序可能因管辖出入境机关的运营情况而异,请务必以您本人收到的通知书内容为准优先确认。

## 1. 罚款的性质 — 通告处分制度

罚款(범칙금)是《出入境管理法》中针对较轻微违法行为、由事务所长等以**通告处分**制度(第102条起)通知缴纳一定金额、以代替刑事告发的金额。在期限内缴纳,该违法行为的程序即告终结;逾期未缴,管辖机关可提出告发,案件可能转入刑事性质的出入境违规审查程序。

## 2. 收到通知书后应首先确认的3项内容

1. **依据条文与违法期间** — 通知书记载的条文(如外国人登记事项变更申报、居留地变更申报、工作单位变更·追加申报相关条文等)及违法期间是否与实际情况一致
2. **罚款基准额** — 通知金额是否与相应违法期间区间的官方基准额一致
3. **缴纳期限** — 逾期可能引发告发等后续程序,应最先确认

## 3. 罚款基准额 — 代表性示例

| 违法行为 | 违法期间 | 罚款基准额 |
|---|---|---|
| 外国人登记事项变更申报迟延(护照号码、所属机构等,应在14日内申报) | 不满3个月 | 10万韩元 |
| 同上 | 6个月以上~不满1年 | 50万韩元 |
| 同上 | 1年以上 | 100万韩元 |
| 居留地变更申报迟延(应在14日内申报) | 不满3个月 | 10万韩元 |
| 同上 | 1年以上~不满2年 | 70万韩元 |
| 同上 | 2年以上 | 100万韩元 |
| 工作单位变更·追加申报迟延(专门人才,应在15日内申报) | 1年以上~不满2年 | 100万韩元 |
| 同上 | 2年以上 | 200万韩元 |

以上金额均为官方基准表所载基准额,实际处罚金额可能因个案情况(是否故意、可酌情考虑的事由等)由管辖机关调整。若通知书上的金额与您了解的情况不符,请勿自行推测,应直接向发出通知书的机关咨询确认。

## 4. 有异议时 — 缴纳前的说明最为关键

通告处分旨在迅速终结轻微案件,因此通常不像一般行政处分那样先走行政复议、行政诉讼程序。

- **缴纳的情况**:在期限内缴纳后,该违法行为的程序即告终结。
- **不缴纳的情况**:管辖机关可提出告发,此后可能转入侦查机关、检察机关的刑事程序。

因此,若对违法事实本身存在争议(如申报期间计算方式不同、有正当事由未能遵守期限等),建议在**缴纳之前**先向发出通知书的机关提交说明材料并咨询,这在实务上更为稳妥。若自行判断而错过期限,可能导致被告发。

## 5. 缴纳罚款会影响滞留资格吗

即使在期限内缴纳罚款使案件终结,违法记录本身仍会保留,今后在滞留期限延长、滞留资格变更、各类积分制审查(如熟练技能人才转换积分制中的扣分项目)时可能被参考。若违法次数累积或性质较重,也可能转入**出入境违规审查**(违法者资格审查),并导致取消滞留资格、下达出境命令等更严重的处分。请务必记住,刑事罚款与出入境行政处分是决定主体与程序均不同的两条独立轨道。关于出入境违规审查的完整说明,请参见[出入境违规审查完全指南](/blog/immigration-offense-review-guide)。

## 6. 实际应对顺序

1. 严格按照通知书原文确认依据条文、违法期间及金额。
2. 若对事实无异议,请在缴纳期限内按指定方式缴纳。
3. 若对事实有异议或有正当事由,请在缴纳前先咨询发出机关并准备说明材料。
4. 若担心违法记录会影响今后的滞留资格审查,建议与行政士事务所等专业人士一同核查完整的滞留履历。

可能转入刑事程序的事项属于另行的法律程序领域,而出入境违规审查及滞留资格应对则属于行政士的业务领域。
