在韩国因酒驾被查处的外国人，最先听到的往往是两句话：**"刑事处罚已经结束了"**，以及**"出入境说还要再叫你去一次"**。

后者正是出入境事犯审查。即使刑事程序以罚金刑收场，出入境·外国人厅仍可通过另一套行政程序，决定是否拒绝延长签证、下达出境命令，或作出强制驱逐处分。

本文系统梳理酒驾被查处后，外国人必须了解的事犯审查全流程。

## 1. 酒驾查处 → 刑事处罚 → 事犯审查

### 第一阶段：查处现场
- 测定血液酒精浓度（BAC）→ 拒绝呼气检测将立即加重处罚
- 收到吊扣或吊销驾照的通知

### 第二阶段：刑事处罚
- 移送检察 → 略式命令（罚金）或正式审判
- 依据BAC数值与有无事故确定处罚

### 第三阶段：事犯审查通知
- 刑事处罚结束后由出入境事务所通知
- 可能在签证延长时自动启动，也可能另行要求出席

### 第四阶段：事犯审查结果
- 准予居留 / 资格变更 / 出境命令 / 强制驱逐 / 入境禁止

## 2. 外国人在韩国酒驾会被驱逐出境吗？按血液酒精浓度（BAC）划分的处分预期

被强制驱逐须属于《出入境管理法》第46条各款所列事由之一，实际结果因个案而异。

| BAC 数值 | 刑事处罚（道路交通法） | 出入境事犯审查预期 |
|---|---|---|
| 0.03 ~ 0.08% | 罚金 ~500万韩元，吊扣驾照100日 | 有条件延长签证（必须备齐酌情减轻材料） |
| 0.08 ~ 0.2% | 1~2年有期徒刑或500~1,000万韩元罚金，吊销驾照 | 出境命令可能性高，亦会考虑强制驱逐 |
| 0.2% 以上 | 2~5年有期徒刑，吊销驾照 | 强制驱逐可能性极高 |
| 拒绝检测 | 1~5年有期徒刑或500万~2,000万韩元罚金 | 强制驱逐事实上已成定局 |
| 伴随事故 | 上述处罚 + 加重（特定犯罪加重处罚法等） | 强制驱逐 + 可能永久禁止入境 |

⚠️ 上表仅为一般趋势，实际结果会因酌情减轻材料（家庭、工作、对韩国社会的贡献度）而产生较大差异。

## 3. 出席事犯审查前的准备清单

### 必备文件
- [ ] 刑事处罚结果通知书（略式命令书或判决书）
- [ ] 酒驾查处报告书
- [ ] 外国人登录证、护照复印件
- [ ] 现持签证复印件及资格证明

### 酌情减轻材料（★ 造成决定性差异的材料）
- [ ] **悔过书·情况说明书**（以韩语撰写，须站在出入境视角组织逻辑）
- [ ] **在职证明 + 四大保险参保记录**（证明对韩国的贡献度）
- [ ] **纳税记录**（证明对韩国社会的贡献）
- [ ] **家庭关系证明 + 子女出生证明**（在韩国有家庭）
- [ ] **志愿服务证明**（融入韩国社会）
- [ ] **韩国语能力考试（TOPIK）成绩单**（定居意愿）
- [ ] **事故和解书、被害人不予追究处罚意见书**（发生事故时）
- [ ] **上司或同事的嘆願书**（以韩语撰写）
- [ ] **戒酒意愿证明**（参加酒精治疗项目等）

### 出席事犯审查时的注意事项
- 着正装或整洁得体的服装
- 韩语不便时，可请行政士或翻译陪同（须事先向出入境事务所申请）
- 回答简短明确，不找借口
- 明确表达悔意与防止再犯的决心

## 4. 酌情减轻材料如何改变结果

以下比较VISION行政士事务所经手的两个真实案例。

### 案例A：材料不足 → 强制驱逐
- 30多岁男性，F-5-1 永住权持有者
- BAC 0.12%，无事故
- 刑事罚金500万韩元
- 出席事犯审查时几乎未提交酌情减轻材料
- **结果：强制驱逐 + 5年禁止入境**

### 案例B：材料充分 → 维持资格
- 30多岁男性，F-5-1 永住权持有者
- BAC 0.13%，无事故
- 刑事罚金700万韩元（高于案例A）
- 出席事犯审查时提交：
  - 在韩居住12年，韩国籍配偶，两名子女
  - 韩国企业高管，年薪8,000万韩元
  - 5年志愿服务记录
  - 参加酒精治疗项目
  - 公司代表的嘆願书 + 韩国籍配偶的嘆願书
- **结果：保留永住权 + 出境命令 → 缓和为保护观察处分**

差异不在BAC数值，而在**准备材料的差距**。

## 6. 五个常见误解

**误解1："罚金都缴了，应该没事了。"**
→ 刑事与行政是两回事。事犯审查会重新开始。

**误解2："我是初犯，应该会从轻处理。"**
→ BAC 0.2% 以上或伴随事故时，初犯同样可能被强制驱逐。

**误解3："我和韩国人结婚了，不会被强制驱逐。"**
→ 即使持F-6结婚移民签证，酒驾受罚后仍属事犯审查对象。但有家庭这一事实会成为酌情减轻要素。

**误解4："刑事案件处理完了，就结束了。"**
→ 刑事案件结束后，出入境事犯审查仍是另行进行的行政程序，属于行政士的领域。

**误解5："自己去出席结果也一样。"**
→ 结果的30~50%取决于酌情减轻材料的质量。独自准备的材料与行政士整理的材料，说服力差距明显。
