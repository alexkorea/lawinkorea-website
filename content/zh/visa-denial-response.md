提交签证延长申请后，最令人不安的通知莫过于**"不予延长"**或**"补正命令"**。若未能在通知书载明的出国期限内妥善应对，可能演变为**强制驱逐（强制遣返）等处分**。

本文按步骤梳理被拒后在出国期限内需要确认的事项。

## 1. 签证延长被拒的类型

### A. 补正命令（Supplementary Order）
- "以现有材料无法作出决定，要求补充提交材料"
- 期限以补正通知书记载为准
- 补齐材料后重新审查

### B. 不予延长（Denial）
- 明确的拒绝处分
- 须在通知书载明的出国期限（自发放日起不超过14日，出入境管理法施行令第33条第2款）内出境或采取其他措施

### C. 建议变更资格
- "现有资格不予批准，建议变更为其他资格"
- 需重新提出申请

## 2. 常见的七类拒签理由

### （1）财政能力不足
- 存款余额、收入证明不足
- D-2（留学）：学费 + 生活费证明不足
- F-2-7（居住）：稳定收入证明不足

### （2）活动事实未获认定
- E-7（特定活动）：实际任职事实存疑
- D-8（企业投资）：实际经营活动证明不足

### （3）家庭关系存疑
- F-6（结婚移民）：婚姻真实性存疑
- F-1（访问同居）：家庭关系证明不足

### （4）刑事处罚或事犯审查
- 酒驾、斗殴等刑事案件
- 出入境违规记录

### （5）学业不振（D-2）
- 出勤率未达学校或法务部标准
- 学分不达标
- 反复休学

### （6）被查获资格外活动
- 打工超时
- 脱离工作单位（E-9）

### （7）材料缺漏或不实
- 未提交必备材料
- 被发现伪造文件

## 3. 分步行动计划

### 第1步：准确掌握拒签理由

**必做事项：**
1. 通读拒签通知书（理由、期限、后续措施）
2. 拍照／扫描留存
3. 前往出入境·外国人厅与工作人员面谈（若可行）
4. 通过信息公开申请确认详细理由

**咨询渠道：**
- 外国人综合支援呼叫中心 1345
- 直接前往就近的出入境·外国人厅
- 由行政士陪同面谈

### 第2步：确定应对方案

从以下四项中作出选择：

#### 方案A）提交补充材料
- 若为补正命令，则此为首选
- 在通知书载明的期限内提交准确材料

#### 方案B）申请变更资格
- 放弃被拒资格，改申请其他资格
- 例如：D-2被拒 → 申请D-10（求职活动）

#### 方案C）提出异议（行政审判）
- 认为拒签处分不当时
- 须自知道处分之日起90日内提出（行政审判法第27条第1款）
- 裁决应自收到审判请求书之日起60日内作出，不得已时可延长30日（行政审判法第45条第1款）

#### 方案D）自愿出境
- 上述方案均不可行时
- 在收到出境命令前主动出境
- 日后申请再入境时可作为说明材料（结果依个案而定）

### 第3步：准备材料并提出申请

**提交补充材料的要点：**
- 针对拒签理由逐项准备准确材料
- 不是简单重复提交，而是能消解拒签理由的材料
- 情况说明书（韩语，行政视角）
- 酌情减轻材料

**申请资格变更的要点：**
- 满足新资格的全部要件
- 如实载明此前被拒的事实 + 变更理由

### 第4步：追加补充或面谈

**可能被要求追加材料：**
- 出入境部门可能要求补充材料
- 应在要求的期限内应对

**若可面谈：**
- 亲自前往出入境说明情况
- 建议由行政士陪同

### 第5步：等待最终决定或准备出境

- 等待结果通知
- 若被拒，立即采取后续措施（自愿出境或提出异议）

## 4. 按理由划分的应对策略

### 因刑事处罚被拒

难度最高的情形。应对方式：
- 如为强制驱逐令，须在收到命令书之日起7日内提出异议（出入境管理法第60条第1款）
- 考虑变更为其他资格（结果依个案而定）
- 自愿出境 → 处理方式可能与强制驱逐不同（依个案而定）

### 因财政能力不足被拒

- 补充存款余额证明
- 父母汇款协议书（公证）
- 登记韩国担保人（财力充足的在韩居住者）
- 四大保险参保记录（就业类签证）

### 因活动事实未获认定被拒

- 证明实际的任职·经营活动
- 照片、影像、同事陈述书
- 交易明细、合同
- 提供工作场所探访指引（可供核查）

### 婚姻真实性存疑（F-6）

- 婚礼照片、同居照片
- 韩国籍配偶的陈述
- 双方家庭会面记录
- 共同财产或共同住所证明
- KakaoTalk、视频通话等日常记录

### 学业不振（D-2）

- 学校方面的嘆願书（学业意愿）
- 追加学期注册证明
- 韩语学习证明
- 父母资助承诺书

## 5. 异议申请（行政审判）流程

### 提出时点
- 自知道处分之日起**90日内**（行政审判法第27条第1款）

### 受理机关
- 中央行政审判委员会（https://www.acrc.go.kr）

### 流程
1. 提交行政审判请求书
2. 处分厅（出入境·外国人厅）提交答辩书
3. 请求人提交补充意见书（可选）
4. 作出裁决（自收到审判请求书之日起60日内，不得已时延长30日 — 行政审判法第45条第1款）

### 费用
- 请求手续费：无
- 委托行政士代理的报酬另计

### 审理结果
- 裁决结果依个案事实与证据而定

## 6. 资格变更的选项

依被拒资格的不同，可考虑的变更选项：

| 被拒资格 | 可变更选项 |
|---|---|
| D-2（留学） | D-10（求职）、E-7（就业） |
| D-4（语言） | D-2（留学）、出境后重新申请 |
| E-7（特定活动） | D-10、F-2-7（居住，积分制） |
| E-9（非专业） | 出境后重新申请、F-6（结婚时） |
| F-2-7（居住） | F-1（访问同居）、F-3（随行） |
| D-8（企业投资） | F-2-12（投资）、F-5-5（永住） |

## 7. 自愿出境的战略价值

被拒后在收到强制驱逐处分前**自愿出境**，可能：
- 与被强制驱逐时的禁止入境处理不同（依个案而定）
- 在日后再入境申请时作为说明材料

出境命令（出入境管理法第68条）与强制驱逐是不同的处分。收到出境命令后应在指定期限内出境；逾期未出境的，将被发放强制驱逐命令书（第68条第4款）。

## 8. Sunshine行政士事务所的被拒应对

### 应对流程
1. **初步咨询** —— 分析拒签理由，确定应对方向
2. **决定补充材料还是变更资格**
3. **收集与撰写材料**
4. **提出申请 + 后续应对**
5. **结果通知 + 决定下一步**

### 本人出境后同样可办
- 自愿出境后，协助在本国重新申请签证
- 若在韩有家属，可由家属代为与行政士同行办理

## 9. 五个常见错误

1. **把补正命令误认为拒签** → 未提交补充材料
2. **忘记出国期限** → 可能进入强制驱逐等程序
3. **凭自己判断提交不当材料** → 招致更多质疑
4. **无视拒签理由，重复提交相同材料**
5. **在异议申请 / 资格变更 / 自愿出境之间选择失当**
