有意取得韩国永住权（F-5）或国籍的外国人，最担心的事项之一就是**过往的刑事记录**。一次酒驾、一起轻微斗殴、一次资格外活动——这些记录是否会构成永住权申请的欠格事由，必须弄清楚。

本文按案例梳理刑事记录对永住权与国籍的影响。

## 1. F-5 永住权的欠格事由（出入境管理法）

### 法律依据
- 《出入境管理法》第10条之3（永住资格）
- 《出入境管理法施行令》第12条之2（永住资格要件等）
- 《出入境管理法施行令》附表1之3（永住资格种类·要件）

永住资格要件在施行令第12条之2及附表1之3中按种类详细规定（F-5-1 ~ F-5-17）。审查中通常会确认下列事项（具体标准以法务部公布的居留指南为准）：

1. **有期徒刑或监禁刑记录**（刑种与执行完毕后的经过时间）
2. **缓刑记录**
3. **出入境违规记录**
4. **强制驱逐·出境命令记录**
5. **其他危害公共安全·秩序的情形**

### 期间标准

各类刑事处分对应的欠格期间，以法务部公布的居留指南（永住资格审查标准）为准，标准可能修订，实际也会因**罪名**与**主管机关的裁量**而有所不同。

## 2. 按罪名划分的永住权影响

### 影响较重的罪名
- **毒品案件**（单纯吸食也极为严重）
- **性犯罪**（强制猥亵、强奸等）
- **杀人、抢劫等严重暴力犯罪**
- **危害国家安全的犯罪**
- **违反外汇管理法（大额）**

→ 此类罪名在审查中可能被特别不利地考虑，结果因个案而异。

### 影响较大的罪名
- **诈骗（金额较大或累计）**
- **参与电信诈骗**
- **惯常暴力行为**
- **单纯吸食毒品（1次）**
- **惯犯盗窃**

### 影响一般的罪名
- **酒驾（1次、无事故）**
- **单纯斗殴（1次）**
- **名誉毁损**
- **资格外活动（反复）**
- **单纯盗窃（小额、1次）**

### 影响相对轻微的情形
- **金额较低的罚金**
- **起诉犹豫**
- **单纯出入境违规（1次）**

## 3. 经过时间的确认方法

### 基本思路
先确认**处罚确定日、刑罚执行完毕日（或缓刑期满日）与预定申请日**，再对照法务部现行标准判断是否已经过所需期间。

以上判断会因罪名、在韩居住期间、家庭关系、对韩国的贡献度等而不同，具体以主管机关的标准与说明为准。

## 4. 审查中可能被考虑的情节

### 可能被有利考虑的情节
- **韩国籍配偶或子女**（F-6 或 F-2）
- **家属为韩国永住权者**
- **在韩长期居住 + 稳定职业**
- **韩语能力**（TOPIK、社会统合项目等）
- **对韩国的贡献活动**（志愿服务、教育、医疗等）
- **本人自首 + 配合调查**（刑事处罚当时）
- **事后完成治疗或教育项目**

### 可能被不利考虑的情节
- 同一事由再犯
- 逃逸或试图规避逮捕
- 虚假陈述
- 在外国发生新的刑事案件

## 5. 申请 F-5 永住权前的自我诊断

### 检查清单

**1. 居留资格要件**
- [ ] 在韩居住5年以上（因资格而异）
- [ ] 稳定资格（E-7、F-2、F-4 等）

**2. 刑事记录审视**
- [ ] 是否有罚金处罚记录？处罚时间是何时？
- [ ] 是否有缓刑或实刑记录？执行完毕或期满是何时？
- [ ] 是否有出入境违规（事犯审查）记录？

**3. 融入韩国社会**
- [ ] 韩语能力（TOPIK 或社会统合项目）
- [ ] 稳定收入（标准因资格而异）
- [ ] 定期纳税记录

**4. 家庭关系**
- [ ] 是否有韩国家人（配偶、子女）？
- [ ] 家人是否稳定居住于韩国？

→ 若上述项目存在问题，建议先确认标准，或补足材料后再行申请。

## 6. 分案例前景

### 案例A：酒驾1次 + 5年后申请永住权
- 30多岁美国籍男性，F-2-7居住签证
- 酒驾 BAC 0.10，罚金400万韩元（5年6个月前）
- 在韩居住8年，就职于韩国企业，韩语TOPIK 5级
- 申请材料：
  - 酒驾后完成酒精治疗项目的证明
  - 5年无事故驾驶记录
  - 完成社会统合项目第5阶段
  - 公司高管嘆願书
  - 3年志愿服务记录
- **结果：永住权（F-5-1）获批**

### 案例B：缓刑2年 + 6年后申请
- 40多岁中国籍男性，F-2-7
- 斗殴案件缓刑1年，6年前期满
- 在韩居住12年，经营韩国企业
- 申请材料：
  - 完成6个月情绪管理治疗
  - 本国家属 + 韩国家属嘆願书
  - 企业营收证明，雇用员工5名
  - 纳税记录正常
- **结果：永住权（F-5-7）获批**（企业家资格）

### 案例C：毒品案件12年后申请
- 30多岁加拿大籍男性，F-2居住
- 吸食大麻1次，12年前受罚
- 申请材料：12年戒毒治疗记录、韩国家属
- **结果：被拒**（毒品案件属永久欠格）
- 后续：建议维持D-10或F-2

## 7. 取得韩国国籍与刑事记录

### 国籍法第5条（归化要件）
- 在韩国连续有住所5年以上（第1号）
- 持有可在韩永住的居留资格（第1号之2）
- 依《民法》已成年（第2号）
- 具备法务部令规定的品行端正要件（第3号，刑事记录在此审查）
- 具备生计能力（收入或可被家属抚养）
- 韩语能力 + 对韩国社会的理解
- 放弃外国国籍（有例外）

### 品行要件
- 入籍审查中，刑事记录作为品行端正要件的一部分被审查，具体标准由法务部令规定

### 实用建议
依《国籍法》第5条第1号之2，一般归化须持有永住资格，因此通常按**先取得永住权（F-5）→ 再申请入籍**的顺序推进。

## 8. 在外国的刑事记录

### 申报义务
申请韩国永住权·国籍时，**在外国的刑事记录同样负有申报义务。** 须在申请书中如实注明无犯罪或犯罪事实。

### 外国无犯罪证明
- 由本国警察或政府机关签发
- 需在韩国公证或办理海牙认证
- 签发日期要求以主管机关的指引为准

### 虚假申报的处罚
- 可能被取消永住权·国籍
- 可能接受强制驱逐等处分

## 9. Sunshine行政士事务所的永住权咨询

### 五步套餐
1. **初步咨询** —— 综合审视刑事记录 + 资格 + 家庭关系
2. **确定申请时点** —— 对照现行标准确认相关期间
3. **材料收集** —— 在韩居留、收入、韩语、家庭、酌情减轻
4. **撰写申请书 + 情况说明书**
5. **后续管理** —— 结果通知后的追加应对

- 申请 F-2-7（积分制居住）
- 申请 F-2-99（长期滞留）
- 考虑 D-10（求职）或其他新资格
