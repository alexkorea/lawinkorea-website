斗殴、盗窃、诈骗、名誉毁损 —— 在韩国卷入刑事案件的外国人，最担心的往往不是处罚本身，而是**"签证会怎么样"**。

VISION行政士事务所每年处理的外国人刑事案件事犯审查超过200件。以下梳理其中最常见的五类罪名及其结果规律，以及保住签证的应对策略。

## 1. 外国人最常卷入的五类刑事案件

### （1）斗殴·伤害
职场纠纷、酒桌冲突、家庭暴力、突发争执。斗殴是外国人最容易卷入的刑事案件。

- 单纯斗殴（伤害轻微）：罚金30~200万韩元 → 事犯审查中可延长签证
- 伤害（有医师诊断书）：罚金200~500万韩元或缓刑 → 可能被考虑强制驱逐
- 特殊斗殴（持凶器、多人）：1年以上有期徒刑 → 强制驱逐可能性高

### （2）盗窃·诈骗
- 单纯盗窃（金额较小）：罚金50~300万韩元 → 资格变更或出境命令
- 惯犯／特殊盗窃：6个月~3年有期徒刑 → 强制驱逐
- 诈骗（含参与电信诈骗）：[参见专题指南](/zh/blog/voice-phishing-foreigners)

### （3）名誉毁损·侮辱
- 网络评论、社交媒体帖子同样可能被追责
- 一般为罚金30~200万韩元
- 在韩国社会观感中，外国人侮辱韩国人往往被从重处理
- 和解后可免于处罚（属反意思不罚罪）

### （4）性犯罪
- 强制猥亵、性骚扰、数字性犯罪
- 即便仅一次，也几乎必然导致永久禁止入境或强制驱逐
- 需登记身份信息 + 就业限制
- 可以和解，但刑事处罚不予免除

### （5）酒后驾驶
- [参见专题指南](/zh/blog/dui-foreigner-visa)

## 2. 各类刑事处分对签证的影响

| 刑事处分 | 含义 | 对签证的影响 |
|---|---|---|
| **不构成犯罪·无罪** | 无罪 | 不影响签证（但事犯审查仍可能进行） |
| **起诉犹豫** | 有罪但不予处罚 | 属事犯审查对象，但有获得轻处分的可能 |
| **罚金刑**（略式命令） | 正式处罚 | 属事犯审查对象，因金额与罪名而异 |
| **宣告犹豫** | 暂缓宣告刑罚（2年） | 属事犯审查对象，较普通罚金略为有利 |
| **缓刑** | 宣告刑罚后暂缓执行 | 被考虑强制驱逐的可能性非常高 |
| **有期徒刑实刑** | 实际服刑 | 强制驱逐几乎已成定局 |

⚠️ **重要：** 刑事处分轻，不代表事犯审查也轻——两者相互独立。反之，即使刑事处分较重，只要酌情减轻被采纳，仍有可能保住资格。

## 3. 保住签证的五步策略

### 第1步：在刑事程序阶段就提前应对事犯审查

多数外国人是在**刑事程序结束之后**才开始准备事犯审查。这已经太迟。应在刑事程序进行期间就确保以下材料：

- 和解书、不予追究处罚意见书
- 酌情减轻材料（家庭、工作、对韩国的贡献）
- 悔过书（以韩语撰写）

### 第2步：从事犯审查的视角重新梳理处分结果

刑事处罚确定后，需分析**该处分在事犯审查中会被如何看待**。

例如：
- "罚金200万韩元" → 出入境职员视角：暴力性犯罪，担心累积
- "起诉犹豫" → 出入境职员视角：虽非正式处罚，但事实已被认定
- "缓刑6个月，考验期2年" → 出入境职员视角：属强制驱逐审视对象

### 第3步：以出入境视角重构酌情减轻材料

面向法院法官的材料，与面向出入境职员的材料**并不相同。**

**法官视角：**
- 损害已恢复、有悔意、无再犯之虞

**出入境职员视角：**
- 对韩国的贡献度、驱逐将造成的社会损失、家庭离散
- 同类再犯可能性、遣返回国后的安全性

### 第4步：事犯审查出席模拟

您需要能够回答以下问题：
- "您为什么来韩国？"
- "这起事件为什么会发生？"
- "为防止再犯，您正在做什么？"
- "继续在韩国生活，您能贡献什么？"
- "如果被强制驱逐，会发生什么？"

回答应简短、明确，语气上不推卸责任。

### 第5步：结果通知后30日内的后续应对

若事犯审查结果不利：
- **提出异议**（行政审判）—— 决定通知后90日内
- **转为自愿出境** —— 即使已作出强制驱逐处分，转为自愿出境仍可缩短禁止入境期限
- **申请资格变更** —— 即便现有签证被拒，仍可以其他资格提出申请

## 4. 实战案例：材料差距改变结果

### 案例A：斗殴罚金200万韩元 → 强制驱逐
- 30多岁男性，E-7签证
- 与同事发生争执并致伤
- 刑事：罚金200万韩元
- 事犯审查材料：仅提交刑事判决书与外国人登录证
- 事犯审查答复："是同事先挑事的"
- **结果：强制驱逐 + 3年禁止入境**

### 案例B：斗殴罚金300万韩元 → 维持资格
- 30多岁男性，F-2-7居住签证
- 街头争执并致伤（处罚重于案例A）
- 刑事：罚金300万韩元
- 事犯审查材料：
  - 被害人和解书 + 不予追究处罚意见书
  - 在韩居住8年，韩国籍配偶，育有子女
  - 公司高管的嘆願书（属公司核心人才）
  - 参加情绪管理治疗项目的证明
  - 3年志愿服务记录
- 事犯审查答复：承认责任 + 防止再犯的决心 + 继续贡献的意愿
- **结果：维持资格 + 保护观察处分**

差别不在罪名或罚金金额，而在**从出入境视角看，材料的厚度与深度**。

## 5. 最常见的五个错误

**错误1："律师把刑事案件办完了，就没事了"**
→ 律师专长于刑事辩护。出入境行政程序是另一回事。

**错误2："罚金都缴了，出入境应该会通融"**
→ 出入境按自身标准重新审查。缴纳罚金本身并非酌情减轻要素。

**错误3："是起诉犹豫，所以很安全"**
→ 起诉犹豫同样属事犯审查对象。"非正式处罚"仅是酌情减轻的一个要素而已。

**错误4："我和韩国人结婚了，不会被强制驱逐"**
→ 持F-6结婚签证在发生刑事案件时同样可能被强制驱逐。家庭是酌情减轻要素，但不是免罪符。

**错误5："自己去老实交代就会获得宽大处理"**
→ 诚实很重要，但未从出入境视角整理过的回答，反而可能造成不利影响。
