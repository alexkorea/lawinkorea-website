暴行、窃盗、詐欺、名誉毀損 — 韓国で刑事事件に巻き込まれた外国人が最も恐れるのは、処罰そのものよりも**「ビザがどうなるのか」**です。

最も多く扱う5つの罪名と結果のパターン、そしてビザを守る対応戦略を整理しました。

## 1. 外国人が最も多く巻き込まれる5つの刑事事件

### (1) 暴行・傷害
職場でのもめごと、飲み会での暴行、家庭内暴力、偶発的な衝突。暴行事件は外国人が最も巻き込まれやすい刑事事件です。

- 単純暴行(被害が軽微)：罰金30~200万ウォン → 事犯審査でビザ延長が可能
- 傷害(医師の診断書あり)：罰金200~500万ウォンまたは執行猶予 → 強制退去の検討があり得る
- 特殊暴行(凶器、多数)：1年以上の懲役 → 強制退去の可能性が高い

### (2) 窃盗・詐欺
- 単純窃盗(被害額が少額)：罰金50~300万ウォン → 資格変更または出国命令
- 常習・特殊窃盗：6か月~3年の懲役 → 強制退去
- 詐欺(特殊詐欺への加担を含む)：[別のガイドを参照](/ja/blog/voice-phishing-foreigners)

### (3) 名誉毀損・侮辱
- インターネットのコメント、SNS の投稿でも処罰され得る
- 一般的に罰金30~200万ウォン
- 韓国の社会感情上、外国人による韓国人への侮辱は重く処罰される傾向
- 示談すれば処罰を免れることがある(反意思不罰罪)

### (4) 性犯罪
- 強制わいせつ、セクシュアルハラスメント、デジタル性犯罪
- 1回でも永久入国禁止または強制退去がほぼ確定
- 身上情報の登録 + 就業制限
- 示談は可能だが刑事処罰は免除されない

### (5) 飲酒運転
- [別のガイドを参照](/ja/blog/dui-foreigner-visa)

## 2. 刑事処分の段階別に見るビザへの影響

| 刑事処分 | 意味 | ビザへの影響 |
|---|---|---|
| **嫌疑なし・無罪** | 罪がない | ビザへの影響なし(ただし事犯審査は進行し得る) |
| **起訴猶予** | 罪はあるが処罰しない | 事犯審査の対象だが軽い処分の可能性 |
| **罰金刑**(略式命令) | 正式な処罰 | 事犯審査の対象。金額と罪名により差 |
| **宣告猶予** | 刑の宣告を先送り(2年) | 事犯審査の対象。通常の罰金よりやや有利 |
| **執行猶予** | 刑の宣告後に執行を猶予 | 強制退去が検討される可能性が非常に高い |
| **懲役の実刑** | 実際に服役 | 強制退去がほぼ確定 |

⚠️ **重要：** 刑事処分が軽くても事犯審査は別です。逆に刑事処分が重くても、情状酌量が受け入れられれば資格を維持できます。

## 3. ビザを守るための5段階戦略

### Step 1. 刑事手続きの段階で事犯審査に先回りする

ほとんどの外国人は**刑事手続きが終わった後**に事犯審査の準備を始めます。それでは遅すぎます。刑事手続きの進行中に次を確保しておく必要があります。

- 示談書、処罰不願書
- 情状酌量資料(家族、職場、韓国への貢献)
- 反省文(韓国語で)

### Step 2. 処分結果を事犯審査の視点で整理し直す

刑事処罰が決まったら、**その処分が事犯審査でどう見えるか**を分析します。

例：
- 「罰金200万ウォン」→ 出入国職員の見方：暴力性の犯罪、累積の懸念
- 「起訴猶予」→ 出入国職員の見方：正式な処罰ではないが事実は認定されている
- 「執行猶予6か月、猶予2年」→ 出入国職員の見方：強制退去の検討対象

### Step 3. 情状酌量資料を出入国の視点で再構成する

裁判官のための資料と出入国職員のための資料は**違います。**

**裁判官の視点：**
- 被害の回復、反省、再犯のおそれがないこと

**出入国職員の視点：**
- 韓国への貢献度、退去による韓国社会の損失、家族の離散
- 同種再犯の可能性、本国送還時の安全性

### Step 4. 事犯審査の出席シミュレーション

次の質問に答えられる必要があります。
- 「なぜ韓国に来たのですか」
- 「この事件はなぜ起きたのですか」
- 「再発防止のために何をしていますか」
- 「韓国で暮らし続けて何を貢献できますか」
- 「強制退去になったらどうなりますか」

回答は短く、明確で、責任を回避しないトーンであるべきです。

### Step 5. 結果通知後30日以内の後続対応

事犯審査の結果が芳しくない場合：
- **異議申し立て**(行政審判) — 決定通知後90日以内
- **自主出国への切り替え** — 強制退去処分でも自主出国に切り替えれば入国禁止期間が短縮され得る
- **資格変更の申請** — 現在のビザが拒否されても別の資格で申請可能

## 4. 実例：資料の差が結果を変える

### 事例A：暴行で罰金200万ウォン → 強制退去
- 30代男性、E-7 ビザ
- 職場の同僚とのもめごとで傷害が発生
- 刑事：罰金200万ウォン
- 事犯審査の提出資料：刑事判決文、外国人登録証のみ
- 事犯審査での回答：「同僚が先に因縁をつけてきました」
- **結果：強制退去 + 3年の入国禁止**

### 事例B：暴行で罰金300万ウォン → 資格維持
- 30代男性、F-2-7 居住ビザ
- 路上のもめごとで傷害が発生(事例Aより処罰は重い)
- 刑事：罰金300万ウォン
- 事犯審査の提出資料：
  - 被害者の示談書 + 処罰不願書
  - 韓国居住8年、韓国人配偶者、子ども
  - 勤務先役員の嘆願書(会社の中核人材)
  - 怒りのコントロール治療プログラムの参加証明書
  - ボランティア活動3年の記録
- 事犯審査での回答：責任の認定 + 再発防止の意思 + 韓国への貢献の意思
- **結果：資格維持 + 保護観察処分**

差は罪名でも罰金額でもありません。**出入国の視点から見た資料の深さ**です。

## 5. 最もよくある5つの誤り

**誤り1：「弁護士が刑事事件を終わらせたので大丈夫です」**
→ 弁護士は刑事弁護の専門。出入国の行政手続きは別です。

**誤り2：「罰金を全部払ったので出入国も大目に見てくれます」**
→ 出入国は独自の基準で改めて審査します。罰金の納付そのものは情状酌量の要素ではありません。

**誤り3：「起訴猶予だから安全です」**
→ 起訴猶予も事犯審査の対象です。正式な処罰でないという点が情状酌量の一要素になるだけです。

**誤り4：「韓国人と結婚しているので強制退去にはなりません」**
→ F-6 結婚ビザでも刑事事件があれば強制退去はあり得ます。家族は情状酌量の要素ですが免罪符ではありません。

**誤り5：「一人で出席して正直に話せば大目に見てくれます」**
→ 正直さは重要ですが、出入国の視点で整理されていない回答は、かえって不利に働くことがあります。

## 6. 行政書士の同行が生む違い

[VISION行政書士事務所](/ja)の刑事事件事犯審査 対応パッケージ：

1. **事件分析**(当日・無料) — 刑事処分とビザへの影響を診断
2. **資料の収集と整理**(5~7日) — 家族・職場・貢献度の資料を体系化
3. **反省文・理由書の作成**(3~5日) — 韓国語 + 出入国の視点
4. **出席シミュレーション**(1~2回) — 想定質問と回答の整理
5. **事犯審査への同行**(当日) — 出入国事務所への同行、通訳、補充発言
6. **結果通知後30日間のフォロー** — 異議申し立てまたは後続のビザ戦略

刑事事件の発生直後が最も良いタイミングです。刑事手続きの終了後に始めると、事犯審査の出席日まで時間が足りません。
