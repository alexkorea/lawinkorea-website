韓国の永住権(F-5)または国籍の取得を目指す外国人が最も心配することの一つが**過去の刑事記録**です。飲酒運転が一度、小さな暴行事件、資格外活動が一度 — こうした記録が永住権申請の欠格事由になり得るのかを、正確に把握しておく必要があります。

VISION行政書士事務所が毎年扱う永住権申請コンサルティングのうち、約40%が刑事記録のある外国人です。この記事では、刑事記録が永住権・国籍に及ぼす影響を事例別に整理します。

## 1. F-5 永住権の欠格事由(出入国管理法)

### 根拠法令
- 「出入国管理法」第10条の3(永住資格)
- 「出入国管理法施行令」第12条の2(永住資格の要件など)
- 「出入国管理法施行令」別表1の3(永住資格の種類・要件)

永住資格の要件は施行令第12条の2および別表1の3に種類別で詳細に規定されています(F-5-1 ~ F-5-17)。次のいずれかに該当すると永住権は欠格です。

1. ❌ **3年以上の懲役刑または禁錮刑**(執行中、または執行終了後5年未経過)
2. ❌ **3年以上の懲役刑の執行猶予**(猶予期間 + 5年)
3. ❌ **出入国違反の累積**(3回以上)
4. ❌ **強制退去処分**(5年以内)
5. ❌ **その他、公共の安全・秩序を害した者**

### 一般的な解釈基準

| 刑事処分 | 欠格期間 |
|---|---|
| 罰金100万ウォン以下 | 約1~2年 |
| 罰金100~500万ウォン | 約2~5年 |
| 罰金500万ウォン以上 | 5年以上 |
| 起訴猶予 | 約1~2年 |
| 宣告猶予 | 約2~3年 |
| 執行猶予1年 | 猶予 + 3年 = 約4年 |
| 執行猶予2年 | 猶予 + 5年 = 約7年 |
| 実刑1年 | 出所後5~7年 |
| 実刑2年以上 | 出所後7~10年 |

⚠️ 上の表は一般基準であり、**罪名**と**出入国職員の裁量**によって変わります。

## 2. 罪名別の永住権への影響

### 🔴 非常に重い影響(永久欠格に近い)
- **麻薬事件**(単純使用でも非常に重い)
- **性犯罪**(強制わいせつ、強姦など)
- **殺人、強盗などの強力犯罪**
- **国家安全保障に関わる犯罪**
- **外国為替管理法違反(大規模)**

→ これらの罪名は10年以上経過しても永住権はほぼ不可能です。

### 🟡 重い影響(5~10年の欠格)
- **詐欺(高額または累積)**
- **特殊詐欺への加担**
- **常習的な暴力**
- **麻薬の単純使用(1回)**
- **常習窃盗**

### 🟢 普通の影響(3~5年の欠格)
- **飲酒運転(1回、無事故)**
- **単純暴行(1回)**
- **名誉毀損**
- **資格外活動(反復)**
- **単純窃盗(少額、1回)**

### 🟢 軽微な影響(1~3年の欠格)
- **罰金100万ウォン以下**
- **起訴猶予**
- **単純な出入国違反(1回)**

## 3. 刑事記録の回復時期の計算法

### 基本の式
**処罰終了日 + 一定期間 = 欠格終了日**

### 計算例

**例A：罰金300万ウォン(飲酒運転)**
- 処罰日：2024-06-01
- 想定される欠格：約5年
- 永住権の申請が可能：**2029-06-01 以降**

**例B：執行猶予1年(暴行)**
- 処罰日：2023-03-15
- 執行猶予の終了：2024-03-14
- 追加の欠格期間：5年
- 永住権の申請が可能：**2029-03-15 以降**

**例C：実刑1年(詐欺)**
- 処罰日：2023-01-10
- 出所日：2024-01-09
- 追加の欠格期間：7年
- 永住権の申請が可能：**2031-01-10 以降**

⚠️ 上記は**一般基準**であり、韓国での居住期間、家族関係、韓国への貢献度によって短縮または延長され得ます。

## 4. 欠格期間を短縮し得る事由

### 強力な短縮事由
- ✅ **韓国人の配偶者または子ども**(F-6 または F-2)
- ✅ **韓国の永住権者である家族**
- ✅ **5年以上の韓国居住 + 安定した職業**
- ✅ **韓国語能力**(TOPIK 5級以上)
- ✅ **韓国への貢献活動**(ボランティア、教育、医療など)
- ✅ **本人の自首 + 捜査協力**(刑事処罰の当時)
- ✅ **事後の治療または教育プログラムの修了**

### 欠格期間が延びる事由
- ❌ 同一事由での再犯
- ❌ 逃走または逮捕の回避を試みたこと
- ❌ 虚偽の陳述
- ❌ 外国での追加の刑事事件

## 5. F-5 永住権 申請前のセルフチェック

### チェックリスト

**1. 在留資格の要件**
- [ ] 韓国居住5年以上(資格により差あり)
- [ ] 安定した資格(E-7、F-2、F-4 など)

**2. 刑事記録の検討**
- [ ] 罰金500万ウォン以上の刑事処罰が5年以内にあるか？
- [ ] 執行猶予または実刑が7~10年以内にあるか？
- [ ] 出入国違反(事犯審査)が5年以内にあるか？

**3. 韓国社会への統合**
- [ ] 韓国語能力(TOPIK または社会統合プログラム)
- [ ] 安定した所得(年6,000万ウォン以上が望ましい)
- [ ] 定期的な納税内訳

**4. 家族関係**
- [ ] 韓国の家族(配偶者、子ども)がいるか？
- [ ] 家族が安定して韓国に居住しているか？

→ 上の項目に ❌ があれば、欠格期間の経過または資料の補完後に申請することをおすすめします。

## 6. 事例別の見通し

### 事例A：飲酒運転1回 + 5年後に永住権申請
- 30代の米国籍男性、F-2-7 居住ビザ
- 飲酒運転 BAC 0.10、罰金400万ウォン(5年6か月前)
- 韓国居住8年、韓国企業に勤務、韓国語 TOPIK 5級
- 申請資料：
  - 飲酒運転後のアルコール治療プログラム修了証明
  - 5年間の無事故運転記録
  - 社会統合プログラム5段階の履修
  - 会社役員の嘆願書
  - ボランティア活動3年の記録
- **結果：永住権(F-5-1)の承認**

### 事例B：執行猶予2年 + 6年後に申請
- 40代の中国籍男性、F-2-7
- 暴行事件で執行猶予1年、6年前に終了
- 韓国居住12年、韓国で事業を運営
- 申請資料：
  - 怒りのコントロール治療6か月の修了
  - 本国の家族 + 韓国の家族の嘆願書
  - 事業体の売上証明、従業員5名の雇用
  - 納税内訳が正常
- **結果：永住権(F-5-7)の承認**(事業家資格)

### 事例C：麻薬事件から12年後の申請
- 30代のカナダ籍男性、F-2 居住
- 大麻の使用1回、12年前に処罰
- 申請資料：12年間の麻薬治療、韓国の家族
- **結果：不許可**(麻薬事件は永久欠格)
- その後：D-10 または F-2 の維持を推奨

## 7. 韓国国籍の取得と刑事記録

### 国籍法第5条(帰化の要件)
- 韓国居住5年以上(永住権取得後の5年以上は別途)
- 満19歳以上
- 品行が端正であること(刑事記録の評価)
- 生計能力(所得または家族の扶養が可能)
- 韓国語能力 + 韓国社会への理解
- 外国国籍の放棄(例外あり)

### 永住権より厳しい基準
- 永住権：5年の欠格
- 国籍取得：7~10年の欠格
- 永住権の取得後、さらに5年の無犯罪が必要

### 実務上のヒント
多くの外国人には、**永住権(F-5)を先に取得 → さらに5年の無犯罪 → 国籍取得**という順序をおすすめします。

## 8. 外国での刑事記録

### 申告義務
韓国の永住権・国籍の申請時には、**外国での刑事記録にも申告義務があります。** 申請書に無犯罪または犯罪事実を明記します。

### 外国の無犯罪証明書
- 本国の警察または政府が発行
- 韓国での公証またはアポスティーユ
- 通常は発給から6か月以内のもの

### 虚偽申告の場合の処罰
- 永住権・国籍の取消
- 強制退去 + 永久入国禁止

## 9. VISION行政書士事務所の永住権コンサルティング

### 5段階パッケージ
1. **無料の初期診断** — 刑事記録 + 資格 + 家族関係の総合検討
2. **申請時期の決定** — 欠格期間の正確な計算
3. **資料の収集** — 韓国居住、所得、韓国語、家族、情状酌量
4. **申請書 + 理由書の作成**
5. **事後の管理** — 結果通知後の追加対応

### 欠格期間中の代替案
- F-2-7(点数制の居住)の申請
- F-2-99(長期滞在)の申請
- D-10(求職)または新たな資格の検討

## 10. 今すぐ診断を受けてください

永住権の申請時期は**早すぎても遅すぎてもいけません。** 欠格期間が正確にいつ終わるのか、その時期が来る前にどの資料を準備すべきかを事前に診断することが要です。
