韓国の永住権(F-5)または国籍の取得を目指す外国人が最も心配することの一つが**過去の刑事記録**です。飲酒運転が一度、小さな暴行事件、資格外活動が一度 — こうした記録が永住権申請の欠格事由になり得るのかを、正確に把握しておく必要があります。

この記事では、刑事記録が永住権・国籍に及ぼす影響を事例別に整理します。

## 1. F-5 永住権の欠格事由(出入国管理法)

### 根拠法令
- 「出入国管理法」第10条の3(永住資格)
- 「出入国管理法施行令」第12条の2(永住資格の要件など)
- 「出入国管理法施行令」別表1の3(永住資格の種類・要件)

永住資格の要件は施行令第12条の2および別表1の3に種類別で規定されています。品行要件については「出入国管理法施行規則」第18条の4第1項第1号が、次のいずれかに該当する人を対象外としています。

1. **禁錮以上の実刑**：刑の執行が終了または免除された日から5年が経過していない人
2. **禁錮以上の刑の執行猶予**：判決が確定した日から5年が経過していない人
3. **罰金刑**：罰金を納付した日から3年が経過していない人
4. **出入国管理法違反**：申請日から最近5年間に3回以上違反した人(過料処分を受けた人を除く)
5. **強制退去命令**：出国した日から7年が経過していない人
6. **出国命令**：出国した日から5年が経過していない人
7. **その他**：これらに準ずる事由として法務部長官が定める人

### 法令上の期間(永住資格・帰化)

| 刑事処分等 | 永住資格(F-5) | 帰化 |
|---|---|---|
| 罰金刑 | 納付の日から3年 | 納付の日から5年 |
| 宣告猶予・起訴猶予 | 個別の事情による | 処分の日から2年 |
| 禁錮以上の刑の執行猶予 | 判決確定の日から5年 | 猶予期間終了の日から7年 |
| 禁錮以上の実刑 | 執行終了・免除の日から5年 | 執行終了等の日から10年 |
| 強制退去命令 | 出国の日から7年 | 出国の日から10年 |
| 出国命令 | 出国の日から5年 | 出国の日から5年 |

根拠：「出入国管理法施行規則」第18条の4第1項第1号、「国籍法施行規則」第5条の2第1号(2026年10月4日 law.go.kr 確認)。いずれも法務部長官が事情を総合的に考慮して許可できる規定があり(出入国管理法施行規則第18条の4第2項、国籍法施行規則第5条の2第2号)、判断は個別の事案によって異なります。

## 2. 罪名別の永住権への影響

### 重く考慮され得る罪名
- **麻薬事件**
- **性犯罪**(強制わいせつ、強姦など)
- **殺人、強盗などの強力犯罪**
- **国家安全保障に関わる犯罪**
- **外国為替管理法違反(大規模)**

→ これらの罪名は、法令上の期間が経過した後も審査で重く考慮されることがあります。

### 経緯や回数が重視され得る罪名
- **詐欺(高額または累積)**
- **特殊詐欺への加担**
- **常習的な暴力**
- **麻薬の単純使用(1回)**
- **常習窃盗**

### 比較的よく問題になる罪名
- **飲酒運転(1回、無事故)**
- **単純暴行(1回)**
- **名誉毀損**
- **資格外活動(反復)**
- **単純窃盗(少額、1回)**

### その他
- **少額の罰金刑**
- **起訴猶予**
- **単純な出入国違反(1回)**

## 3. 刑事記録の回復時期の計算法

### 基本の式
**起算日(罰金の納付日・判決確定日・執行終了日など) + 法令上の期間 = 期間の経過日**

### 計算例

**例A：罰金刑(飲酒運転)**
- 罰金の納付日：2024-06-01
- 永住資格の品行要件上の期間：納付の日から3年
- 期間の経過：**2027-06-01 以降**

**例B：執行猶予(暴行)**
- 判決の確定日：2023-03-15
- 永住資格の品行要件上の期間：判決確定の日から5年
- 期間の経過：**2028-03-15 以降**

**例C：実刑(詐欺)**
- 刑の執行終了日：2024-01-09
- 永住資格の品行要件上の期間：執行終了の日から5年
- 期間の経過：**2029-01-09 以降**

上記は法令上の期間の計算例です。期間が経過しても許可が保証されるわけではなく、韓国での居住期間、家族関係、韓国への貢献度などが総合的に考慮され、判断は個別の事案によって異なります。

## 4. 総合的に考慮され得る事情

法務部長官は、国内で形成した社会的・経済的基盤、韓国社会への寄与の程度、違反行為による公益侵害の程度などを総合的に考慮して永住資格の取得を許可できるとされています(出入国管理法施行規則第18条の4第2項)。

### 有利な事情として考慮され得るもの
- **韓国人の配偶者または子ども**(F-6 または F-2)
- **韓国の永住権者である家族**
- **韓国での長期居住 + 安定した職業**
- **韓国語能力**
- **韓国への貢献活動**(ボランティア、教育、医療など)
- **本人の自首 + 捜査協力**(刑事処罰の当時)
- **事後の治療または教育プログラムの修了**

### 不利に考慮され得る事情
- 同一事由での再犯
- 逃走または逮捕の回避を試みたこと
- 虚偽の陳述
- 外国での追加の刑事事件

## 5. F-5 永住権 申請前のセルフチェック

### チェックリスト

**1. 在留資格の要件**
- [ ] 資格ごとに定められた韓国居住期間(施行令別表1の3)
- [ ] 安定した資格(E-7、F-2、F-4 など)

**2. 刑事記録の検討**
- [ ] 罰金の納付日から3年が経過しているか？
- [ ] 執行猶予の判決確定日、または実刑の執行終了日から5年が経過しているか？
- [ ] 最近5年間に出入国管理法違反が3回以上ないか？(過料処分を除く)

**3. 韓国社会への統合**
- [ ] 韓国語能力(TOPIK または社会統合プログラム)
- [ ] 本人または生計を同じくする家族の所得が前年度の一人当たり国民総所得(GNI)以上など(出入国管理法施行規則第18条の4第1項第2号)
- [ ] 定期的な納税内訳

**4. 家族関係**
- [ ] 韓国の家族(配偶者、子ども)がいるか？
- [ ] 家族が安定して韓国に居住しているか？

→ 満たしていない項目があれば、法令上の期間の経過や資料の補完を検討してから申請することをおすすめします。

## 6. 事例別の見通し

### 事例A：飲酒運転1回 + 5年後に永住権申請
- 30代の米国籍男性、F-2-7 居住ビザ
- 飲酒運転 BAC 0.10、罰金400万ウォン(5年6か月前)
- 韓国居住8年、韓国企業に勤務、韓国語 TOPIK 5級
- 申請資料：
  - 飲酒運転後のアルコール治療プログラム修了証明
  - 5年間の無事故運転記録
  - 社会統合プログラム5段階の履修
  - 会社役員の嘆願書
  - ボランティア活動3年の記録
- **結果：永住権(F-5-1)の承認**

### 事例B：執行猶予2年 + 6年後に申請
- 40代の中国籍男性、F-2-7
- 暴行事件で執行猶予1年、6年前に終了
- 韓国居住12年、韓国で事業を運営
- 申請資料：
  - 怒りのコントロール治療6か月の修了
  - 本国の家族 + 韓国の家族の嘆願書
  - 事業体の売上証明、従業員5名の雇用
  - 納税内訳が正常
- **結果：永住権(F-5-7)の承認**(事業家資格)

### 事例C：麻薬事件から12年後の申請
- 30代のカナダ籍男性、F-2 居住
- 大麻の使用1回、12年前に処罰
- 申請資料：12年間の麻薬治療、韓国の家族
- **結果：不許可**(麻薬事件は永久欠格)
- その後：D-10 または F-2 の維持を推奨

## 7. 韓国国籍の取得と刑事記録

### 国籍法第5条(帰化の要件)
- 5年以上継続して韓国に住所があること
- 韓国で永住できる在留資格を持っていること(第1の2号)
- 民法上の成年であること
- 品行が端正であること(刑事記録の評価)
- 生計能力(所得または家族の扶養が可能)
- 韓国語能力 + 韓国社会への理解
- 外国国籍の放棄(例外あり)

### 帰化の品行要件(国籍法施行規則第5条の2)
- 禁錮以上の実刑：執行終了等の日から10年
- 禁錮以上の刑の執行猶予：猶予期間終了の日から7年
- 罰金刑：納付の日から5年
- 宣告猶予・起訴猶予：処分の日から2年
- 強制退去命令：出国の日から10年 / 出国命令：出国の日から5年

### 実務上のヒント
一般帰化では永住資格を持っていることが要件の一つです(国籍法第5条第1の2号)。そのため、**永住資格(F-5)の取得 → 帰化の申請**という順序で準備するのが一般的です。

## 8. 外国での刑事記録

### 申告義務
韓国の永住権・国籍の申請時には、**外国での刑事記録にも申告義務があります。** 申請書に無犯罪または犯罪事実を明記します。

### 外国の無犯罪証明書
- 本国の警察または政府が発行
- 韓国での公証またはアポスティーユ
- 有効期間などは提出先の案内を確認してください

### 虚偽申告の場合
- 虚偽や不正な方法で取得した永住資格は取消の事由とされています(出入国管理法第89条の2第1項第1号)
- その他の不利益につながることもあります

## 9. サンシャイン行政書士事務所の永住権コンサルティング

### 5段階パッケージ
1. **無料の初期診断** — 刑事記録 + 資格 + 家族関係の総合検討
2. **申請時期の決定** — 欠格期間の正確な計算
3. **資料の収集** — 韓国居住、所得、韓国語、家族、情状酌量
4. **申請書 + 理由書の作成**
5. **事後の管理** — 結果通知後の追加対応

### 欠格期間中の代替案
- F-2-7(点数制の居住)の申請
- F-2-99(長期滞在)の申請
- D-10(求職)または新たな資格の検討

## 10. 今すぐ診断を受けてください

永住権の申請時期は**早すぎても遅すぎてもいけません。** 欠格期間が正確にいつ終わるのか、その時期が来る前にどの資料を準備すべきかを事前に診断することが要です。
