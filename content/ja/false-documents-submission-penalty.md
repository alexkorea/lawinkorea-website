在留期間の延長や資格の変更の際、書類が足りないと気が焦ります。そんなとき「それらしいものを作って出せばいい」という誘惑が生じますが、偽造・変造書類や虚偽の申請書は、出入国管理法が別に禁止し処罰する行為です。この記事では、虚偽書類提出の禁止規定の内容と罰則、単なる誤記との違いを整理しました。

## 要点

- 資格外活動、勤務先の変更・追加、在留資格の付与・変更、在留期間の延長などの許可申請で、**偽造・変造文書**や**虚偽の事実が書かれた申請書**を提出するなどの不正な方法で申請してはなりません。
- そうした申請の**あっせん・勧誘**も禁止されています。
- 違反すると3年以下の懲役または3千万ウォン以下の罰金の対象となり、外国人は退去強制事由にも当たります。
- 犯則金の基準額は、違反回数やあっせん人数が増えるほど上がります。

## 1. どの許可申請が対象ですか？

虚偽書類提出の禁止規定は、出入国管理法による在留関連の**許可申請**に関する行為が対象です。平たく言えば、資格外活動許可、勤務先の変更・追加許可、在留資格の付与、在留資格の変更許可、在留期間の延長許可の申請などです。禁止される行為は二つあります。

- 偽造・変造された文書を立証資料として提出したり、虚偽の事実が書かれた申請書を提出したりするなどの**不正な方法による申請**
- 上記の行為の**あっせん・勧誘**

## 2. 罰則と犯則金の基準

出入国管理法は、この規定に違反した人を3年以下の懲役または3千万ウォン以下の罰金に処すると定めています。官署の長の告発がなければ公訴を提起できず、官署の長は犯罪の確証を得たとき、罰金に相当する犯則金を通告できます。出入国管理法施行規則の犯則金の基準額は次のとおりです（2026年10月時点）。

| 区分 | 回数・人数 | 犯則金の基準額 |
|---|---|---|
| 本人の申請 | 1回目 | 500万ウォン |
| | 2回目 | 1,000万ウォン |
| | 3回目 | 2,000万ウォン |
| | 4回目以上 | 3,000万ウォン |
| あっせん・勧誘 | 1人 | 1,000万ウォン |
| | 2〜4人 | 1,500万ウォン |
| | 5〜9人 | 2,000万ウォン |
| | 10〜19人 | 2,500万ウォン |
| | 20人以上 | 3,000万ウォン |

基準額は年齢・環境・動機・結果・負担能力を考慮して2分の1の範囲で減らしたり増やしたりできます。通告書は15日以内に納め、納めた後は同じ事件で再び処罰されません。

## 3. 外国人への影響

出入国管理法は、この規定に違反した外国人を退去強制の対象と定めています。永住資格者は、法が定める例外を除き退去強制されません。すでに在留許可を受けている場合は、[在留許可取消し対応ガイド](/ja/blog/foreigner-visa-cancellation-response)もご確認ください。自費で自主的に出国しようとする人には出国命令ができます。

## 4. 単なる誤記とはどう違いますか？

一方、出入国管理法は、この法律による各種の申請や届出で**虚偽の事実を記載・報告した人**に50万ウォン以下の過怠金を科すと定めています。ただし虚偽書類提出の禁止に違反して刑事罰の対象となる人は除かれます。出入国管理法施行令の過怠金の基準額は1回目30万ウォン、2回目40万ウォン、3回目以上50万ウォンです（2026年10月時点）。どの規定が適用されるかは、偽造・変造文書を提出したか、不正な方法で申請したかなどの事実関係によるため、断定はできません。調査を受けることになったら、[事犯審査ガイド](/ja/blog/immigration-offense-review-guide)のように、まず経緯と資料を整理してください。

## 5. 書類に問題が生じたときの順序

1. **問題の書類を確認します。** どの申請に、どの書類を、誰から受け取ったのかを整理します。
2. **提出前なら、事実どおりに準備し直します。** 書類が入手できなければ、管轄官署に代替方法を問い合わせてください。
3. **すでに提出済みなら、官署に訂正方法を確認します。** 自ら正した経緯は、のちの説明に役立つことがあります。
4. **出頭要求書・通告書が届いたら、まず期限を確認します。** 通告書は受け取った日から15日です。
5. **疎明資料を整理します。** 経緯・反省の内容・再発防止の計画を書面にまとめるとき、[反省文の書き方ガイド](/ja/blog/reflection-letter-guide)が役立ちます。

## 6. 行政士事務所がお手伝いできること

申請書と証拠書類の事実関係の点検、訂正手続きの案内、違反の経緯を説明する疎明書・意見書の作成、外国語書類の翻訳をお手伝いします。告発後の捜査・刑事裁判での弁護は行政士の業務範囲外のため、お受けしていません。

書類に問題があるとわかったら、提出前に、すでに出したなら一日も早く点検を始めてください。
