転職や副業を始めるとき、「会社同士で処理してくれるだろう」と思って進めてしまうことがあります。しかし、就労可能な在留資格を持っていても、勤務先が変わったり増えたりした時点で、出入国管理法上の許可または申告の義務が生じます。この記事では、勤務先の変更・追加を逃した場合の処罰基準と対応手順を整理しました。

## 要点

- 在留資格の範囲内で勤務先を変更・追加するには、**事前に法務部長官の許可**が必要です（第21条第1項本文）。
- 施行令第26条の2に該当する専門人材は、勤務先を変更・追加した日から**15日以内の申告**で足ります（同項ただし書き）。
- 許可なく変更・追加すると、1年以下の懲役または1,000万ウォン以下の罰金の対象で（第95条第6号）、犯則金の基準額は100万ウォンから1,000万ウォンです（2026年10月時点、施行規則 別表7）。
- 申告義務だけに違反した場合は200万ウォン以下の過料で、基準額は10万ウォンから200万ウォンです（2026年10月時点、施行令 別表2）。

## 1. 許可と申告はどう違いますか？

第21条第1項は、韓国に滞在する外国人が在留資格の範囲内で勤務先を変更・追加するには、大統領令で定めるところにより**事前に法務部長官の許可**を受けるよう定めています。施行令第26条第1項に基づき、勤務先変更・追加許可申請書と法務部令で定める書類を管轄官署に提出します。

例外があります。専門的な知識・技術・技能を持つ人で大統領令が定める人は、勤務先を変更・追加した**日から15日以内に申告**すれば足ります（第21条第1項ただし書き）。施行令第26条の2第1項は、その対象を教授（E-1）から特定活動（E-7）までの在留資格のいずれかを持つ外国人で、法務部長官が告示する要件を備えた人と定めています。同じ職種でも要件を満たさなければ、申告ではなく事前の許可の対象です。

## 2. 許可なく勤務先を変えるとどんな処罰がありますか？

第95条第6号は、第21条第1項本文に違反して許可なく勤務先を変更・追加した人を、1年以下の懲役または1,000万ウォン以下の罰金に処すると定めています（2026年10月時点）。許可を受けていない外国人を雇用した人も同じ号で処罰されます（第21条第2項）。指定された勤務先以外の場所で勤務した場合は第18条第2項違反で、第95条第5号が適用されます。

官署の長は、調査の結果、犯罪の確証を得たときは、罰金に相当する犯則金の納付を通告できます（第102条第1項）。施行規則[別表7]の基準額は違反期間に応じて次のとおりです（2026年10月時点）。

| 違反期間 | 犯則金の基準額 |
|---|---|
| 3か月未満 | 100万ウォン |
| 3か月以上6か月未満 | 200万ウォン |
| 6か月以上1年未満 | 300万ウォン |
| 1年以上2年未満 | 500万ウォン |
| 2年以上 | 1,000万ウォン |

第95条第5号と第6号の基準額は同じです。これは**基準額**で、年齢と環境、違反の動機と結果、負担能力、違反回数などを考慮し、2分の1の範囲で減軽・加重できます（施行規則第86条第2項）。通告書は受け取った日から15日以内に納め（第105条第1項）、通告どおり納めれば、同じ事件で再び処罰されることはありません（第106条）。

## 3. 申告だけが遅れた場合はどうなりますか？

申告の対象なのに15日を過ぎた場合は、刑罰ではなく**過料**の問題です。第100条第1項第3号は、第21条第1項ただし書きの申告義務に違反した人に200万ウォン以下の過料を科すと定めています（2026年10月時点）。

| 遅れた期間 | 過料の基準額 |
|---|---|
| 3か月未満 | 10万ウォン |
| 3か月以上6か月未満 | 30万ウォン |
| 6か月以上12か月未満 | 50万ウォン |
| 1年以上2年未満 | 100万ウォン |
| 2年以上 | 200万ウォン |

施行令[別表2]の、第21条第1項ただし書きの申告義務に関する基準です。事情を考慮して2分の1の範囲で減額できますが、過料を滞納している場合は減額されません（別表2の一般基準）。また、過料を科す前には事前通知と10日以上の意見提出期間が与えられます（秩序違反行為規制法第16条）。法務部の在留案内マニュアルも、期限を過ぎた申告は過料の処分と事件の終結後に受理すると説明しています。

## 4. 強制退去とその後の在留への影響は？

第46条第1項第9号は、第21条第1項本文に違反して許可なく勤務先を変更・追加した場合や、第21条第2項に違反して外国人を雇用・あっせんした場合を強制退去の対象事由と定めています。ただし法務部の在留案内マニュアルの専門人材事後申告の項目は、許可なく変更・追加された勤務先で働いた場合を、違反の経緯と程度を総合して審査するとし、次のように案内しています。

- 初回の違反：通告処分後に勤務先の変更等を認める
- 直近2年以内に違反が2回以上、または外国人招請制限業者が雇用した場合：原則として通告処分後に出国措置

個別の結果は官署が判断するため、上記は例として理解してください。同じマニュアルは、勤務先変更・追加の申告は在留許可の申請ではないので、最初に許可された在留期間を超えて滞在するには別に在留期間延長許可が必要だとも案内しています。

## 5. 雇用した会社にも責任がありますか？

はい。雇用する側にも義務があります。第21条第2項は、勤務先の変更・追加の許可を受けていない外国人を雇用したり、雇用をあっせんしたりしてはならないと定めています。また第19条第1項は、就労資格のある外国人を雇用した者に、解雇・退職・死亡、所在不明、雇用契約の重要な内容の変更があった場合、15日以内の申告を求めています。これに違反すると200万ウォン以下の過料です（2026年10月時点、第100条第1項第1号）。事業主側の責任は[不法雇用の事業主処罰ガイド](/ja/blog/illegal-employer-penalty)に整理しています。

## 6. すでに勤務先が変わっていると気づいたときの手順

1. **日付を整理します。**新しい勤務先で働き始めた日、前の勤務先をやめた日、許可または申告をした日。基準額の区分はこの期間で決まります。
2. **自分が許可の対象か申告の対象かを確認します。**在留資格と告示の要件によって異なります。
3. **管轄の出入国・外国人官署にすぐ確認します。**申請には法務部令で定める書類が必要で、在留資格ごとに異なります。
4. **出頭要求や通告書を受けたら期限を守ります。**出頭要求書には趣旨と日時・場所が書かれ（施行令第58条）、通告書は受け取った日から15日が目安です。
5. **事情を事実どおりに整理します。**転職の経緯、雇用主の案内の有無、前の勤務先の移籍同意の有無などを、証拠とともにまとめておくと説明が明確になります。

## 7. 行政士にお任せいただけること

勤務先の変更・追加の許可および申告書類の作成と提出代行、違反の経緯を説明する疎明書・意見書の作成、証拠資料の整理と翻訳をお手伝いします。告発後の捜査・刑事裁判での弁護は行政士の業務範囲外のため、お受けしていません。

すでに勤務先が変わっている場合は、まず現在の許可・申告の状態を確認してください。通告書や出頭要求書がある場合は、日付を確認して、残りの期限と疎明資料を一緒に点検しましょう。
