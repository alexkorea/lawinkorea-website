韓国で飲酒運転により摘発された外国人が最初に聞く言葉は二つあります。**「刑事処罰は終わりました」**、そして**「出入国からもう一度呼ばれるそうです」**。

後者がまさに出入国事犯審査です。刑事手続きが罰金刑で終わっていても、出入国・外国人庁は別の行政手続きとして、ビザ延長の拒否、出国命令、強制退去を決定することができます。

この記事では、飲酒運転の摘発直後に外国人が知っておきたい事犯審査の流れと準備を整理します。

## 1. 飲酒運転の摘発 → 刑事処罰 → 事犯審査

### 第1段階：取締り現場
- 血中アルコール濃度(BAC)の測定 → 測定を拒否すると別途処罰の対象(道路交通法第148条の2第2項)
- 免許停止または取消の通知

### 第2段階：刑事処罰
- 検察送致 → 略式命令(罰金)または正式裁判
- BAC と事故の有無によって処罰が決定

### 第3段階：事犯審査の通知
- 刑事処罰の終了後、出入国事務所から通知
- ビザ延長の時点で自動的に始まる場合と、別途出席を求められる場合がある

### 第4段階：事犯審査の結果
- 在留許可 / 資格変更 / 出国命令 / 強制退去 / 入国禁止

## 2. 韓国で飲酒運転をしたら強制退去になりますか？血中アルコール濃度(BAC)別の処分見通し

強制退去は出入国管理法第46条各号に定められた事由に該当する場合に行われ、実際の結果は個別の事案によって異なります。

| BAC 数値 | 刑事処罰(道路交通法第148条の2第3項・初回違反) | 出入国事犯審査 |
|---|---|---|
| 0.03%以上0.08%未満 | 1年以下の懲役または500万ウォン以下の罰金 | 事犯審査の対象となり得る |
| 0.08%以上0.2%未満 | 1年以上2年以下の懲役または500万ウォン以上1千万ウォン以下の罰金 | 出国命令や強制退去が検討されることがある |
| 0.2%以上 | 2年以上5年以下の懲役または1千万ウォン以上2千万ウォン以下の罰金 | 出国命令や強制退去が検討されることがある |
| 測定拒否 | 1年以上5年以下の懲役または500万ウォン以上2千万ウォン以下の罰金(同条第2項) | 出国命令や強制退去が検討されることがある |
| 事故を伴う場合 | 上記の処罰に加え、他の法律による処罰があり得る | より重く検討されることがある |

10年以内の再違反は同条第1項により別の法定刑が適用されます。運転免許の停止・取消は道路交通法第93条によります。上の表の出入国欄は一般的な説明であり、処分は情状資料(家族、職場、韓国への貢献度)を含む個別の事件によって異なります。

## 3. 事犯審査の出席前チェックリスト

### 必須書類
- [ ] 刑事処罰の結果通知書(略式命令書または判決文)
- [ ] 飲酒運転の取締り報告書
- [ ] 外国人登録証、パスポートの写し
- [ ] 現在のビザの写しおよび資格証明書

### 情状酌量資料
- [ ] **反省文・理由書**(韓国語で作成し、出入国の視点から論理的に)
- [ ] **在職証明書 + 四大保険の加入内訳**(韓国への貢献度の立証)
- [ ] **納税内訳**(韓国社会への貢献の証明)
- [ ] **家族関係証明書 + 子の出生証明書**(韓国に家族がいること)
- [ ] **ボランティア活動証明書**(韓国社会への統合)
- [ ] **韓国語能力試験(TOPIK)の成績表**(定着の意思)
- [ ] **事故の示談書、被害者の処罰不願書**(事故があった場合)
- [ ] **職場の上司または同僚の嘆願書**(韓国語で)
- [ ] **禁酒の意思を示す証明書**(アルコール治療プログラムへの参加など)

### 事犯審査に出席する際の注意点
- スーツまたは端正な服装
- 韓国語が難しい場合は行政書士または通訳者の同行(出入国事務所への事前申請が必要)
- 回答は短く明確に、言い訳をしない
- 反省と再発防止の意思を明確に表現する

## 4. 情状酌量資料が結果をどう変えるか

サンシャイン行政書士事務所が取り扱った実際の事例を二件、比較します。

### 事例A：資料が不十分 → 強制退去
- 30代男性、F-5-1 永住権保持者
- BAC 0.12%、無事故
- 刑事罰金500万ウォン
- 事犯審査の出席時、情状酌量資料がほとんどなし
- **結果：強制退去 + 5年の入国禁止**

### 事例B：資料が充分 → 資格維持
- 30代男性、F-5-1 永住権保持者
- BAC 0.13%、無事故
- 刑事罰金700万ウォン(事例Aより高額)
- 事犯審査の出席時：
  - 韓国居住12年、韓国人配偶者、子ども2人
  - 韓国企業の役員、年俸8,000万ウォン
  - ボランティア活動5年の記録
  - アルコール治療プログラムへの参加
  - 会社代表の嘆願書 + 韓国人配偶者の嘆願書
- **結果：永住権の維持 + 出国命令 → 保護観察処分に緩和**

差はBACではありません。**準備された資料の差**です。

## 5. 行政書士が同行すると何が違うのか

[サンシャイン行政書士事務所](/ja)が実際に事犯審査へ同行する際の違いです。

### (1) 事前シミュレーション
出入国職員がよく尋ねる質問を準備し、依頼者の回答を整えます。「なぜ飲酒運転をしたのですか」という質問に「一杯しか飲んでいません」と答えると、かえって危険です。

### (2) 書類のパッキングと強調点の整理
情状酌量資料を単に提出するのではなく、出入国職員が要点を把握しやすいよう、要約表紙とインデックスを作成します。

### (3) 同行しての発言
依頼者が韓国語で十分に表現できない部分、出入国行政手続きの観点から追加説明が必要な部分を行政書士が補います。

### (4) その後の戦略
事犯審査の結果が出たら、異議申し立て(強制退去命令は命令書を受け取った日から7日以内、出入国管理法第60条第1項)、資格変更申請、自主出国の時期調整などを直ちに開始します。

## 6. よくある誤解5つ

**誤解1：「罰金を全部払ったので安全です」**
→ 刑事と行政は別です。事犯審査はあらためて始まります。

**誤解2：「初犯だから大目に見てもらえます」**
→ 血中アルコール濃度が高い場合や事故を伴う場合などは、初犯でも強制退去が検討されることがあります。

**誤解3：「韓国人と結婚しているので強制退去にはなりません」**
→ F-6 結婚移民ビザでも、飲酒運転で処罰されれば事犯審査の対象です。ただし家族がいるという事実は情状酌量の要素になります。

**誤解4：「刑事事件が終わったので終わりです」**
→ 刑事事件が終わっても、出入国事犯審査は別の行政手続きであり、行政書士の領域です。

**誤解5：「自分で出席しても同じです」**
→ 情状資料をどう整理して提出するかは重要です。出入国の視点で整理された資料は、事情を伝えるうえで役立つことがあります。

## 7. 今すぐすべきこと

飲酒運転で摘発されたなら、刑事手続きが進行中であっても**事犯審査への備えを先に始めるべきです。** 刑事処罰が終わってから始めると、出席日までの時間が足りない場合が多くあります。
