韓国で飲酒運転により摘発された外国人が最初に聞く言葉は二つあります。**「刑事処罰は終わりました」**、そして**「出入国からもう一度呼ばれるそうです」**。

後者がまさに出入国事犯審査です。刑事手続きが罰金刑で終わっていても、出入国・外国人庁は別の行政手続きとして、ビザ延長の拒否、出国命令、強制退去を決定することができます。

この記事では、飲酒運転の摘発直後に外国人が知っておくべき事犯審査のすべてを整理します。

## 1. 飲酒運転の摘発 → 刑事処罰 → 事犯審査

### 第1段階：取締り現場
- 血中アルコール濃度(BAC)の測定 → 呼気検査を拒否すると即座に処罰が加重
- 免許停止または取消の通知

### 第2段階：刑事処罰
- 検察送致 → 略式命令(罰金)または正式裁判
- BAC と事故の有無によって処罰が決定

### 第3段階：事犯審査の通知
- 刑事処罰の終了後、出入国事務所から通知
- ビザ延長の時点で自動的に始まる場合と、別途出席を求められる場合がある

### 第4段階：事犯審査の結果
- 在留許可 / 資格変更 / 出国命令 / 強制退去 / 入国禁止

## 2. 血中アルコール濃度(BAC)別の処分見通し

| BAC 数値 | 刑事処罰(道路交通法) | 出入国事犯審査の見通し |
|---|---|---|
| 0.03 ~ 0.08% | 罰金 ~500万ウォン、免許停止100日 | ビザ延長が条件付きで可能(情状酌量資料が必須) |
| 0.08 ~ 0.2% | 1~2年の懲役または500~1,000万ウォンの罰金、免許取消 | 出国命令の可能性が高い、強制退去も検討 |
| 0.2% 以上 | 2~5年の懲役、免許取消 | 強制退去の可能性が非常に高い |
| 測定拒否 | 1~5年の懲役または500万~2,000万ウォンの罰金 | 強制退去が事実上確定的 |
| 事故を伴う場合 | 上記の処罰 + 加重(特定犯罪加重処罰法など) | 強制退去 + 永久入国禁止の可能性 |

⚠️ 上の表は一般的な傾向であり、情状酌量資料(家族、職場、韓国への貢献度)によって結果は大きく変わり得ます。

## 3. 事犯審査の出席前チェックリスト

### 必須書類
- [ ] 刑事処罰の結果通知書(略式命令書または判決文)
- [ ] 飲酒運転の取締り報告書
- [ ] 外国人登録証、パスポートの写し
- [ ] 現在のビザの写しおよび資格証明書

### 情状酌量資料(★ 決定的な差を生む資料)
- [ ] **反省文・理由書**(韓国語で作成し、出入国の視点から論理的に)
- [ ] **在職証明書 + 四大保険の加入内訳**(韓国への貢献度の立証)
- [ ] **納税内訳**(韓国社会への貢献の証明)
- [ ] **家族関係証明書 + 子の出生証明書**(韓国に家族がいること)
- [ ] **ボランティア活動証明書**(韓国社会への統合)
- [ ] **韓国語能力試験(TOPIK)の成績表**(定着の意思)
- [ ] **事故の示談書、被害者の処罰不願書**(事故があった場合)
- [ ] **職場の上司または同僚の嘆願書**(韓国語で)
- [ ] **禁酒の意思を示す証明書**(アルコール治療プログラムへの参加など)

### 事犯審査に出席する際の注意点
- スーツまたは端正な服装
- 韓国語が難しい場合は行政書士または通訳者の同行(出入国事務所への事前申請が必要)
- 回答は短く明確に、言い訳をしない
- 反省と再発防止の意思を明確に表現する

## 4. 情状酌量資料が結果をどう変えるか

VISION行政書士事務所が取り扱った実際の事例を二件、比較します。

### 事例A：資料が不十分 → 強制退去
- 30代男性、F-5-1 永住権保持者
- BAC 0.12%、無事故
- 刑事罰金500万ウォン
- 事犯審査の出席時、情状酌量資料がほとんどなし
- **結果：強制退去 + 5年の入国禁止**

### 事例B：資料が充分 → 資格維持
- 30代男性、F-5-1 永住権保持者
- BAC 0.13%、無事故
- 刑事罰金700万ウォン(事例Aより高額)
- 事犯審査の出席時：
  - 韓国居住12年、韓国人配偶者、子ども2人
  - 韓国企業の役員、年俸8,000万ウォン
  - ボランティア活動5年の記録
  - アルコール治療プログラムへの参加
  - 会社代表の嘆願書 + 韓国人配偶者の嘆願書
- **結果：永住権の維持 + 出国命令 → 保護観察処分に緩和**

差はBACではありません。**準備された資料の差**です。

## 5. 行政書士が同行すると何が違うのか

[VISION行政書士事務所](/ja)が実際に事犯審査へ同行する際の違いです。

### (1) 事前シミュレーション
出入国職員がよく尋ねる30の質問を準備し、依頼者の回答を整えます。「なぜ飲酒運転をしたのですか」という質問に「一杯しか飲んでいません」と答えると、かえって危険です。

### (2) 書類のパッキングと強調点の整理
情状酌量資料を単に提出するのではなく、出入国職員が5分以内に要点を把握できるよう、要約表紙とインデックスを作成します。

### (3) 同行しての発言
依頼者が韓国語で十分に表現できない部分、出入国行政手続きの観点から追加説明が必要な部分を行政書士が補います。

### (4) その後の戦略
事犯審査の結果が出た後、30日以内の異議申し立て、資格変更申請、自主出国の時期調整などを直ちに開始します。

## 6. よくある誤解5つ

**誤解1：「罰金を全部払ったので安全です」**
→ 刑事と行政は別です。事犯審査はあらためて始まります。

**誤解2：「初犯だから大目に見てもらえます」**
→ BAC 0.2% 以上、または事故を伴う場合は初犯でも強制退去があり得ます。

**誤解3：「韓国人と結婚しているので強制退去にはなりません」**
→ F-6 結婚移民ビザでも、飲酒運転で処罰されれば事犯審査の対象です。ただし家族がいるという事実は情状酌量の要素になります。

**誤解4：「弁護士が刑事事件を終わらせたので終わりです」**
→ 弁護士は刑事弁護の専門です。出入国事犯審査は行政手続きであり、行政書士の領域です。

**誤解5：「自分で出席しても同じです」**
→ 結果の30~50%は情状酌量資料の質に左右されます。一人で準備した資料と行政書士が整理した資料では、説得力に大きな差があります。

## 7. 今すぐすべきこと

飲酒運転で摘発されたなら、刑事手続きが進行中であっても**事犯審査への備えを先に始めるべきです。** 刑事処罰が終わってから始めると、出席日までの時間が足りない場合が多くあります。
