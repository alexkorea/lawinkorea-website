ビザの満了日をうっかり忘れた、更新書類の準備が間に合わず期限を過ぎてしまった、というケースは意外と多いです。まず気になるのは「いくら払うのか」と「韓国にとどまれるのか」ではないでしょうか。この記事では、在留期間を超えた場合の犯則金の基準とその後の手続きを、条文の順に整理しました。

## 要点

- 外国人は在留資格と在留期間の範囲内でのみ滞在でき（第17条第1項）、さらに滞在するには**在留期間が終わる前に**更新許可を受ける必要があります（第25条第1項）。
- 更新許可なく期間を超えて滞在を続けると、3年以下の懲役または3,000万ウォン以下の罰金の対象です（第94条第17号）。
- 実務では、調査のうえ罰金に相当する**犯則金**の納付を通告する場合が多く、基準額は超過期間に応じて50万ウォンから3,000万ウォンまでです（施行規則 別表7）。
- 犯則金を納めた後も、強制退去・出国命令・今後の在留審査には別に注意が必要です。

## 1. 在留期間が終わるとどの条文が適用されますか？

ポイントは2つの条文です。第25条第1項は、在留期間を超えて滞在するには**期間が終わる前に**法務部長官の更新許可を受けるよう定めています。施行令第31条第1項も、更新申請を在留期間の満了前に行うよう求めています。この義務に違反し、更新許可なく期間を超えて滞在を続けた人は、第94条第17号により3年以下の懲役または3,000万ウォン以下の罰金に処される可能性があります。

期限を過ぎると「更新」ではなくすでに違反の状態になるため、後から書類を出しても違反の事実は残ります。期限を過ぎたことに気づいたら、できるだけ早く管轄の出入国・外国人官署に状況を確認してください。

## 2. 犯則金はいくらですか？

出入国事犯の事件で、調査の結果、犯罪の確証を得たときは、官署の長が罰金に相当する金額、すなわち犯則金を書面で通告できます（第102条第1項）。基準額は、施行規則[別表7]が超過期間別に定めています。

| 超過期間 | 犯則金の基準額 |
|---|---|
| 1か月未満 | 50万ウォン |
| 1か月以上3か月未満 | 100万ウォン |
| 3か月以上6か月未満 | 200万ウォン |
| 6か月以上1年未満 | 500万ウォン |
| 1年以上2年未満 | 1,000万ウォン |
| 2年以上3年未満 | 1,500万ウォン |
| 3年以上5年未満 | 2,000万ウォン |
| 5年以上7年未満 | 2,500万ウォン |
| 7年以上 | 3,000万ウォン |

これは**基準額**です。官署の長は、年齢と環境、違反の動機と結果、犯則金の負担能力、違反回数などを考慮し、基準額の2分の1の範囲で減軽・加重できます（施行規則第86条第2項）。法務部長官も、同様の事情を考慮して通告処分そのものを免除することができます（第103条第2項）。そのため、満了日の翌日から実際に出国した日（または許可を受けた日）までの期間を正確に整理することが大切です。

## 3. 通告書を受け取ったらどうなりますか？

通告書を受け取った日から15日以内に犯則金を納めなければなりません（第105条第1項）。期間内に納めなければ官署の長が告発しなければならず、告発前に納めれば告発されません（同条第2項）。通告どおり納めれば、同じ事件で再び処罰されることはありません（第106条）。

逆に、調査の結果、犯情が禁錮以上の刑に当たると認められれば、通告処分なしにすぐ告発されることもあります（第102条第3項）。出入国事犯の事件は、出入国・外国人官署の長の告発がなければ公訴を提起できません（第101条第1項）。

## 4. 犯則金を納めれば終わりですか？

いいえ。刑事面の犯則金と、在留に関する行政手続きは別々に進みます。

- **強制退去事由**：第25条違反は、第46条第1項第8号の強制退去対象事由に含まれます。永住資格者は原則として強制退去されませんが、例外があります（第46条第2項）。
- **出国命令**：第46条第1項に該当すると認められる場合でも、自費で自ら出国しようとする人には出国命令ができます（第68条第1項第1号）。通告処分後に出国措置が妥当な場合は同項第5号です。自主出国のメリットとデメリットは[外国人の自主出国ガイド](/ja/blog/foreigner-voluntary-departure-2026)に整理しています。
- **滞在を続けられるか**：超過期間、違反の経緯、家族や就労の事情などを総合して官署が判断します。同じ超過期間でも結果が異なることがあります。

## 5. 今後の在留審査にどう影響しますか？

法務部の在留案内マニュアル（2026年9月）には、犯則金の履歴や不法残留の期間が後の審査に反映される部分があります。

- 求職（D-10）の制限対象：出入国管理法違反で犯則金を受けた人のうち、「在留許可制限統合基準」により制限される人。例として、初犯は500万ウォン以上、再犯は直近3年の合算700万ウォン以上が記載されています。
- その他長期（F-2-99）への変更：滞在期間の算定から不法残留（第25条違反）や不法就労（第18条違反）の期間を除き、在留資格変更の抑制対象にも不法残留者が含まれます。

資格ごとに基準が違うため、今後、更新・変更・永住の申請を考えているなら、まず犯則金の金額と日付を整理しておくと安心です。

## 6. 期限を過ぎたと気づいたときの手順

1. **まず日付を確認します。**許可された在留期間の満了日と、実際に出国した（または予定の）日を書き出してください。犯則金の区分はこの期間で決まります。
2. **管轄の出入国・外国人官署に状況を問い合わせます。**滞在を続けられる事情があるのか、出国が必要かによって方向が変わります。
3. **出頭要求書・通告書を受けたら期限を守ります。**出頭要求書には趣旨と日時・場所が書かれ（施行令第58条）、通告書は受け取った日から15日が目安です。
4. **事情を整理して疎明資料を準備します。**入院や書類の遅れなど遅れた理由と証拠、家族・就労の事情を事実どおりにまとめると説明が明確になります。事実と異なる内容はかえって不利になりかねません。

## 7. 行政士にお任せいただけること

在留に関する申請書類の作成と提出代行、違反の経緯を説明する疎明書・意見書の作成、証拠資料の整理と翻訳をお手伝いします。告発後の捜査・刑事裁判での弁護は行政士の業務範囲外のため、お受けしていません。

すでに期間を過ぎている場合、時間がたつほど基準額の区分が上がる可能性があります。通告書や出頭要求書を受け取ったら、まず記載された日付を確認し、残りの期限と疎明資料を一緒に点検してみてください。
