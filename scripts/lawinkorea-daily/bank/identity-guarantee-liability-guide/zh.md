给朋友、家人或员工签了身份保证书之后，很多人才回头琢磨："我到底担了什么责任？"先说结论：保证人责任的核心，是外国人在韩国居留、被保护和出境所需要的费用。法律规定可以让保证人承担这些费用的全部或一部分，保证人不履行、国库因此垫付时，国家还可以向保证人行使追偿权。

## 核心要点

- 保证书的保证内容有三项：使外国人在居留期间遵守法规，承担出境旅费及相关费用，承担居留或保护期间产生的费用。
- 保证期限最长4年，各类许可的期限不能超过保证期限。
- 保证人不履行责任而使国库负担时，会被追偿；视情况还可以要求每名外国人预先缴存300万韩元以下的保证金（截至2026年10月，第90条第4款）。
- 撤回保证的程序没有找到明确规定，法律中只有"撤回后外国人的许可可能被取消或变更"这一点。

## 签字时到底承诺了什么

法务部身份保证书表格中的保证内容只有三行。使其在居留期间遵守各项法规；承担出境旅费及相关费用的支付责任；承担居留或保护期间产生费用的支付责任。下面还有一句："上述保证人确认被保证外国人在大韩民国居留期间其身份无异常，并保证以上事项。"

这里常见一个误解：以为外国人无论出什么事，自己都要无限承担。表格和法律中写明的范围，是与居留·保护·出境有关的费用。反过来，把它当成"只是借个名字的文件"也很危险，因为费用责任真的可能被追讨。

钱怎么走也要了解。保证人不履行而使国库负担时，法务部长官可以对保证人行使追偿权。追偿通知以书面形式送达，写明追偿金额的计算依据，自收到通知之日起15日内必须缴纳。

如果担心保证人不会承担费用，或仅凭保证无法达到保证目的，可以要求保证人对每名外国人缴存300万韩元以下的保证金（截至2026年10月，第90条第4款）。保证人不履行时，保证金用于居留·保护·出境费用；保证人履行了责任或认定保证目的已达成时，保证金会返还。

## 保证期限最长可以写几年

保证期限最长为4年。表格上有同样的文字，填写示例是从申请日起最长到4年。写5年、10年也只认4年。

期限还与居留期限挂钩。发放各类许可时，许可期限不能超过保证书的保证期限。所以保证期限写得短，外国人拿到的居留期限就可能变短。法务部指南写明：K-point E74一次最长可给2年居留，但保证期限短于2年就拿不到2年，即使雇佣合同是2年也一样。

另一方面，在保证期限内延长居留时，不需要再次提交保证书。保证期限已经过了的话，有的情况需要重新提交。邀请结婚移民者父母等家人的部分签证，还规定保证期限为自入境之日起3年。

所以写几年，是比看上去更重要的选择。时间越长对外国人越有利，但保证人被绑定的时间也越长。

## 哪些居留情形会要求身份保证书

并不是所有居留资格都要求。法律规定，在签证发放、居留许可、外国人保护等事项上认为有必要时，可以要求保证。法务部指南中比较典型的情形如下。

| 情形 | 与身份保证书有关的内容 |
|---|---|
| 以结婚同居为目的的签证 | 作为配偶的邀请人成为被邀请人的身份保证人 |
| 永住(F-5)资格者的配偶居住(F-2-3)签证 | 国内配偶的身份保证书 |
| 韩国公民未成年外国子女变更为居住(F-2-2) | 拥有抚养权的父或母的身份保证书 |
| 申请永住 | 提交身份保证书(部分永住资格免除) |
| 因探亲入境者的居留延期 | 年满20岁者提交身份保证书 |
| 非专业就业积分制(E-7-4) | 雇主为身份保证人 |
| 艺术演出(E-6)中的E-6-2 | 仅此资格收取身份保证书 |

以上只是典型情形。即使资格相同，也会因申请类型不同而免除，指南还注明出入境机关审查时可增减材料。签字之前，先问清楚自己是为哪一项申请做保证。

## 谁可以当保证人，哪些情况不行

基本资格是这样的：在大韩民国国内有住址，并需说明自己有保证能力。外国人当保证人时，必须持有外国人登录证(외국인등록증)，保证期限不能超过该保证人自己的居留期限。被保证的外国人有所属机关或团体时，除特殊原因外由该机关·团体的负责人担任保证人，这种情况下不需要另行说明保证能力。政府机关担任保证人等情形，也可以免于提交保证书。

至于"绝对不能当保证人的人"，在法令中没有找到禁止名单。不过确有限制资格的规定。

- 以申请日为基准，最近1年内有未履行保证责任的事实，可以在1年范围内限制保证人资格。
- 所属机关·团体·企业的负责人担任保证人，最近1年内有3次以上未履行保证责任的，同样属于限制对象。

住址和保证能力都是需要说明的内容，签字之前先想好用什么材料来证明。

## 想不再保证，或情况发生变化

被问得最多的就是：怎么撤回？老实说，撤回的方法或表格，我在法令和法务部指南中没有找到规定。与其自己随便写份文件，不如先向管辖的出入境·外国人机关咨询。

法律中能看到的是撤回的效果。保证人撤回保证或没有保证人时，法务部长官可以取消或变更外国人的签证发放、居留许可等。也就是说，撤回可能直接影响外国人的居留。撤回后已经产生的费用责任如何处理，我没找到相关记载，所以不下定论。

更换保证人是有规定的。作为韩国公民的保证人以在外国永住为目的出境时，被保证的外国人必须重新设定保证人；外国人保证人出境时也一样。如果你正打算移居或离开，请提前和外国人谈好这件事。

## 签字前要核对的事项

1. 弄清是谁的什么申请。签证、延期、申请永住，保证期限可能不同。
2. 自己决定保证期限。不能超过4年，写得短，许可期限也可能变短。
3. 准备能说明住址和保证能力的材料。
4. 想一想自己是否打算出境或移居国外。那种情况需要新的保证人。
5. 保留一份复印件。收到追偿通知或出席要求时，可以立刻核对期限和内容。
