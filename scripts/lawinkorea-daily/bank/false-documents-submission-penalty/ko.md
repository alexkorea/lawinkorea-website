체류기간을 연장하거나 자격을 바꿀 때 서류가 부족하면 마음이 급해져요. 이럴 때 "일단 비슷하게 만들어서 내면 되겠지" 하는 유혹이 생기지만, 위조·변조 서류나 거짓 신청서는 출입국관리법이 따로 금지하고 처벌하는 행위입니다. 이 글에서는 제26조의 내용과 처벌, 단순한 잘못 적음과의 차이를 조문대로 정리했어요.

## 핵심 요약

- 체류자격 외 활동, 근무처 변경·추가, 체류자격 부여·변경, 체류기간 연장 등의 허가 신청에서 **위조·변조 문서**를 내거나 **거짓 사실이 적힌 신청서**를 내는 등 부정한 방법으로 신청해서는 안 돼요(제26조 제1호).
- 그런 신청을 **알선·권유**하는 것도 금지돼요(제26조 제2호).
- 위반하면 3년 이하 징역 또는 3천만원 이하 벌금 대상이고(제94조 제17호의2), 외국인은 강제퇴거 사유에도 해당해요(제46조 제1항 제10호의2).
- 범칙금 기준액은 위반 횟수나 알선 인원이 늘수록 올라가요.

## 1. 어떤 허가 신청이 대상인가요?

제26조는 제20조, 제21조, 제23조부터 제25조까지, 제25조의2·제25조의3·제25조의4에 따른 **허가 신청**과 관련한 행위를 대상으로 해요. 쉽게 말해 체류자격 외 활동허가, 근무처 변경·추가허가, 체류자격 부여, 체류자격 변경허가, 체류기간 연장허가 신청 등이에요. 금지되는 행위는 두 가지입니다.

- 위조·변조된 문서 등을 입증자료로 제출하거나 거짓 사실이 적힌 신청서 등을 제출하는 등 **부정한 방법으로 신청**하는 행위
- 위 행위를 **알선·권유**하는 행위

## 2. 처벌과 범칙금 기준

제94조 제17호의2는 제26조를 어긴 사람을 3년 이하 징역 또는 3천만원 이하 벌금에 처한다고 정해요. 관서장의 고발이 있어야 공소를 제기할 수 있고(제101조 제1항), 관서장은 범죄의 확증을 얻으면 벌금에 상당하는 범칙금을 통고할 수 있어요(제102조 제1항). 시행규칙 [별표 7]의 기준액은 다음과 같아요.

| 구분 | 횟수·인원 | 범칙금 기준액 |
|---|---|---|
| 직접 신청(제1호) | 1회 | 500만원 |
| | 2회 | 1,000만원 |
| | 3회 | 2,000만원 |
| | 4회 이상 | 3,000만원 |
| 알선·권유(제2호) | 1명 | 1,000만원 |
| | 2~4명 | 1,500만원 |
| | 5~9명 | 2,000만원 |
| | 10~19명 | 2,500만원 |
| | 20명 이상 | 3,000만원 |

기준액은 나이와 환경, 위반 동기와 결과, 부담능력을 참작해 2분의 1 범위에서 줄이거나 늘릴 수 있어요(시행규칙 제86조 제2항). 통고서는 15일 안에 내야 하고(제105조 제1항), 낸 뒤에는 같은 사건으로 다시 처벌받지 않아요(제106조).

## 3. 외국인에게 미치는 영향

제46조 제1항 제10호의2는 제26조를 위반한 외국인을 강제퇴거 대상으로 정해요. 영주 자격자는 법에 정한 예외 사유가 아니면 강제퇴거되지 않아요(제46조 제2항). 이미 받은 체류허가가 있다면 [체류허가 취소 대응 가이드](/ko/blog/foreigner-visa-cancellation-response)도 함께 확인하세요. 자기 비용으로 자진 출국하려는 사람에게는 출국명령을 할 수 있어요(제68조 제1항 제1호).

## 4. 단순한 잘못 적음과는 어떻게 다른가요?

제100조 제3항 제2호는 이 법에 따른 각종 신청이나 신고에서 **거짓 사실을 적거나 보고한 사람**에게 50만원 이하 과태료를 부과한다고 정해요. 단 제94조 제17호의2에 해당하는 사람은 제외돼요. 시행령 [별표 2]의 기준액은 1회 30만원, 2회 40만원, 3회 이상 50만원이에요. 어느 규정이 적용될지는 위조·변조 문서를 냈는지, 부정한 방법으로 신청한 것인지 등 사실관계에 따라 달라지니 단정할 수 없어요. 조사를 받게 되면 [사범심사 가이드](/ko/blog/immigration-offense-review-guide)처럼 경위와 자료를 먼저 정리하세요.

## 5. 서류에 문제가 생겼을 때의 순서

1. **문제가 된 서류를 확인해요.** 어떤 신청에, 어떤 서류를, 누구에게서 받아 냈는지 정리하세요.
2. **제출 전이라면 사실대로 다시 준비해요.** 서류를 구할 수 없으면 관할 관서에 대체 방법을 문의하세요.
3. **이미 제출했다면 관서에 정정 방법을 확인해요.** 자진해서 바로잡은 경위는 이후 설명에 도움이 될 수 있어요.
4. **출석요구서·통고서를 받으면 기한부터 확인해요.** 통고서는 받은 날부터 15일이에요.
5. **소명 자료를 정리해요.** 경위, 반성의 내용, 재발 방지 계획을 서면으로 정리하면 [반성문 작성 가이드](/ko/blog/reflection-letter-guide)가 도움이 돼요.

## 6. 선샤인행정사사무소가 도와드릴 수 있는 일

신청서와 증빙 서류의 사실관계 점검, 정정 절차 안내, 위반 경위를 설명하는 소명서·의견서 작성, 외국어 서류 번역을 도와드려요. 고발 이후의 수사·형사재판 변호는 행정사 업무 범위 밖이라 맡지 않습니다.

서류에 문제가 있다는 것을 알았다면 제출하기 전에, 이미 냈다면 하루라도 빨리 점검을 시작하세요.
