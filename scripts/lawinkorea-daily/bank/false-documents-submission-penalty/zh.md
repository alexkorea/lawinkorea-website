延长居留期间或变更资格时，如果材料不够，人难免着急。这时容易产生“先做一份差不多的交上去”的念头，但伪造、变造材料或虚假申请书，是出入境管理法另行禁止并处罚的行为。这篇文章按条文整理第26条的内容、处罚以及与单纯填错的区别。

## 要点

- 在资格外活动、变更·增加工作单位、居留资格赋予·变更、居留期间延长等许可申请中，不得以提交**伪造·变造文件**或**写有虚假事实的申请书**等不正当方法申请（第26条第1项）。
- **介绍·劝诱**此类申请也被禁止（第26条第2项）。
- 违反者可处3年以下徒刑或3000万韩元以下罚金（第94条第17项之2），对外国人而言也属于强制驱逐事由（第46条第1款第10项之2）。
- 罚款基准额随违规次数或介绍人数增加而提高。

## 1. 哪些许可申请属于对象？

第26条适用于与第20条、第21条、第23条至第25条、第25条之2、之3、之4所定**许可申请**相关的行为。简单说，就是资格外活动许可、变更·增加工作单位许可、居留资格赋予、居留资格变更许可、居留期间延长许可等申请。被禁止的行为有两类。

- 以提交伪造、变造文件作为证明材料或提交写有虚假事实的申请书等**不正当方法申请**的行为
- **介绍·劝诱**上述行为

## 2. 处罚与罚款基准

第94条第17项之2规定，违反第26条的人，处3年以下徒刑或3000万韩元以下罚金。须有机关负责人告发方可起诉（第101条第1款），负责人在确认犯罪后可通告缴纳相当于罚金的罚款（第102条第1款）。施行规则[附表7]的基准额如下。

| 类别 | 次数·人数 | 罚款基准额 |
|---|---|---|
| 本人直接申请（第1项） | 第1次 | 500万韩元 |
| | 第2次 | 1000万韩元 |
| | 第3次 | 2000万韩元 |
| | 第4次以上 | 3000万韩元 |
| 介绍·劝诱（第2项） | 1人 | 1000万韩元 |
| | 2至4人 | 1500万韩元 |
| | 5至9人 | 2000万韩元 |
| | 10至19人 | 2500万韩元 |
| | 20人以上 | 3000万韩元 |

基准额可参酌年龄、环境、动机、结果和负担能力在二分之一范围内减轻或加重（施行规则第86条第2款）。通告书须在15日内缴纳（第105条第1款），缴纳后同一案件不会再被处罚（第106条）。

## 3. 对外国人的影响

第46条第1款第10项之2规定，违反第26条的外国人属于强制驱逐对象。永久居留资格者除法律规定的例外情形外不会被强制驱逐（第46条第2款）。如果已经持有居留许可，也请参考[居留许可撤销应对指南](/zh/blog/foreigner-visa-cancellation-response)。愿意自费自愿出境的人可作出出境命令（第68条第1款第1项）。

## 4. 与单纯填错有什么不同？

第100条第3款第2项规定，在依本法的各种申请或申报中填写或报告**虚假事实**的人，处50万韩元以下过怠金，但属于第94条第17项之2的人除外。施行令[附表2]的基准额为第1次30万韩元，第2次40万韩元，第3次以上50万韩元。适用哪一条取决于是否使用了伪造·变造文件、是否以不正当方法申请等事实情况，不能一概而论。如果接受调查，请先像[事犯审查指南](/zh/blog/immigration-offense-review-guide)中那样整理经过和材料。

## 5. 材料出问题时的处理顺序

1. **确认出问题的材料。** 整理是哪项申请、哪份材料、从谁那里取得。
2. **如果还没提交，请如实重新准备。** 无法取得材料时，向管辖机关询问替代方法。
3. **如果已经提交，向机关确认更正方法。** 主动纠正的经过可能有助于之后的说明。
4. **收到出席要求书·通告书，先确认期限。** 通告书自收到之日起15日。
5. **整理说明材料。** 把经过、反省内容和防止再犯的计划写成书面，[反省书写作指南](/zh/blog/reflection-letter-guide)可供参考。

## 6. 行政士事务所可以协助的事项

我们可以协助核对申请书和证明材料中的事实、指导更正程序、撰写说明违规经过的陈述书·意见书，以及翻译外文文件。告发之后的侦查·刑事审判辩护不属于行政士的业务范围，我们不承接。

如果知道材料有问题，请在提交之前开始检查；如果已经提交，请尽快开始。
