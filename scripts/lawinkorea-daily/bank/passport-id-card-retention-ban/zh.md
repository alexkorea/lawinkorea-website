有些人在开始工作时会听到"为了防止你跑掉，护照由公司保管"或者"借的钱还清之前，外国人登录证先放我这里"。出入境管理法第33条之3对任何人都禁止这种行为。下面说明哪些行为被禁止、违反会怎样，以及想取回证件应按什么顺序行动。

## 核心要点

- 任何人都不得把外国人的护照或外国人登录证作为就业合同或债务履行的担保手段收下，也不得强迫或介绍他人提供。
- 违反属于刑事处罚对象；员工因业务违反时，雇主也可能被并处罚金。
- 同一条还禁止伪造外国人登录号码使用、不正当使用他人登录证等行为。违反的外国人可能成为强制驱逐对象。
- 外国人本人有随时携带护照或外国人登录证的义务，证件被扣在别人手里，对本人也是负担。

## 1. 哪些行为被禁止？

出入境管理法规定，任何人都不得实施下列行为。

1. 将外国人的护照或外国人登录证作为就业合同或债务履行的担保手段收下，或强迫、介绍他人提供
2. 伪造外国人登录号码，为自己或他人的财物或财产利益而使用，或介绍此类行为
3. 向他人传递、散布伪造外国人登录号码或手机外国人登录证的程序，或介绍此类行为
4. 不正当使用他人的外国人登录证或手机外国人登录证，或明知自己的登录证会被不正当使用仍提供给他人，或介绍上述行为
5. 为财物或财产利益不正当使用他人的外国人登录号码，或介绍此类行为

老板扣着护照的问题，关键在于是否属于第1项。不管叫"保管"还是"管理"，只要是作为不让你离开或逼你还债的手段收下的，就属于禁止行为。由于条文写的是"任何人"，不仅是雇主，管理人员、中介、提供住宿的人也都适用。

## 2. 违反会怎样？

- 刑事处罚：截至2026年10月，违反该条的人依出入境管理法第94条可处3年以下有期徒刑或3000万韩元以下罚金。
- 两罚规定：法人代表或员工等在法人或个体经营者的业务中实施第1项行为（把护照或登录证作为担保收下）的，除处罚行为人外，对该法人或个体经营者也科以罚金。但为防止违法已尽到相当注意和监督义务的除外。
- 邀请外国人受限：因第1项行为被判刑，或缴纳了罚金、犯则金的邀请人或用工单位，可能在依处分轻重确定的期间内无法取得外国人的签证发放认定书。

雇用外国人的雇主应了解的其他处罚，请参考[非法雇用雇主处罚指南](/zh/blog/illegal-employer-penalty)。

## 3. 交出护照的外国人也会被处罚或驱逐吗？

出入境管理法第46条把违反该条的外国人列为强制驱逐对象。因此，外国人具体做了什么很重要。

- 第1项禁止的行为是把护照或登录证作为担保"收下"，以及"强迫或介绍"他人提供。按老板要求交出护照这一行为本身，并没有写在第1项的禁止行为中。
- 但如果外国人以管理人员或中介的身份收下其他外国人的护照，或强迫、介绍提供，就违反第1项。
- 明知自己的外国人登录证会被不正当使用仍借给他人，或使用他人的登录证，属于违反第4项。这种情况下，除刑事处罚外还可能成为强制驱逐对象。

还要记住，17岁以上的外国人必须随时携带护照或外国人登录证，公务员要求时必须出示。证件放在别人手里，就很难履行这项义务。关于携带和出示义务，请参考[外国人登录证携带·遗失指南](/zh/blog/foreigner-id-card-carry-lost-reissue)。

## 4. 取回方法与举报途径

1. 先明确要求归还。最好用短信、聊天软件等能留下记录的方式。
2. 收集证据。保存交出证件的日期、交出的证件种类、"辞职就不还""还了钱就给你"之类的话，以及劳动合同和工资记录。
3. 可以向出入境·外国人管理机关举报。根据出入境管理法，任何人发现涉嫌违反该法的人，都可以向出入境管理公务员举报。
4. 如果是非专业就业（E-9）劳工，也确认能否变更工作单位。因雇主违反劳动条件或不当对待等非劳工责任的原因，被雇佣劳动部长官公告认定为难以继续工作的情形，可以申请变更工作单位。申请在雇佣劳动部就业中心办理，之后还需在出入境·外国人管理机关取得工作单位变更许可。是否符合条件，请向就业中心确认。未经许可更换工作单位的风险，请参考[工作单位变更许可违规指南](/zh/blog/workplace-change-without-permission-penalty)。
