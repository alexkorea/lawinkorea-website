永住資格（F-5）を持つ外国人が刑事事件に関わると、まず「永住者でも追放されるのか」という質問が出てきます。出入国管理法第46条は、永住資格を持つ人を原則として強制退去から守り、いくつかの重い場合にだけ例外を設けています。これとは別に永住資格そのものを取り消す制度もあるため、二つを分けて考えることが大切です。永住権を **申請するとき** に犯罪歴がどう考慮されるかは [刑事記録と永住権・国籍取得](/ja/blog/criminal-record-pr-impact) で扱っており、ここではすでに永住資格を持っている人について見ていきます。

## 要点

- 永住資格を持つ人は、一般の外国人の強制退去事由にあたっても **原則として強制退去されません**。
- 例外は **内乱・外患の罪**、**5年以上の懲役・禁錮の後に釈放された人のうち法務部令で定める人**、**不法出入国の幇助・不法入国者の隠匿など** の三つです。
- **永住資格の取消し** は強制退去とは別の処分で、取り消されると出国命令の対象になります。ただし申請により一般在留資格を受けられることがあります。

## 1. 原則 — 永住者は強制退去されません

一般の外国人は、資格外活動、外国人登録義務違反、禁錮以上の刑を言い渡されて釈放された場合など、さまざまな事由で強制退去の対象になり得ます。しかし永住資格を持つ人は、これらの事由にあたっても韓国の外へ強制退去されないのが原則です。永住資格を持つ外国人は、活動範囲と在留期間の制限も受けません。

## 2. 例外 — 永住者でも強制退去される三つの場合

1. **刑法上の内乱の罪または外患の罪を犯した人**
2. **5年以上の懲役または禁錮の刑を言い渡されて釈放された人のうち、法務部令で定める人**
3. **不法出入国を助けた人** — 外国人を不法に入国・出国させ、または韓国を経由して他国へ不法入国させる目的で、船舶等や旅券・査証・搭乗券などの書類・物品を提供し、またはあっせんした人、不法入国した外国人を隠匿・逃避させ、またはその目的で交通手段を提供・あっせんした人、そしてこれらを教唆・幇助した人

2号の「法務部令で定める人」とは、次の罪を犯した人で、**法務部長官が強制退去させることが相当と認める人** です。

- 刑法上の殺人の罪、強姦と強制わいせつの罪、強盗の罪
- 性暴力犯罪の処罰等に関する特例法違反
- 麻薬類管理に関する法律違反
- 特定犯罪加重処罰等に関する法律の一部の条項違反
- 国家保安法違反
- 暴力行為等処罰に関する法律のうち犯罪団体等の構成・活動に関する条項違反
- 保健犯罪取締に関する特別措置法違反

つまり「5年以上の刑 + 釈放 + 列挙された罪 + 法務部長官の相当性の判断」がすべてそろう必要があります。5年以上の刑を受けたという事実だけで、ただちに強制退去の対象になるわけではありません。

## 3. 永住資格の取消し — 強制退去とは別の処分

出入国管理法第89条の2は、次の場合に限って永住資格を取り消すことができると定めています。

1. 偽りその他不正な方法で永住資格を取得した場合（この場合は **必ず取り消し**）
2. 刑法、性暴力処罰法、児童・青少年性保護法、特定犯罪加重処罰法、特定経済犯罪加重処罰法、麻薬類管理法、暴力行為処罰法、保健犯罪取締法に定める罪で **2年以上の懲役・禁錮の刑が確定** した場合
3. 最近5年以内に法律違反で懲役・禁錮の刑を言い渡され、確定した **刑期の合計が3年以上** の場合
4. 一定額以上の投資の維持などを条件に永住資格を受けた人がその条件に違反した場合
5. 国家安全保障、外交関係、国民経済などにおいて韓国の国益に反する行為をした場合

韓国の出入国実務指針は、上の2の強制退去の例外事由にあたる場合も永住資格の取消事由としてあわせて案内しています。

取り消そうとするときは本人を出頭させて意見を聴くことができ、その場合は取消事由と出頭の日時・場所を **出頭日の7日前まで** に知らせなければなりません。取り消されても、**韓国に引き続き在留する必要性が認められ、一般在留資格の要件を備えた人が申請** すれば、一般在留資格を受けられることがあります。一般在留資格を受けられなければ、出国命令の対象になります。また、取り消されると「永住資格を持つ人」ではなくなるため、1の強制退去の保護も受けられなくなります。

## 4. 出国命令・強制退去と再入国

- **出国命令** — 出国期限が定められ、住居の制限などの条件が付くことがあります。期限までに出国しないか条件に違反すると、直ちに強制退去命令書が発付されます。
- **強制退去命令** — 命令書を受け取った日から **7日以内** に、地方出入国・外国人官署の長を経て法務部長官に異議を申し立てられます。保護と異議申立ての手続は [保護された外国人の異議申立てガイド](/ja/blog/immigration-detention-objection-guide) をご覧ください。
- **再入国** — 強制退去命令を受けて出国した後 **5年を経過していない人** は、入国を禁止されることがあります。解除の手続は [入国禁止の解除申請](/ja/blog/entry-ban-removal) でご確認ください。

## 5. 刑事手続中の永住者が確認すべきこと

1. **言い渡された刑と罪名を正確に確認します。** 強制退去の例外は「5年以上」、永住資格の取消しは「2年以上の確定」または「5年以内の合計3年以上」と基準が異なります。判決文の罪名と刑をもとに確認してください。
2. **永住証の有効期間と再入国期間を管理します。** 永住証の有効期間は10年で、実務指針上、再入国免除期間（出国した日から2年以内）または再入国許可期間までに入国しなければ永住資格を失います。
3. **意見聴取の通知を受けたらすぐに準備します。** 通知は出頭日の7日前に届くこともあり、時間が短いです。韓国内の家族関係、生活・経済基盤、在留を続ける必要がある事情を資料にまとめましょう。
4. **一般在留資格の要件を事前に確認します。** 取り消された場合に申請できる在留資格があるか、要件の資料をそろえられるかを点検しておきましょう。

## 6. 行政書士事務所がお手伝いできること

永住資格取消しの意見聴取に提出する疎明書・意見書の作成、家族関係・生活基盤の証明資料の整理と翻訳、一般在留資格の申請書類の準備、強制退去命令に対する異議申立書の作成をお手伝いします。刑事事件の捜査・裁判での弁護や訴訟代理は行政士の業務範囲外のため、お受けしていません。

意見聴取の通知は出頭日の7日前までに届けばよく、強制退去命令に対する異議申立ての期限は7日です。判決文や通知書を受け取った日付からまず整理しておきましょう。
