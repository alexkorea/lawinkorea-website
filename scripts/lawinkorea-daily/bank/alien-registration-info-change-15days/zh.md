换了新护照，或者更换了学校、公司，外国人登录证上的信息就和实际情况不一致了。这时如果没有在15日内办理变更申报，就可能被处以过怠金。它与搬家时办理的居住地变更申报是不同的义务，所以很容易漏掉。这篇文章整理变更申报的对象、方法以及逾期的过怠金。

## 要点

- 已办理外国人登录的外国人，登录事项发生变更时，须在**15日内**向居住地管辖机关申报变更（第35条）。
- 对象包括①姓名、性别、出生日期、国籍，②护照号码、签发日期、有效期，③法务部令规定的事项。
- 违反者可处100万韩元以下过怠金（截至2026年10月，第100条第2款第1项）。
- 搬家时的居住地变更申报（第36条）是另一项义务，请一并参考[居住地变更申报指南](/zh/blog/residence-change-report-fine)。

## 1. 哪些变更需要申报？

第35条规定的申报对象如下。

1. 姓名、性别、出生日期及国籍
2. 护照号码、签发日期及有效期
3. 法务部令规定的事项

施行规则第49条之2将下列事项列为第3项的内容。

- 文化艺术（D-1）、留学（D-2）以及一般研修（D-4）至贸易经营（D-9）资格者的**所属机构·团体的变更（含名称变更）或增加**
- 在学与否的变更
- 求职（D-10）资格者的研修开始事实或研修机构的变更
- 访问就业（H-2）资格者的首次就业开始，或所受雇的个人·企业的变更
- 职业或年收入金额的变更（仅限相关资格者）

例如领取了新护照、留学生转学，或所属公司更名，都可能属于这类。这与工作单位变更·增加的许可或申报（第21条）是不同的制度，具体属于哪一种，请参考[资格外活动处分指南](/zh/blog/unauthorized-activity-disposition-2026)和机关的说明。

## 2. 申报方法

依施行令第44条，将**外国人登录事项变更申报书**连同**外国人登录证和护照**提交给居住地管辖的厅长·事务所长·出张所长。机关负责人收到变更申报后整理记录表，姓名、性别、出生日期、国籍变更的，补发外国人登录证并通知居住地的市·郡·区及邑·面·洞负责人。预约方式和其他材料可能因机关而异，请在前往前确认。

## 3. 逾期会怎样？

第100条第2款第1项规定，违反第35条的人处100万韩元以下过怠金（截至2026年10月）。施行令[附表2]的基准额随逾期时间而定。

| 逾期时间 | 过怠金基准额 |
|---|---|
| 不满3个月 | 10万韩元 |
| 3个月以上不满6个月 | 30万韩元 |
| 6个月以上不满1年 | 50万韩元 |
| 1年以上 | 100万韩元 |

法务部长官可考虑年龄、环境、动机、结果和负担能力免除过怠金（第100条第5款）。过怠金由地方出入境·外国人机关的负责人征收（第100条第4款），收到后请依通知书确认提出异议的方法和期限。类似的程序可参考[出入境通告处分应对指南](/zh/blog/immigration-fine-notice-response-2026)。

## 4. 申报前的检查顺序

1. **确认变更的日期。** 15日从变更之日起算。
2. **用文件确认变更后的信息。** 可能需要新护照、转学证明或公司变更文件等。
3. **同时带上外国人登录证和护照。** 两者都要附在申报书上。
4. **向居住地管辖机关预约。** 请前往管辖居住地的机关。
5. **如果已经逾期，请立即申报。** 逾期越久基准额越高。

## 5. 行政士事务所可以协助的事项

我们可以协助填写并代为提交变更申报书、核对是否属于申报对象、翻译外文文件，以及收到过怠金通知时撰写经过说明。告发之后的侦查·刑事审判辩护不属于行政士的业务范围，我们不承接。

如果最近护照或所属机构有变化，请先数一数日期。如果已经超过15日，请现在就确认申报方法。
