以前に犯則金を納めた、出国命令を受けたことがある、という方が、ビザの更新や変更が止まるのかを知りたくて来られたのだと思います。先に答えると、**履歴があるというだけでは止まりません。**ただし金額・回数・どれだけ前のことかによって不許可になることがあり、どの資格で申請するかで線引きも変わります。

## 要点

- 犯則金の履歴は、通常**初犯で500万ウォン以上、再犯は直近3年の合算700万ウォン以上**で在留許可制限の対象になります（2026年10月時点、法務部の滞在案内マニュアル）。
- 資格によっては、**直近5年間に3回以上の違反（過料は除く）**、強制退去後7年・出国命令後5年といった期間要件が別に付きます。
- 訪問就業（H-2）は、直近3年以内に犯則金を3回受けると、金額に関係なく在留不許可のうえ出国措置と定められています。
- 「1回以下・100万ウォン以下・10年経過」は制限を解く規定ではなく、**遵法市民教育**を免除される条件です。

## まず知っておくこと：犯則金と過料は別物です

どちらも「罰金」と呼ぶ人が多いのですが、審査では扱いが違います。

**犯則金**は、出入国事件を調べて犯罪が確認されたときに、罰金に相当する金額を書面で通告するものです。通告書を受け取った日から15日以内に納める必要があり、通告どおり納めれば同じ事件で再び処罰されません。在留期間の超過や無許可の就労などが典型です。

**過料**は、届出義務を怠った、外国人登録証(외국인등록증)の発給申請をしなかったなど、比較的軽い違反に科されます。法律上の上限は200万・100万・50万ウォン以下に分かれており、出入国官署の長が賦課します。事情を考慮して免除されることもあります（2026年10月時点、第100条第1項から第4項）。

そのため「5年で3回の違反」を数えるときは過料を除き、D-10のポイント減点でも過料は合算しません。ただ、先ほどの遵法市民教育の免除条件では過料が罰金・犯則金と並んで書かれているので、その数字がどの規定のものかを確認してください。

## 在留許可制限統合基準の数字

犯則金でよく出てくる数字は二つです（2026年10月時点、法務部の滞在案内マニュアル）。

- 初犯：**500万ウォン以上**
- 再犯：直近3年以内の合算**700万ウォン以上**

求職（D-10）、永住（F-5）、特別な貢献による居住（F-2）の品行要件にも同じ数字が入っています。永住や優秀人材では「直近3年間に1回で500万ウォン以上の犯則金処分を受けたか、合算額が700万ウォン以上」と書かれています（2026年10月時点、法務部の滞在案内マニュアル）。

よくある誤解は、100万・200万ウォンの犯則金なら大丈夫と考えることです。線より低ければこの統合基準には当たりませんが、後述のとおり、ポイント減点や回数要件、教育の要件には影響します（2026年10月時点、法務部の滞在案内マニュアル）。

## 資格別にどう変わるか

| 資格・状況 | 履歴の扱われ方（2026年10月時点、法務部の滞在案内マニュアル） |
|---|---|
| 求職（D-10） | 5年以内の強制退去・出国命令、3年以内の300万ウォン以上の罰金刑、統合基準に当たる犯則金（初犯500万ウォン以上、再犯3年合算700万ウォン以上）で制限対象。ポイント制では減点もあります |
| 居住（F-2-99）変更 | 3年以内に出入国管理法違反3回以上で通告処分額の合計が500万ウォン以上なら変更が抑制されます。3年以内の300万ウォン以上の罰金刑も同様です |
| 居住（F-2）投資者 | 3年以内に犯則金を受け、在留許可を制限すべき事由があれば欠格です |
| 地域特化型優秀人材（F-2） | 3年以内の犯則金合算が500万ウォン以上、または直近3年以内に犯則金処分が3回以上なら欠格です |
| 永住（F-5） | 5年間に3回以上の違反（過料除く）、3年間の犯則金500万ウォン以上または合算700万ウォン以上、強制退去後7年・出国命令後5年が未経過、などで止まります |
| 訪問就業（H-2） | 初犯500万ウォン以上、または再犯3年合算700万ウォン以上で在留不許可・出国措置。3年以内に犯則金3回なら金額を問わず同じです |
| 在外同胞（F-4） | 犯則金の総額が700万ウォン以上の場合、合算が700万ウォンに達した時点の犯則金を完納した日から3年間、資格付与が制限されます |

表は複雑に見えますが、軸は三つだけです。**金額**（500万・700万ウォン）、**回数**（3回）、**経過期間**（3年・5年・7年）。申請する資格がどれを見るのかをまず確認しましょう。F-4は、6か月以上にわたって100時間以上のボランティア活動が確認できれば、3年の制限が1年に軽減されます。

### D-10は減点もあります

ポイント制の求職（D-10-1）では、制限事由に当たらなくても履歴で点数が引かれます。犯則金が300万ウォン以上なら30点、100万ウォン以上300万ウォン未満なら10点、50万ウォン以上100万ウォン未満なら5点の減点で、申請日から5年以内の処分金額を合算します。過料は合算しません。罰金刑の履歴は別に減点され、二つの項目は重ねて適用されます。合格ラインぎりぎりの方は、履歴で何点引かれるか計算してみてください（2026年10月時点、法務部の滞在案内マニュアル）。

### F-2-99への変更では、滞在期間の数え方にも影響します

その他の長期居住（F-2-99）に変更するには5年以上の継続滞在が必要ですが、不法残留の期間、出国命令の期間、強制退去命令を受けてから退去が完了するまでの期間は合算から除かれます。出国命令や強制退去で完全に出国した場合は、30日以内に再入国しても滞在が途切れたものとして扱われます。事実上、5年を最初から数え直すことになります。不法残留者も変更の抑制対象として挙げられています。

### 永住が最も細かいです

永住審査の品行要件には、ここまでの数字がほぼ全部入っています。罰金刑を受けたなら納付日から3年、5年間に出入国管理法違反が3回以上（過料除く）なら欠格、強制退去命令を受けて出国した日から7年、出国命令なら5年を待つ必要があります。

## 「1回以下・100万ウォン以下・10年経過」とは

この文言を「100万ウォン以下なら問題ない」と読む方がいますが、正しくは**遵法市民教育**の話です。

居住（F-2）や永住（F-5）の申請者のうち、国内法違反が確認された人は3時間の遵法市民教育を受けなければなりません。ただし次のいずれかなら、教育なしでも許可できます。

- 過去に教育を修了しており、その後の追加違反がない場合
- 違反が1回以下で、不起訴または100万ウォン以下の罰金・犯則金・過料の処分だった場合（2026年10月時点、法務部の滞在案内マニュアル）

期間の基準もあります。違反の期間は事件が終結した日（不起訴処分日、罰金納付日など）から数え、在留資格の変更は10年、在留期間の更新は5年が過ぎると教育の対象から外れます。永住は直近10年以内の違反が対象です。

この教育は、**すでに統合基準などの欠格事由に当たる人には適用されません。**欠格なら教育を受けても許可は出ないからです。初回の更新で対象になった場合は次の更新までの修了を案内され、2回目からは新たな違反が確認されると、修了しなければ更新できません。

## 履歴がある状態で申請する前にやること

1. **履歴を日付順に書き出します。**処分の種類（犯則金、過料、罰金、強制退去、出国命令）、金額、処分日、納付日、出国日を1行ずつ。審査基準の多くは申請日から3年、5年とさかのぼって数えます。
2. **申請する資格の基準に当てはめます。**同じ履歴でも、H-2と永住では結果が変わることがあります。
3. **経過期間を計算します。**合算が700万ウォンに達した時点、罰金を納めた日など、起算点が資格ごとに違います（2026年10月時点、法務部の滞在案内マニュアル）。
4. **未納がないか確認します。**罰金や追徴金が残っていると、それ自体が障害になる資格もあります。
5. **基準に当たるなら、疎明資料を準備します。**違反の経緯、再発防止、家族や仕事の事情を事実のとおりにまとめてください。事実と異なる内容は、かえって不利になります。
