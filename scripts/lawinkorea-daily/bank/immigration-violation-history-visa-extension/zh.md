你点进来，大概是因为以前交过犯则金或收到过出境命令，想知道这会不会卡住签证延期或变更。先说结论：**仅仅有记录，并不会直接被卡住。**但根据金额、次数和时间的远近，可能会被不予许可，而且不同居留资格的界线并不一样。

## 核心要点

- 犯则金记录通常以**初犯500万韩元以上，再犯最近3年合计700万韩元以上**作为居留许可限制对象（截至2026年10月，法务部滞留指南）。
- 根据资格不同，还会附加**最近5年内违法3次以上(不含行政罚款)**、强制驱逐后7年、出境命令后5年等期间要件。
- 访问就业(H-2)在最近3年内收到3次犯则金，无论金额多少，都是不予居留并要求出境。
- “1次以下、100万韩元以下、经过10年”不是解除限制的规定，而是免除**守法市民教育**的条件。

## 先弄清楚：犯则金和行政罚款不一样

很多人把两者都叫“罚款”，但在审查中处理方式不同。

**犯则金**是出入境案件调查后确认构成犯罪时，以书面形式通告相当于罚金的金额。收到通告书之日起15日内必须缴纳，按通告缴纳后，同一案件不会再受处罚。居留期限超期、未经许可就业等，都属于这一类。

**行政罚款(过怠料)**针对较轻的违法，比如漏报应申报事项、没有申请外国人登记证(외국인등록증)发放等。法律规定的上限分为200万、100万、50万韩元以下，由出入境机关负责人征收，也可以综合情况予以免除（截至2026年10月，第100条第1款至第4款）。

所以计算“5年3次违法”时不含行政罚款，D-10积分制扣分也不合计行政罚款。但前面说的守法市民教育免除条件里，行政罚款与罚金、犯则金写在一起，所以要看清楚某个数字属于哪项规定。

## 居留许可限制统一标准，先看数字

犯则金方面，最常见的是两个数字（截至2026年10月，法务部滞留指南）。

- 初犯：**500万韩元以上**
- 再犯：最近3年内合计**700万韩元以上**

求职(D-10)、永住(F-5)，以及因特殊贡献取得居留(F-2)的品行要件里，都有同样的数字。永住和优秀人才一类写的是“最近3年内一次犯则金处分达500万韩元以上，或合计达700万韩元以上”（截至2026年10月，法务部滞留指南）。

有一个常见误解：以为100万、200万韩元的犯则金没关系。金额低于界线，确实不触及这项统一标准，但如下所示，积分扣分、次数要件、教育要求仍然会受影响（截至2026年10月，法务部滞留指南）。

## 不同资格怎么适用

| 资格·情形 | 记录如何被计入（截至2026年10月，法务部滞留指南） |
|---|---|
| 求职(D-10) | 5年内被强制驱逐或出境命令、3年内被判300万韩元以上罚金、或犯则金触及统一标准(初犯500万韩元以上、再犯3年合计700万韩元以上)，即为限制对象。积分制还要扣分 |
| 居留(F-2-99)变更 | 3年内违反《出入境管理法》3次以上且通告处分金额合计500万韩元以上，则抑制变更；3年内被判300万韩元以上罚金同样如此 |
| 居留(F-2)投资者 | 3年内收到犯则金、存在应限制居留许可的事由，即为不合格 |
| 地区特色人才(F-2) | 3年内犯则金合计500万韩元以上，或最近3年内被处犯则金3次以上，即为不合格 |
| 永住(F-5) | 5年内违法3次以上(不含行政罚款)、3年内犯则金500万韩元以上或合计700万韩元以上、被强制驱逐命令出境不满7年或被出境命令出境不满5年等，均会被卡住 |
| 访问就业(H-2) | 初犯500万韩元以上，或再犯3年内合计700万韩元以上，不予居留并要求出境。3年内犯则金3次，无论金额同样处理 |
| 在外同胞(F-4) | 犯则金总额达700万韩元的，自该合计达到700万韩元时的那笔犯则金缴清之日起3年内，限制授予资格 |

表格看起来复杂，其实只有三条轴线：**金额**(500万、700万韩元)、**次数**(3次)、**经过的时间**(3年、5年、7年)。先看你要申请的资格关注哪一条。F-4如果能证明在6个月以上的时间里完成100小时以上志愿服务，3年的限制可缩短为1年。

### D-10还会扣分

采用积分制的求职(D-10-1)，即使没有触及限制，记录也会扣分。犯则金300万韩元以上扣30分，100万以上不满300万扣10分，50万以上不满100万扣5分，按申请日前5年内的处分金额合计计算，行政罚款不合计。罚金记录另行扣分，两项分数叠加适用。如果分数刚好在及格线附近，需要算一算记录会扣多少（截至2026年10月，法务部滞留指南）。

### 变更为F-2-99时，居留期间的计算也会受影响

变更为其他长期居留(F-2-99)需要连续居留5年以上，其中非法滞留期间、出境命令期间、被强制驱逐命令后到驱逐完成之间的期间，都不计入。因出境命令或强制驱逐而完全离境的，即使30日内再次入境，也视为居留中断。实际上5年要重新计算。非法滞留者本身也被列为抑制变更的对象。

### 永住最严格

永住审查的品行要件几乎包含上面所有数字。被判罚金的，要从缴纳之日起满3年；5年内违反《出入境管理法》3次以上(不含行政罚款)则不合格；被强制驱逐命令出境的，要等出境之日起7年，被出境命令的要等5年。

## “1次以下、100万韩元以下、经过10年”是什么

不少人把这句话理解为“100万韩元以下就没问题”。其实说的是**守法市民教育**。

申请居留(F-2)或永住(F-5)的人，如果确认有国内法违法记录，需要接受3小时的守法市民教育。但符合下列任一情形，不接受教育也可获得许可。

- 以前已经完成该教育，之后没有新的违法
- 违法在1次以下，且为不起诉或100万韩元以下的罚金·犯则金·行政罚款（截至2026年10月，法务部滞留指南）

还有期间限制。违法期间从案件终结之日(不起诉处分日、缴纳罚金之日等)起算，变更居留资格满10年、居留期间延期满5年，就不再属于教育对象。永住则以最近10年内的违法为对象。

这项教育**不适用于已经触及居留许可限制统一标准等不合格事由的人**。不合格的话，接受教育也得不到许可。首次延期时属于教育对象的，会被告知在下次延期前完成；从第二次起，如果又发现新的违法，必须完成教育才能延期。

## 有记录时，申请前可以做的事

1. **按日期列出记录。**每一项写明处分种类(犯则金、行政罚款、罚金、强制驱逐、出境命令)、金额、处分日、缴纳日、出境日。大部分标准都是从申请日往前倒数3年、5年。
2. **用你要申请的资格的标准去对照。**同样的记录，H-2和永住的结果可能不同。
3. **计算经过的期间。**起算点因资格而异，比如合计达到700万韩元的时点、缴纳罚金之日（截至2026年10月，法务部滞留指南）。
4. **确认有没有未缴款项。**罚金或追缴款没缴清，对某些资格来说本身就是障碍。
5. **触及标准时，准备说明材料。**如实整理违法经过、防止再犯的措施、家庭和工作情况。与事实不符的内容反而会让情况更不利。
