在韩国从事的事情变了，比如从读书变成工作，居留资格也要跟着变。最常见的错误是想着“许可很快会下来，先开始工作吧”。这篇文章按条文整理变更许可的原则，以及顺序颠倒的后果。

## 要点

- 在韩居留的外国人要从事**属于现有居留资格以外的其他资格的活动**，须**事先**取得法务部长官的变更许可（第24条第1款）。
- 免于登录的人员（第31条第1款各项）因身份变更而需要变更资格的，须自身份变更之日起30日内取得许可（第24条第2款）。
- 未经许可从事其他资格的活动，可处3年以下徒刑或3000万韩元以下罚金（第94条第16项），也属于强制驱逐事由（第46条第1款第8项）。

## 1. 什么时候需要变更许可？

第24条第1款的标准是“活动”。超出现有居留资格允许的活动范围、从事属于其他居留资格的活动，须在活动之前取得许可。例如，读书的人想要从事就业活动，就可能属于这种情形。如果只是稍微超出活动范围，另有资格外活动许可（第20条），具体适用哪一种，请参考[资格外活动处分指南](/zh/blog/unauthorized-activity-disposition-2026)和管辖机关的说明。

## 2. 申请程序

依施行令第30条，将**居留资格变更许可申请书**连同法务部令规定的材料提交给厅长·事务所长·出张所长。机关负责人附上意见转送法务部长官，获得许可后在护照上盖变更许可印或粘贴贴纸；签发或换发外国人登录证时则以此代替。审查依施行规则第31条之2所定标准进行。

## 3. 许可前就活动会怎样？

第94条第16项规定，违反第24条、未经许可从事其他居留资格活动的人，处3年以下徒刑或3000万韩元以下罚金。常以通告处分的罚款了结，施行规则[附表7]的基准额随违规期间而定。

| 违规期间 | 罚款基准额 |
|---|---|
| 不满1个月 | 50万韩元 |
| 1个月以上不满3个月 | 100万韩元 |
| 3个月以上不满6个月 | 200万韩元 |
| 6个月以上不满1年 | 500万韩元 |
| 1年以上不满2年 | 1000万韩元 |

基准额可参酌年龄、环境、动机和负担能力在二分之一范围内减轻或加重（施行规则第86条第2款）。通告书须在15日内缴纳（第105条第1款），缴纳后同一案件不会再被处罚（第106条）。这类记录可能影响之后的居留审查，也请参考[出入境处罚综合指南](/zh/blog/immigration-law-penalties-guide)。

## 4. 变更许可被拒绝时

施行令第33条第1款规定，不予变更许可时会通知申请人，并可让其以已获许可的居留资格居留。若写明出境期限，则为自签发之日起不超过14日（同条第2款）。拒绝的原因也可参考[签证拒绝应对指南](/zh/blog/visa-denial-response)。

## 5. 正确的顺序

1. **先确定新活动是什么。** 区分它属于现有资格的活动范围还是其他资格的活动。
2. **许可前不要开始新活动。** 应在获得许可之后开始，而不是提交申请的当天。
3. **备齐材料后申请。** 材料因资格而异，请确认管辖机关的说明。
4. **仔细阅读通知书。** 不予许可时会写明出境期限或是否维持原资格。
5. **如果已经开始，请停止并整理经过。** 时间越长，基准额越高。
