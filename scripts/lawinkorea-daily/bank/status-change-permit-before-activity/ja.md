就職・留学・結婚などで韓国での活動が変わったら、在留資格も変える必要があります。ところが「もうすぐ許可が出るから先に働き始めよう」という考えが最もよくある失敗です。この記事では、変更許可の原則と、順序を誤った場合の結果を条文どおりに整理しました。

## 要点

- 韓国に滞在する外国人が**現在の在留資格とは異なる資格に該当する活動**をするには、**あらかじめ**法務部長官の変更許可を受けなければなりません（第24条第1項）。
- 登録免除対象者（第31条第1項各号）が身分の変更で資格を変えるには、身分が変わった日から30日以内に許可を受ける必要があります（第24条第2項）。
- 許可なく別の資格の活動をすると、3年以下の懲役または3千万ウォン以下の罰金の対象となり（第94条第16号）、退去強制事由にも当たります（第46条第1項第8号）。

## 1. 変更許可が必要なとき

第24条第1項の基準は「活動」です。持っている在留資格で認められた活動範囲を超え、別の在留資格に該当する活動をするには、その活動の前に許可が必要です。たとえば、学業をしていた人が就労活動をしようとする場合が当たり得ます。範囲からの軽微な逸脱には、資格外活動許可（第20条）が別にあります。どちらに当たるかは[資格外活動処分ガイド](/ja/blog/unauthorized-activity-disposition-2026)と管轄官署の案内で確認してください。

## 2. 申請の手続き

施行令第30条により、**在留資格変更許可申請書**に法務部令で定める書類を添えて庁長・事務所長・出張所長に提出します。官署の長が意見を付けて法務部長官に送り、許可されると旅券に変更許可印を押すかステッカーを貼ります。外国人登録証を発行・再発行する場合は、それで代えられます。審査は施行規則第31条の2に基づく基準で行われます。

## 3. 許可前に活動するとどうなりますか？

第94条第16号は、第24条に違反して許可なく別の在留資格の活動をした人を、3年以下の懲役または3千万ウォン以下の罰金に処すると定めています。犯則金の通告処分で処理されることが多く、施行規則［別表7］の基準額は違反期間によって異なります。

| 違反期間 | 犯則金の基準額 |
|---|---|
| 1か月未満 | 50万ウォン |
| 1か月以上3か月未満 | 100万ウォン |
| 3か月以上6か月未満 | 200万ウォン |
| 6か月以上1年未満 | 500万ウォン |
| 1年以上2年未満 | 1,000万ウォン |

基準額は年齢・環境・動機・負担能力などにより2分の1の範囲で減らしたり増やしたりできます（施行規則第86条第2項）。通告書は15日以内に納め（第105条第1項）、納めた後は同じ事件で再び処罰されません（第106条）。履歴は今後の在留審査に影響し得るため、[出入国の罰則総合ガイド](/ja/blog/immigration-law-penalties-guide)もご覧ください。

## 4. 変更が不許可のとき

施行令第33条第1項は、変更許可をしないときは申請人にその旨を知らせ、この場合すでに許可された在留資格で滞在させることができると定めています。出国期限を記載する場合は発行日から14日を超えない範囲です（同条第2項）。不許可の理由は[ビザ拒否への対応ガイド](/ja/blog/visa-denial-response)でも確認できます。

## 5. 正しい順序

1. **新しい活動が何かを決めます。** 現在の資格の活動範囲か、別の資格の活動かを区別します。
2. **許可前に新しい活動を始めません。** 申請した日ではなく、許可を受けてから始めます。
3. **書類を準備して申請します。** 書類は資格ごとに異なるため、管轄官署の案内を確認してください。
4. **通知書をよく読みます。** 不許可の場合は出国期限や現在の資格の維持について記載されています。
5. **すでに始めていたら中止し、経緯を整理します。** 期間が長いほど基準額が上がります。

## 6. 行政書士事務所がお手伝いできること

在留資格変更許可申請書の作成と提出代行、資格別の書類点検、違反の経緯を説明する疎明書の作成、外国語書類の翻訳をお手伝いします。告発後の捜査・刑事裁判での弁護は行政士の業務範囲外のため、お受けしていません。

新しい活動を始める前なら、許可の順序から確認してください。すでに始めている場合は、期間を整理してからご相談ください。
