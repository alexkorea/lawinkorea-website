家族や友人、従業員を韓国に呼ぼうと招請状を書くとき、「少しくらい事実と違っても大丈夫」と考える人がいます。しかし、招請書類や査証申請書への虚偽記載は、出入国管理法が別に禁止している行為です。この記事では、第7条の2の内容と罰則、招請された外国人への影響を条文どおりに整理しました。

## 要点

- 虚偽の事実の記載や虚偽の身元保証などの不正な方法による外国人の招請・あっせん、虚偽の査証・査証発給認定書の申請・あっせんは禁止されています（第7条の2）。
- 違反すると3年以下の懲役または3千万ウォン以下の罰金の対象です（第94条第3号）。
- 犯則金の基準額は招請人数が多いほど上がります（施行規則別表7）。
- 虚偽招請で入国した外国人も退去強制の対象になり得ます（第46条第1項第2号）。

## 1. どんな行為が禁止されていますか？

第7条の2は、「何人も」外国人を入国させるために次の二つの行為をしてはならないと定めています。

- 虚偽の事実の記載や虚偽の身元保証などの**不正な方法で外国人を招請**し、またはその招請を**あっせん**する行為
- **虚偽で査証または査証発給認定書を申請**し、またはその申請を**あっせん**する行為

招請人の職業・所得・関係を水増ししたり、実在しない契約や事業を根拠に記載したりすることが当たり得ます。具体的な判断は事案によるため、断定はできません。

## 2. 罰則と犯則金の基準

第94条第3号は、第7条の2に違反した人を3年以下の懲役または3千万ウォン以下の罰金に処すると定めています。出入国事犯の事件は官署の長の告発がなければ公訴を提起できず（第101条第1項）、官署の長は犯罪の確証を得たとき、罰金に相当する犯則金を通告できます（第102条第1項）。施行規則［別表7］の基準額は次のとおりです。

| 招請人数 | 犯則金の基準額 |
|---|---|
| 1人 | 1,000万ウォン |
| 2人 | 1,200万ウォン |
| 3人 | 1,400万ウォン |
| 5人 | 1,800万ウォン |
| 10人 | 2,800万ウォン |
| 11人以上 | 3,000万ウォン |

基準額は年齢・環境・動機・結果・負担能力を考慮して2分の1の範囲で減らしたり増やしたりできます（施行規則第86条第2項）。犯情が禁錮以上の刑に当たると認められれば、通告処分なしに告発されることもあります（第102条第3項）。通告書は15日以内に納め（第105条第1項）、納めた後は同じ事件で再び処罰されません（第106条）。

## 3. 招請された外国人への影響

第46条第1項第2号は、第7条の2に違反した外国人、または同条の虚偽招請などの行為で入国した外国人を退去強制の対象と定めています。永住資格者は、法が定める例外を除き退去強制されません（第46条第2項）。自費で自主的に出国しようとする人には出国命令ができるため（第68条第1項第1号）、[外国人の自主出国ガイド](/ja/blog/foreigner-voluntary-departure-2026)と[入国禁止解除ガイド](/ja/blog/entry-ban-removal)もあわせてご覧ください。入国制限の事由や期間は事案により異なります。

## 4. 調査はどう行われますか？

出入国管理公務員は、虚偽招請などによる不法入国を防ぐために必要なとき、外国人の招請や国際結婚などをあっせん・仲介する人やその事業所を訪問して質問し、資料提出を求めることができます（第81条第2項）。正当な理由なく拒否してはならず（第81条第4項）、帳簿や資料の提出要求を拒否・忌避すると100万ウォン以下の過怠金の対象です（第100条第2項第3号）。出頭を求められたら、[事犯審査ガイド](/ja/blog/immigration-offense-review-guide)のように、まず事実関係と資料を整理してください。

## 5. 招請書類を作る前と後のチェック順序

1. **記載内容が事実か、証拠で確認します。** 職業・所得・関係・招請目的を書類で裏付けられるか見ましょう。
2. **あっせん業者の説明だけを信じません。** あっせんも禁止対象で、書類の最終責任は申請人にあります。
3. **誤りがあれば提出前に直します。** すでに提出済みなら、管轄官署に訂正方法を問い合わせてください。
4. **出頭要求書や通告書が届いたら、まず期限を確認します。** 通告書は受け取った日から15日です。
5. **招請された人の滞在計画を別に点検します。** 退去強制や入国制限は事案ごとに異なります。

## 6. 行政書士事務所がお手伝いできること

招請書類や査証発給認定書申請書の事実関係の点検、証拠の整理、経緯を説明する疎明書・意見書の作成、外国語書類の翻訳をお手伝いします。告発後の捜査・刑事裁判での弁護は行政士の業務範囲外のため、お受けしていません。

まだ提出前なら内容の点検から、すでに調査の通知を受けたなら日付の確認から始めてください。
