为亲属、朋友或员工写邀请函时，有人觉得稍微写得和事实不一样也没关系。但邀请材料和签证申请书中的虚假记载，是出入境管理法另行禁止的行为。这篇文章按条文整理第7条之2的内容、处罚以及对被邀请外国人的影响。

## 要点

- 以虚假事实记载或虚假身份保证等不正当方法邀请或介绍邀请外国人，以及虚假申请或介绍申请签证、签证发放认定书，均被禁止（第7条之2）。
- 违反者可处3年以下徒刑或3000万韩元以下罚金（第94条第3项）。
- 罚款基准额随邀请人数增加而提高（施行规则附表7）。
- 因虚假邀请入境的外国人也可能成为强制驱逐对象（第46条第1款第2项）。

## 1. 哪些行为被禁止？

第7条之2规定，“任何人”都不得为使外国人入境而实施以下两种行为。

- 以虚假事实记载或虚假身份保证等**不正当方法邀请外国人**，或**介绍**此类邀请
- **虚假申请签证或签证发放认定书**，或**介绍**此类申请

夸大邀请人的职业、收入、关系，或以并不存在的合同或业务为依据填写，都可能属于此类。具体判断因案而异，不能一概而论。

## 2. 处罚与罚款基准

第94条第3项规定，违反第7条之2的人，处3年以下徒刑或3000万韩元以下罚金。出入境犯罪案件须有机关负责人告发方可起诉（第101条第1款），负责人在确认犯罪后可通告缴纳相当于罚金的罚款（第102条第1款）。施行规则[附表7]的基准额如下。

| 邀请人数 | 罚款基准额 |
|---|---|
| 1人 | 1000万韩元 |
| 2人 | 1200万韩元 |
| 3人 | 1400万韩元 |
| 5人 | 1800万韩元 |
| 10人 | 2800万韩元 |
| 11人以上 | 3000万韩元 |

基准额可参酌年龄、环境、动机、结果和负担能力在二分之一范围内减轻或加重（施行规则第86条第2款）。情节被认定属于禁锢以上刑罚的，可不经通告处分直接告发（第102条第3款）。收到通告书须在15日内缴纳（第105条第1款），缴纳后同一案件不会再被处罚（第106条）。

## 3. 对被邀请外国人的影响

第46条第1款第2项规定，违反第7条之2的外国人，或因该条所定虚假邀请等行为入境的外国人，属于强制驱逐对象。永久居留资格者除法律规定的例外情形外不会被强制驱逐（第46条第2款）。愿意自费自愿出境的人可作出出境命令（第68条第1款第1项），请一并参考[外国人自愿出境指南](/zh/blog/foreigner-voluntary-departure-2026)和[禁止入境解除指南](/zh/blog/entry-ban-removal)。入境限制的事由和期间因案而异。

## 4. 调查如何进行？

为防止虚假邀请导致的非法入境，出入境管理公务员在必要时可访问介绍·中介外国人邀请或国际婚姻的人或其营业场所，提问并要求提交材料（第81条第2款）。无正当理由不得拒绝（第81条第4款），拒绝或回避提交账簿或材料的要求，可处100万韩元以下过怠金（第100条第2款第3项）。如被要求出席，请先像[事犯审查指南](/zh/blog/immigration-offense-review-guide)中那样整理事实和材料。

## 5. 准备邀请材料前后的检查顺序

1. **用证明材料核实所写内容是否属实。** 看职业、收入、关系和邀请目的能否用文件支持。
2. **不要只听中介的说明。** 介绍行为同样被禁止，材料的最终责任在申请人。
3. **有写错的地方，提交前先改正。** 已经提交的，请向管辖机关询问更正方法。
4. **收到出席要求书或通告书，先确认期限。** 通告书自收到之日起15日。
5. **另行检查被邀请人的居留计划。** 强制驱逐和入境限制因案而异。

## 6. 行政士事务所可以协助的事项

我们可以协助核对邀请材料和签证发放认定书申请书中的事实、整理证明材料、撰写说明经过的陈述书·意见书，以及翻译外文文件。告发之后的侦查·刑事审判辩护不属于行政士的业务范围，我们不承接。

如果还没提交，请先从内容核对开始；如果已经收到调查通知，请先从确认日期开始。
