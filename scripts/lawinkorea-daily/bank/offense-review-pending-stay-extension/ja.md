調査が続いているのに在留期間が終わりそうなとき、更新申請をしていいのか、それとも動かないほうがいいのか、一番迷いますよね。先に結論を言うと、更新は**在留期間が終わる前に**申請するという原則は、調査中だからといって変わりません。許可されるかどうかは、調査の内容と合わせて機関が判断します。

## 要点

- 調査や違反審査の最中でも、更新は満了前に申請します。事件が進行中だから期間が自動的に延びるという規定は見当たりません。
- 調査後の結果は大きく三つに分かれます。違反なしの通知、通告処分のような処分、そして出国勧告・出国命令・強制退去命令など出国に関わる措置です。
- 更新が不許可になっても出国期限が定められ、事情があれば出国期限の猶予や、出国のための在留期間更新を申請できます。
- 処分の履歴は、その後の永住や他の資格の審査で別に見られます。今回の更新と今後の計画を一緒に考える必要があります。

## 調査を受けているのに、満了日が近づいています

出入国管理公務員は、強制退去事由に当たると疑われる外国人を調査でき、必要なら出頭を求めて尋問できます。出頭要求書には、出頭の趣旨、日時、場所が書かれていなければなりません。韓国語が難しい場合、陳述は通訳を通す必要があり、内容は調書に残ります。

ところが、この調査手続きと在留期間は別々の時計です。外国人は在留資格と在留期間の範囲でのみ滞在でき、それ以上いるには期間が終わる前に更新許可を受けなければなりません。更新申請も、期間が終わる前に書類を出すことになっています。

ここでよくある誤解があります。「調査中だから結果が出るまでは大丈夫だろう」と様子を見ているうちに、満了日を過ぎてしまうケースです。調査を理由に期間が延びるという条文は見つけにくく、更新許可なく期間を過ぎればそれ自体が別の違反になります。すでに調査を受けている立場で、違反がもう一つ積み重なるわけです。

## 審査が終わるとどんな決定が出るか

調査が終わると、機関の長は遅滞なく強制退去事由に当たるかを審査して決定します。大まかには次のとおりです。

| 決定 | どんな場合か |
|---|---|
| 該当なしの通知 | 強制退去事由に当たらないと認められれば、その旨が知らされます |
| 通告処分 | 調査の結果、犯罪の確証を得たとき、罰金に相当する犯則金（범칙금）を納めるよう書面で通告します |
| 告発 | 犯罪の情状が禁錮以上の刑に当たると認めれば、直ちに告発します |
| 出国勧告 | 違反の程度が軽い場合に、自主的な出国を勧める措置です |
| 出国命令 | 自費で自主的に出国しようとする人などに対して出せる処分です |
| 強制退去命令 | 強制退去事由に当たると認められるとき出せます |

すべての事件が一本の線で流れるわけではありません。同じ違反でも、通告処分のあとに在留を許可する場合もあれば、通告処分のあと出国措置につながる場合もあります。たとえば留学生の無許可アルバイトは、初回で程度が軽ければ通告処分後に在留許可が可能とされる一方、建設業での不法就労は例外なく出国命令と案内されています。

もう一点。他の法律に違反して強制退去事由に当たる場合でも、人道的な事由などが考慮され、強制退去なしに在留許可（違反審査を含む）の決定を受けた人がいると、永住の審査基準に書かれています。つまり審査の結論が必ず出国とは限りません。

## 更新を申請するとどうなるか

更新は申請すべきですが、審査する側が調査のことを知らないと思ってはいけません。在留許可の審査の過程で、機関は必要なら申請人を呼んで質問したり資料の提出を求めたりできます。すでに得た許可も、法律違反の程度が重大と判断されれば取り消しや変更があり得ますが、その前に意見を聴くことができ、事由と日時・場所は出頭日の7日前までに通知しなければなりません。

実務では、次のように準備するのがよいです。

- 満了日の前に、まず更新申請を受け付けてもらいます。
- 違反の経緯、反省、今後の計画を事実どおりに整理した疎明書も一緒に用意します。
- 家族関係、勤務状況、納税・居住の資料など、韓国での生活基盤が分かる資料を集めておきます。

更新が許可されないと、不許可の事実が書面で通知され、その書式には発行日から14日を超えない範囲で出国期限が書かれます。ただ在留資格の変更が不許可になった場合は、すでに許可された在留資格で滞在させることもあるとされており、申請内容によって結果は変わります。

期限内の出国が難しい事情があるなら、道は二つあります。出国のための船舶等がない、病気などやむを得ない事由があれば出国期限の猶予を申請でき、許可された在留期間が終わる人がやむを得ない事由で出国できないときは、出国のための在留期間更新を申請できます。どちらも事由を疎明する資料を添えて出す必要があり、更新期間が30日を超える場合は法務部長官の承認が要ります。

## 審査中に働いてもよいか

在留期間が残っていて、在留資格が就労を認めているなら、調査を受けているという事実だけで働けなくなる条文は見当たりません。就労は、あくまで在留資格と許可された勤務先が基準です。

ただし注意点が二つあります。

一つ目は、在留期間がすでに終わっている場合、状況がまったく変わることです。許可された期間を超えた滞在なので、働くことはもちろん、いること自体が問題になります。

二つ目は、調査されている内容が無許可の勤務先変更や資格外就労なら、その活動を続けるのは同じ違反を重ねることになる点です。訪問就業（H-2）のように、資格ごとに違反の処理基準が別にある場合もあるので、自分の資格にどんな基準が付いているか、まず確認が必要です。

## 決定がその後の在留許可に与える影響

違反審査の結果は、その事件だけで終わらず、その後の審査に履歴として残ります。いくつか例を挙げます。

- **永住（F-5）**：直近3年間に出入国管理法違反で500万ウォン以上の犯則金処分を受けた、または合算が700万ウォン以上だと、品行要件で引っかかります（2026年10月時点、法務部の滞在案内マニュアル）。強制退去命令を受けて出国した日から7年、出国命令を受けて出国した日から5年が過ぎていない場合も同じです。ポイント制では、通告処分の金額に応じて減点があり、申請日から5年以内の処分が対象です。
- **資格変更の審査**：求職（D-10）などでは、申請日から5年以内に強制退去や出国命令を受けた人、犯則金の基準に当たる人が欠格事由とされています。
- **滞在期間の合算**：その他の長期滞在者が居住（F-2）に変更する審査では、出国勧告の期間や出国命令の期間は滞在期間の算定から除かれます。
- **勤務先の変更**：届出期限を過ぎた勤務先変更は、初回なら通告処分後に認められる場合がありますが、直近2年以内の違反が2回以上なら、原則として通告処分後に出国措置と案内されています。

結局、「今回の更新が通るか」と「3年後、5年後に永住や資格変更でどう見られるか」は、ひとまとまりで考える必要があります。事件の終わらせ方に選択の余地があるなら、そのとき残る履歴の重さも一緒に量ってください。

## 順番に整理すると

1. 許可された在留期間の満了日をカレンダーに書き込みます。調査の日程とは別に管理します。
2. 出頭要求書が届いたら日時・場所を確認し、通訳が必要なら依頼します。
3. 満了日の前に更新申請を受け付けてもらいます。申請後に出国すると不許可になり得るので、韓国にいる間に申請してください。
4. 疎明書と証拠資料を一緒に準備します。
5. 通告書を受け取ったら、受け取った日から15日以内に納める必要があり、納めないと告発の対象になり得ます。
6. 不許可の通知や出国措置を受けたら、書かれた出国期限をまず確認し、守るのが難しければ猶予の申請をすぐ検討します。

## 行政士ができること

サンシャイン行政士事務所(선샤인행정사사무소)では、在留期間更新などの申請書類の作成と提出代行、違反の経緯を説明する疎明書・意見書の作成、証拠資料の整理と翻訳をお手伝いします。捜査や刑事裁判での弁護・代理は行政士の業務範囲外のため、行っていません。
