调查还在进行，居留期限却快到了，最让人犯难的就是到底该申请延期，还是先不动。先说结论：延期必须在**居留期限届满前**申请，这一原则不会因为正在接受调查而改变。至于能不能获准，由机关结合调查内容一起判断。

## 核心要点

- 调查或违法审查期间，延期也要在届满前申请。没有看到因为案件正在进行就自动延长期限的规定。
- 调查之后的结果大致分三类：认定不违法的通知、通告处分之类的处分，以及劝告出境、出境命令、强制驱逐命令等与出境有关的措施。
- 即使延期被拒，也会确定出境期限；有实际困难时，可以申请延缓出境期限或申请为出境而延期。
- 处分记录会在之后的永久居留及其他资格审查中单独显示，所以要把眼前的延期和今后的计划放在一起考虑。

## 正在接受调查，居留届满日期临近

出入境管理公务员可以调查被怀疑属于强制驱逐事由的外国人，有必要时可以要求其到场并询问。出席要求书上必须写明出席的目的、日期和地点。听不懂韩语的话，陈述必须经过翻译，陈述内容会记入笔录。

但是，这个调查程序和居留期限是两个不同的时钟。外国人只能在居留资格和居留期限的范围内停留，想继续停留就要在期限届满前取得延期许可。延期申请本身也规定要在期限届满前提交材料。

这里有一个常见误区：「正在被调查，所以结果出来之前应该没事」。就这样等着，结果过了届满日。很难找到因调查而延长期限的条文，没有延期许可就超过期限，本身就是另一个违法行为。在已经被调查的处境下，又多了一个违法。

## 审查结束后会作出什么决定

调查结束后，机关负责人会及时审查是否属于强制驱逐事由并作出决定。大致如下。

| 决定 | 适用情形 |
|---|---|
| 不属于的通知 | 认定不属于强制驱逐事由时，会告知此意 |
| 通告处分 | 调查结果取得犯罪确证时，以书面通告缴纳相当于罚金的犯则金（범칙금） |
| 告发 | 认为犯罪情节属于监禁以上刑罚时，立即告发 |
| 劝告出境 | 违法程度较轻时，劝其自行出境 |
| 出境命令 | 可对愿意自费自行出境的人等作出 |
| 强制驱逐命令 | 认定属于强制驱逐事由时可以作出 |

并不是所有案件都沿着同一条线走。同样的违法，有时在通告处分之后允许继续居留，有时通告处分之后会转为出境措施。例如留学生未经许可兼职，首次被查且违法程度较轻时，可以在通告处分后给予居留许可，而建筑行业的非法就业则被指引为无一例外的出境命令。

再补充一点。因违反其他法律而属于强制驱逐事由时，永久居留的审查标准里也提到，有人出于人道主义等事由未被强制驱逐，而是获得了居留许可（包括违法审查）。所以审查的结论并不一定是出境。

## 提交延期申请后会怎样

延期要申请，但不要以为审查的一方不知道调查的事。在居留许可审查过程中，机关有必要时可以让申请人到场询问或要求提交材料。已经获得的许可，如果认定违反法律的程度严重，也可以被取消或变更，不过此前可以听取意见，事由、日期、地点须在出席日7天前通知。

实务上这样准备比较好。

- 在届满日之前先提交延期申请。
- 同时准备如实整理违法经过、反省和今后计划的说明书。
- 收集能体现在韩生活基础的材料，如家庭关系、工作情况、纳税和居住材料。

延期不获许可时，会以书面通知不许可的事实，该表格中会写明自签发之日起不超过14日的出境期限。但是资格变更不获许可时，也可能让其继续以已获准的居留资格停留，所以结果因申请内容而异。

如果在期限内难以出境，有两条路。没有可乘的船舶等或因疾病等不得已的事由，可以申请延缓出境期限；获准居留期限将届满的人因不得已的事由无法出境时，可以申请为出境而延期。两者都要附上说明事由的材料，延期超过30日需要法务部长官的批准。

## 审查期间可以工作吗

居留期限还有剩余且居留资格允许就业的话，没有看到仅因正在被调查就禁止工作的条文。工作与否始终以居留资格和获准的工作单位为准。

不过有两点要小心。

第一，居留期限已经届满的话，情况完全不同。这属于超出获准期限的停留，不仅工作，连停留本身都成问题。

第二，被调查的事项如果是未经许可变更工作单位或从事资格外就业，继续那项活动就是在延续同一个违法。访问就业（H-2）等资格还有各自的违法处理标准，所以要先看自己的资格适用哪种标准。

## 决定对之后居留许可的影响

违法审查的结果不会在这个案件里就结束，而是作为记录留在之后的审查中。举几个例子。

- **永久居留（F-5）**：最近3年内因违反出入境管理法受到500万韩元以上犯则金处分，或累计犯则金达700万韩元以上，在品行要件上会被卡住（截至2026年10月，法务部滞留指南）。受强制驱逐命令出境后未满7年、受出境命令出境后未满5年的情形也一样。积分制中，按通告处分金额扣分，对象是申请日起5年内的处分。
- **资格变更审查**：求职（D-10）等，申请日起5年内受过强制驱逐或出境命令的人、符合犯则金标准的人，被列为欠格事由。
- **居留期间合计**：其他长期居留者变更为居住（F-2）资格的审查中，劝告出境期间和出境命令期间不计入居留期间。
- **变更工作单位**：超过申报期限的工作单位变更，首次违法可在通告处分后获准，但最近2年内违法2次以上的，原则上是通告处分后出境措施。

归根结底，「这次延期能不能批」和「3年、5年后在永久居留或资格变更中怎么被看待」要作为一个整体来考虑。如果案件的结束方式还有选择余地，也要把它留下的记录的分量一并掂量。

## 按顺序整理

1. 把获准居留期限的届满日写在日历上，与调查日程分开管理。
2. 收到出席要求书时，确认日期和地点，需要翻译的话提出要求。
3. 在届满日之前提交延期申请。申请后出境可能被不许可，请在韩国停留期间申请。
4. 同时准备说明书和证明材料。
5. 收到通告书的话，须自收到之日起15日内缴纳，不缴纳可能被告发。
6. 收到不许可通知或出境措施时，先确认所写的出境期限，难以遵守的话立即考虑申请延缓。
