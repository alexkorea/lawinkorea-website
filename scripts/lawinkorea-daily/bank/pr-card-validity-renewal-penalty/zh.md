永住证（영주증）有效期已过或快到期的话，先记住这一点：永住证有效期为10年，必须在这段期限**结束之前**换发。超过期限就属于过怠费（과태료）对象，基准金额会随逾期时间变长，从10万韩元一路升到100万韩元（截至2026年10月，施行令附表2）。如果已经过期，拖得越久档位越高，建议尽快到居住地所在的出入境·外国人机关提交换发申请。

## 核心要点

- 永住证是发给持有永住资格的外国人的外国人登录证，有效期为10年。
- 要办的是**换发**，不是延长居留期限。必须在有效期结束之前，向居住地所在的出入境·外国人厅（办事处·出张所）申请。
- 逾期不换发，属于200万韩元以下过怠费对象。处罚标准表按未换发的时间分为10万、30万、50万、100万韩元（截至2026年10月，第100条第1款第4项、施行令附表2）。
- 卡片有效期过了，并不等于永住资格马上消失。资格的丧失和撤销另有事由。

## 1. 永住证的有效期是多久？

永住证自签发之日起10年有效。换发后的新卡同样适用10年。

这里很多人会搞混。持有永住资格的人，活动范围和居留期限都不受限制，所以这不像普通签证那样「居留期限到了就延期」。资格本身不变，每10年换的只是**起身份证作用的卡片**。

所以卡片过期后，人仍然可以继续在韩国生活。但放着不管，就违反了法律规定的换发义务，罚款就是这么来的。

## 2. 最晚何时、去哪里、带什么？

**时间。** 施行令规定，要在永住证有效期届满日之前提交申请书。至于到期前几天开始受理，法令没有另行规定。不少机关实行事先预约访问制度，请先在HiKorea确认可预约的日期，不要把时间卡在最后一天，尽量留出余地。

**地点。** 居住地所在的出入境·外国人厅、办事处或出张所。

**材料。** 永住证换发需要：

- 申请书：综合申请书（申报书）中勾选「登录证换发」一项。
- 护照
- 居住地证明材料：租赁合同、住宿提供确认书、公共事业费缴费收据等是常见的例子。
- 原永住证：换发时需要交回，机关会将其销毁。
- 照片1张：护照规格（35mm x 45mm），拍摄时间不超过6个月。

另外，法律规定要缴纳手续费。金额和缴纳方式，办理时机关会告知。

**代理。** 换发的申请和领取，可以本人亲自办理，也可以由法务部长官指定的人代理。谁可以代理、需要什么材料，由法务部长官另行规定，所以委托他人办理前，请先向机关确认。

再补充一点。本文讲的是「有效期届满后的更新」。如果是卡片丢失或破损需要重新办理，请看[外国人登录证携带·丢失补办一文](/zh/blog/foreigner-id-card-carry-lost-reissue)。

## 3. 逾期不换发，过怠费是多少？

出入境管理法规定，对未换发永住证的人处以200万韩元以下的过怠费（截至2026年10月，第100条第1款第4项、施行令附表2）。实际金额由施行令的处罚标准表确定，标准是**未换发的时间**。

| 超过的时间 | 过怠费基准金额 |
|---|---|
| 不满3个月 | 10万韩元 |
| 3个月以上不满6个月 | 30万韩元 |
| 6个月以上不满12个月 | 50万韩元 |
| 1年以上 | 100万韩元 |

从表中可以看出，时间越久档位越高。觉得「反正都一样」而再拖一个月，反而吃亏。

这些是基准金额，并不固定（截至2026年10月，施行令附表2）。

- 可以减轻的情形：因自然灾害或火灾造成财产重大损失，或综合考虑违法程度、动机和结果、年龄和环境、缴纳能力后认为有必要减轻的，可在基准金额二分之一范围内减轻。但已经在拖欠罚款的，不予减轻。
- 可以加重的情形：违法内容严重，或最近3年内有违反法律的事实的，可在二分之一范围内加重，但不得超过200万韩元。
- 免除：法务部长官可以综合考虑年龄、环境、违法动机和结果、缴纳能力等，免除过怠费。

过怠费由出入境·外国人机关的负责人征收。所以如果已经晚了，与其编理由，不如如实说明为什么晚了，并同时提交换发申请。

## 4. 2018年9月之前取得永住资格的人，期限不同

2018年9月21日之前就已经持有永住资格的人，手里可能是旧规定下签发的永住证。法律为这部分人另外规定了换发期限。

- 自取得永住资格之日起已满10年的人：期限为2020年9月20日。
- 当时尚未满10年的人：自取得永住资格之日起满10年之日起2年内，必须换发。

旧永住证在换发之前视为有效。机关还应向这些人寄送写明申请期限的通知书，无法确认下落时，则在官报上公告。即使没收到通知书，期限也照常走，所以如果你是在那一段时间前后取得的永住资格，请自己算一下期限。

尚未满10年的人，如果愿意也可以提前换发。这时新永住证的有效期为自签发日起10年。

## 5. 如果在用手机版登录证

以永住证形式办理的手机版外国人登录证，有效期到永住证有效期届满日为止。所以卡片过期，手机版也一起结束。

换发实体永住证，是现有手机版登录证可以被注销效力的事由之一；换发之后，也可以重新申请手机版。手机版只能发给本人使用的1台手机，申请时需要出示护照或永住证。

## 6. 现在该按什么顺序做

1. **先确认到期日。** 对照卡片上的有效期和今天的日期。如果已经过期，先算一下是否不满3个月。
2. **确认是否适用特别期限。** 如果是2018年9月之前取得的永住资格，适用第4部分的期限。
3. **准备材料。** 护照、居住地证明材料、原永住证、规格照片1张、综合申请书。
4. **在HiKorea预约访问。** 临近到期的话，选最早可约的日期。
5. **如果已经晚了，整理好原因。** 如有住院、滞留海外等情况，请准备能看出日期的材料，以便说明。与事实不符的说明反而会不利。
