旅行で韓国に来た外国人は、ホテルやゲストハウスのチェックインで旅券の提示を求められることがあります。宿泊施設を運営する方も、外国人客の情報をどう扱えばよいか気になるところです。出入国管理法第81条の3は、この義務をごく特別な場合にだけ適用するよう定めています。この記事では、誰が・いつ・何をするのかと、違反時の過怠金を条文どおりに整理しました。

## 要点

- 短期滞在資格（滞在90日以下）の外国人を**宿泊外国人**といいます（第81条の3第1項、第10条の2第1項第1号）。
- 宿泊外国人の資料提供義務は、感染症やテロの警報の発令など**法務部令で定める場合に限られます**。
- 宿泊業者は、資料を受け取ったとき（または警報の発令時）から**12時間以内**に情報通信網で提出しなければなりません（第81条の3第2項）。
- 違反すると**50万ウォン以下の過怠金**の対象です（第100条第3項第1号の2・第1号の3）。

## 1. 誰が対象ですか？

第81条の3第1項の**宿泊外国人**は、第10条の2第1項第1号の**短期滞在資格**を持つ外国人です。観光・訪問などの目的で90日以下（査証免除協定などで90日を超える場合はその期間）滞在できる資格です。長期滞在資格者は、この条項の宿泊外国人に当たりません。宿泊業者は次のいずれかに当たる人です。

- 公衆衛生管理法により**宿泊業として届け出た**人
- 観光振興法により**観光宿泊業、外国人観光都市民泊業、韓屋体験業**として登録した人

## 2. いつ資料を提供しますか？

この義務は常時のものではありません。第81条の3第1項は、感染症の危機警報やテロ警報の発令など**法務部令で定める場合に限る**としています。施行規則第69条の2第1項によれば、次の場合です。

1. 感染症の拡散により**「関心」段階以上の危機警報**が発令された場合で、保健福祉部長官や疾病管理庁長の資料要請などにより法務部長官が必要と認めて**告示**する場合
2. **「注意」段階以上のテロ警報**が発令された場合で、関係機関の資料要請などにより法務部長官が必要と認めて**告示**する場合

提供する資料は**旅券、旅行証明書、外国人入国許可書**のいずれかです（同条第2項）。現在この義務が適用されるかは、法務部の告示と宿泊施設の案内でご確認ください。

## 3. 宿泊業者はどう提出しますか？

第81条の3第2項により、宿泊業者は、宿泊外国人が提供した資料を、宿泊したとき、または警報が発令されたときから**12時間以内**に、法務部令で定める情報通信網で法務部長官に提出します。施行規則第69条の3は次のように定めています。

- 提出資料は旅券・旅行証明書・外国人入国許可書の**写し**です。
- 宿泊業者は宿泊情報通信網に**利用者登録**をし、提出のたびに電子署名関連情報を一緒に送信します。
- 火災・停電・通信網の障害などで情報通信網の利用が不可能と法務部長官が認めるか、点検の公告があるときは、**電子メール・ファクス・テキスト・電話または訪問**で提出します。

宿泊業者は、収集した資料を個人情報保護法に従って保有・管理します（第81条の3第3項）。

## 4. 違反するとどうなりますか？

第100条第3項により、次の場合に50万ウォン以下の過怠金が科されます。

- 宿泊外国人が資料を**提供しなかった場合**（第1号の2）
- 宿泊業者が資料を**提出しなかった、または虚偽で提出した場合**（第1号の3）

施行令［別表2］の基準額は、どちらも次のとおりです。

| 違反回数 | 過怠金の基準額 |
|---|---|
| 1回目 | 10万ウォン |
| 2回目 | 20万ウォン |
| 3回目 | 30万ウォン |
| 4回目 | 40万ウォン |
| 5回目以上 | 50万ウォン |

過怠金は地方出入国・外国人官署の長が賦課・徴収し（第100条第4項）、法務部長官は事情を考慮して免除できます（第100条第5項）。過怠金の通知を受けたら、似た手続きを[通告処分対応ガイド](/ja/blog/immigration-fine-notice-response-2026)でご覧いただけます。ほかの違反の金額は[出入国の罰則総合ガイド](/ja/blog/immigration-law-penalties-guide)にまとめています。

## 5. 状況別のチェック順序

**旅行者の方**

1. チェックインのとき、旅券を持っているか確認します。外国人は常に旅券などを携帯する義務もあります（第27条）。
2. その要請が特別な警報期間によるものか、宿泊施設に尋ねてみましょう。

**宿泊業者の方**

1. 法務部の告示で義務が適用される期間か確認します。
2. 宿泊情報通信網の利用者登録をしておきます。
3. 12時間の期限を記録し、通信障害時の代替提出方法を確認します。
4. 収集した資料は個人情報保護法に従って管理します。

## 6. 行政書士事務所がお手伝いできること

過怠金の通知書の事実関係の点検、意見書の作成、宿泊施設の外国人対応手順の点検、外国語の案内文の翻訳をお手伝いします。告発後の捜査・刑事裁判での弁護は行政士の業務範囲外のため、お受けしていません。

過怠金の通知を受けたら、通知書の日付と異議申立ての方法から確認してください。
