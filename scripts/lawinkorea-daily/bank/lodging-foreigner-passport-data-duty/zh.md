来韩国旅行的外国人，在酒店或民宿办理入住时，有时会被要求出示护照；经营住宿场所的人也想知道该如何处理外国客人的信息。出入境管理法第81条之3只在非常特殊的情形下才适用这项义务。这篇文章按条文整理谁、何时、要做什么，以及违反时的过怠金。

## 要点

- 持短期居留资格（居留90日以下）的外国人称为**住宿外国人**（第81条之3第1款，第10条之2第1款第1项）。
- 住宿外国人的资料提供义务**仅限于**传染病、恐怖警报发布等**法务部令规定的情形**。
- 住宿业者须自收到资料时（或警报发布时）起**12小时内**通过信息通信网提交（第81条之3第2款）。
- 违反者可处**50万韩元以下过怠金**（截至2026年10月，第100条第3款第1项之2、之3）。

## 1. 谁是适用对象？

第81条之3第1款的**住宿外国人**，是持有第10条之2第1款第1项所定**短期居留资格**的外国人，即以观光、访问等目的可居留90日以下（因免签协定等可超过90日的，为该期间）的资格。长期居留资格者不属于本条的住宿外国人。住宿业者是指下列之一的人。

- 依公共卫生管理法**申报住宿业**的人
- 依观光振兴法登记为**观光住宿业、外国人观光城市民宿业、韩屋体验业**的人

## 2. 何时须提供资料？

这并非常态义务。第81条之3第1款限定于传染病危机警报或恐怖警报发布等**法务部令规定的情形**。依施行规则第69条之2第1款，包括：

1. 因传染病扩散发布**“关注”阶段以上危机警报**，且因保健福祉部长官或疾病管理厅长要求提供资料等，法务部长官认为需要而**公告**的情形
2. 发布**“注意”阶段以上恐怖警报**，且因相关机关要求提供资料等，法务部长官认为需要而**公告**的情形

须提供的资料是**护照、旅行证明书、外国人入境许可书**之一（同条第2款）。现在是否适用该义务，请确认法务部公告和住宿场所的说明。

## 3. 住宿业者如何提交？

依第81条之3第2款，住宿业者须自住宿时或警报发布时起**12小时内**，通过法务部令规定的信息通信网，将住宿外国人提供的资料提交给法务部长官。施行规则第69条之3规定：

- 提交的资料是护照、旅行证明书或外国人入境许可书的**复印件**。
- 住宿业者须在住宿信息通信网上进行**用户登记**，每次提交时一并发送电子签名相关信息。
- 因火灾、停电、通信网故障等经法务部长官认定无法使用信息通信网，或有维护公告时，通过**电子邮件、传真、短信、电话或亲自到访**提交。

住宿业者依个人信息保护法持有并管理收集到的资料（第81条之3第3款）。

## 4. 违反会怎样？

依第100条第3款，对下列情形处50万韩元以下过怠金（截至2026年10月）。

- 住宿外国人**未提供**资料（第1项之2）
- 住宿业者**未提交或虚假提交**资料（第1项之3）

施行令[附表2]的基准额，两种情形均为（截至2026年10月）：

| 违规次数 | 过怠金基准额 |
|---|---|
| 第1次 | 10万韩元 |
| 第2次 | 20万韩元 |
| 第3次 | 30万韩元 |
| 第4次 | 40万韩元 |
| 第5次以上 | 50万韩元 |

过怠金由地方出入境·外国人机关负责人征收（第100条第4款），法务部长官可考虑情况予以免除（第100条第5款）。如果收到过怠金通知，类似程序可参考[通告处分应对指南](/zh/blog/immigration-fine-notice-response-2026)。其他违规的金额请见[出入境处罚综合指南](/zh/blog/immigration-law-penalties-guide)。

## 5. 分情形的检查顺序

**如果您是旅客**

1. 入住时确认自己带着护照。外国人还负有随身携带护照等的义务（第27条）。
2. 向住宿场所询问该要求是否因特别警报期间而提出。

**如果您是住宿业者**

1. 确认法务部公告目前是否适用该义务。
2. 预先在住宿信息通信网上完成用户登记。
3. 记录12小时的期限，并确认通信故障时的替代提交方式。
4. 依个人信息保护法管理收集到的资料。

## 6. 行政士事务所可以协助的事项

我们可以协助核对过怠金通知书中的事实、撰写意见书、检查住宿场所对外国客人的处理流程，以及翻译外语告示。告发之后的侦查·刑事审判辩护不属于行政士的业务范围，我们不承接。

如果收到过怠金通知，请先确认通知书上的日期和异议方法。
