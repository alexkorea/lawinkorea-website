F-4签证被认为几乎不限制就业，所以反而更容易出事。先说结论：即使是F-4，也不能做单纯劳务，不能去赌博场所、娱乐酒吧这类涉及风俗的场所，也不能做法务部公告另行列出的部分服务和销售职业；一旦被发现在这些地方工作，可能面临罚款、不予延期等不利后果。如果已经干过，首先要弄清楚究竟是哪一条规定的问题。

## 核心要点

- F-4除了单纯劳务、违背善良风俗的行为，以及为公共利益或国内就业秩序而需要限制的职业外，就业不受限制。
- 职业是否受限，以法务部公告的职业清单为准。保洁、保安、快递·外卖、建筑单纯工是典型例子；厨房帮工、家政、农渔业单纯工虽然听起来也是“单纯”活，却标为允许。
- 在人口减少地区的地区特化型签证试点地区，单纯劳务等限制放开，但只限于该广域自治团体范围内。
- 违反可能被依违法案件处理、被处罚款、不予延期；罚款累积后，还会在以后的F-4资格授予等环节受到限制。

## 1. 哪些工作受限？

法律对F-4基本放开各类签证的活动限制，只拦住三件事：单纯劳务行为、违背善良风俗或社会秩序的行为，以及为公共利益或国内就业秩序而认为需要限制的就业。

施行规则把“单纯劳务行为”解释为需要简单、日常体力劳动的工作，即韩国标准职业分类中单纯劳务职工的就业领域。具体职业写在法务部公告里，比较显眼的有：

- 搬家工、邮递员、快递员、跑腿·外卖代理配送员、餐厅外卖员、牛奶·报纸等定期配送员
- 建筑物清洁工、街道·公共场所清洁工、垃圾·可回收物收集员
- 公寓保安、建筑物保安·巡逻、停车管理员、检票员
- 传单发放员、抄表员、燃气检查员、擦鞋工、手洗衣物·简单熨烫工

风俗方面，公告列出赌博营业场所、在娱乐酒吧以娱乐从业人员身份工作，以及风俗营业中违背善良风俗的营业场所。第三类基于公共利益的限制，包括足部护理师、沐浴管理师、婚礼从业员、卡拉OK服务员、网吧·录像厅从业员、高尔夫球童、酒类服务从业员、摆摊及流动销售员。

公告清单里没有直接出现名称的工作很多，所以请同时对照下面法务部的对照表。

## 2. 容易混淆的职业这样区分

法务部整理了“容易混淆的主要就业限制范围”表。只摘录居住在试点地区以外的一般F-4的标注：

| 允许 | 受限 |
|---|---|
| 产品单纯分拣员、其他制造相关单纯从业员 | 建筑单纯工 |
| 家政、育儿帮工 | 搬家工 |
| 快餐准备员、厨房帮工 | 快递员、餐饮外卖员 |
| 农业·林业·渔业单纯工 | 建筑物清洁工、建筑物保安 |
| 租赁产品上门检查员 | 婚礼从业员、高尔夫球童 |
| 酒店服务员、其他住宿设施服务员 | 摆摊及流动销售员 |
| 餐饮服务员、饮料服务员 | |

餐厅的工作最容易误解。同在一家餐厅，厨房帮工和餐饮服务员标为允许，餐饮外卖员却标为受限。要看自己实际做的是哪种职业，而不是店名。

另外，即使是允许的工作，如果韩国法令要求具备一定资格，仍需具备该资格。

## 3. 限制被放开的情形

有两种。

**人口减少地区地区特化型试点地区。** 在法务部长官指定的地区特化型签证事业所在的市·郡·区设有居所，或在该居所所属的广域市·道范围内工作的F-4，不受单纯劳务和公共利益限制职业的限制。风俗相关场所在此同样不行。问题在于地区范围。在推荐地区所属广域自治团体以外的其他广域自治团体工作，属于违反F-4就业限制范围，要依违法案件处理；如果是地区特化同胞(F-4-R)，则属于违反许可条件，法务部说明可能被不予延期甚至取消居留资格。

**原来的访问就业(H-2)单位。** 从2026年2月起，访问就业与外籍同胞(F-4)两条线合并为F-4。转为F-4之后，如果想继续在H-2时申报过的单位工作，应事先申请居留资格外活动许可。不经许可直接接着干是否可以，需要另行判断，所以变更资格后仍在同一单位工作的人，请先确认是否属于许可对象。

## 4. 违反后会怎样？

下面是原文中能直接确认的不利后果。

- **违法处理。** 法务部说明写明，违反F-4就业限制范围属于违法案件处理对象。出入境违法案件调查后如有犯罪确证，机关可以书面通告缴纳相当于罚金的罚款；如果犯罪情节认为属于监禁以上刑罚，则会立即告发。走哪一条，取决于违反的程度。
- **不予延期。** 说明写明，违反法律的F-4可能被限制居留期间延期许可；F-4不就业承诺书里也有“已被告知违反时可能受到罚款处分及不予延期等处罚”的内容。
- **违反许可条件。** 地区特化同胞(F-4-R)违反许可条件，会面临取消居留资格、限制延期、违法处理等措施。法律允许因违反许可条件而取消或变更居留许可，此时法务部长官可以传唤当事人听取意见，并须在出席日7天前通知事由、日期和地点。被取消许可的人可能被下达出境命令。
- **之后的限制。** 因违反出入境管理法而被处分的罚款总额达到700万韩元以上的，从使合计达到700万韩元的那笔罚款缴清之日起3年内，属于F-4资格授予等的限制对象。如果韩国中央志愿服务中心的实绩确认书能证明在6个月以上期间累计志愿服务100小时以上，该期间减为1年。罚金总额达到700万韩元以上的，同样受3年限制（截至2026年10月，法务部滞留指南）。

雇主要承担什么责任是另一回事。雇用外国人的一般规定见[非法雇用雇主的处罚](/zh/blog/illegal-employer-penalty)。站在本人的角度，即使单位说“F-4什么都能做”，承诺书也是由本人写明不从事受限职业，所以应当按责任可能落到自己身上来处理。

一般的非法就业·居留资格外活动处理，见[居留资格外活动处理说明](/zh/blog/unauthorized-activity-disposition-2026)和[非法就业处罚说明](/zh/blog/illegal-employment-penalty)。

## 5. 已经在受限行业干过，请按这个顺序

1. **先弄清楚做的是哪个职业。** 不要写职称，要写实际业务（是否包含配送、保洁范围、保安是否包含巡逻），对照上面的表和公告清单。如果是允许的职业，也许根本没有问题。
2. **看看是否适用地区例外。** 确认居所和工作地是否在试点地区，以及是否在同一广域自治团体范围内。
3. **把工作换成允许的职业。** 一边继续受限工作一边解释，对自己不利。如果换过工作，请用劳动合同和工资明细留下从何时开始变化的记录。
4. **把工作事实整理成证明材料。** 劳动合同、工资入账记录、健康保险缴纳记录，以及能显示工作期间和形态的材料。需要说明时它们是基准。
5. **确认延期时间。** 居留期间须在届满前申请延期，即使正在接受调查，也不要错过届满日。
6. **收到通告书或出席要求书，先确认期限。** 罚款通告书须自收到之日起15日内缴纳，在此期间不缴的，机关负责人应当告发（告发前缴纳则不告发）。
7. **有H-2经历的，看是否属于居留资格外活动许可对象。**

## 6. 可以委托行政士办理哪些事项？

可以委托办理F-4居留期间延期、居留资格外活动许可等申请材料的填写与代为提交、撰写说明违规经过的陈述书·意见书，以及整理并翻译工作证明材料。调查阶段的应对和被告发后的刑事审判辩护不属于行政士的业务范围，我们不承接。
