F-4ビザは就労の制約がほとんどないと言われます。だからこそ引っかかる人が多いんです。先に結論を言うと、F-4でも単純労務、賭博営業所や遊興酒場のような風俗関連の店、そして法務部が告示で別に挙げている一部のサービス・販売職には就けません。そうした場所で働いた事実が分かると、犯則金や在留期間更新の不許可などの不利益を受ける可能性があります。すでに働いてしまったなら、まずどのルールが問題なのかを正確に切り分けることが先です。

## 要点

- F-4は、単純労務、善良な風俗に反する行為、公益や国内の就業秩序のために制限が必要な職業を除けば、就労の制限がありません。
- 職業が制限かどうかは、法務部告示の職業一覧で判断します。清掃・警備・宅配や配達・建設の単純職が代表例で、厨房補助・家事手伝い・農漁業の単純職は、同じ「単純」な仕事に聞こえても許容と表示されています。
- 人口減少地域の地域特化型ビザのモデル地域では単純労務などが緩和されますが、その広域自治体の範囲内に限られます。
- 違反すると違反事件としての処理、犯則金、更新不許可がありえて、犯則金が積み上がると後のF-4資格付与などでも制限されます。

## 1. どんな仕事が制限されますか？

法律はF-4について活動の制限を大きく緩めたうえで、三つだけを止めています。単純労務、善良な風俗や社会秩序に反する行為、そして公共の利益や国内の就業秩序を守るために制限が必要と認められる就業です。

施行規則は「単純労務行為」を、単純で日常的な肉体労働を要する業務で、韓国標準職業分類の単純労務職従事者の就業分野と定めています。具体的な職業は法務部告示に書かれていて、目立つものを挙げるとこうなります。

- 引っ越し作業員、郵便配達員、宅配員、クイック・配達代行の配達員、飲食店の配達員、牛乳・新聞などの定期配達員
- 建物清掃員、道路・公共の場所の清掃員、ごみ・リサイクル品の収集員
- マンション警備員、建物の警備・巡回、駐車管理員、検札員
- チラシ配布員、検針員、ガス点検員、靴磨き、手洗い洗濯・簡単なアイロン掛け

風俗の面では、賭博営業所、遊興酒場で遊興従事者として働くこと、風俗営業のうち善良な風俗に反する営業所での就業が挙げられています。三つ目の公益上の制限には、足のケア師、入浴管理員、結婚式従事員、カラオケ接客員、PCルーム・ビデオルームの従事員、ゴルフ場のキャディ、酒類サービス従事員、露店・移動販売員が入っています。

告示の一覧に名前が出てこない仕事も多いので、下の法務部の対照表を併せて見てください。

## 2. 紛らわしい職業はこう分かれます

法務部が「混同しやすい主な就業制限範囲」としてまとめた表から、モデル地域の外に住む一般のF-4の表示だけを写すとこうなります。

| 許容 | 制限 |
|---|---|
| 製品単純選別員、その他の製造関連の単純従事員 | 建設の単純従事員 |
| 家事手伝い、育児手伝い | 引っ越し作業員 |
| ファストフード調理準備員、厨房補助員 | 宅配員、飲食配達員 |
| 農業・林業・漁業の単純従事員 | 建物清掃員、建物警備員 |
| レンタル製品の訪問点検員 | 結婚式従事員、ゴルフ場キャディ |
| ホテルサービス員、その他の宿泊施設サービス員 | 露店・移動販売員 |
| 飲食サービス従事員、飲料サービス従事員 | |

飲食店の仕事が一番勘違いしやすいところです。同じ店でも、厨房補助員や飲食サービス従事員は許容、飲食配達員は制限と表示されています。店の名前ではなく、自分が実際にしている仕事がどの職業にあたるかを見てください。

なお、許容される仕事でも、韓国の法令が一定の資格を求める職業なら、その資格は備えなければなりません。

## 3. 制限が外れる場合もあります

二つあります。

**人口減少地域の地域特化型モデル地域。** 法務部長官が定めた地域特化型ビザ事業の対象市・郡・区に居所を置くか、その居所が属する広域市・道の中で働くF-4は、単純労務と公益上の制限職業の制限を受けません。風俗関連の店はここでも不可です。問題は地域の範囲です。推薦された地域が属する広域自治体の外、つまり別の広域自治体で働くと、F-4の就業制限範囲の違反として違反事件の処理対象となり、地域特化同胞(F-4-R)なら許可条件違反として更新不許可や在留資格の取消しまでありうると、法務部の案内にあります。

**以前の訪問就業(H-2)の職場。** 2026年2月から、訪問就業と在外同胞(F-4)の二本立てだった在留資格がF-4に統合されました。H-2で届け出た職場で、F-4に変更した後も働き続けたいなら、事前に在留資格外活動許可を受けます。許可なく続けて働いてよいかどうかは別に確認が必要なので、資格を変えたあとも同じ職場で働いているなら、まず許可の対象かどうかを確かめてください。

## 4. 違反するとどうなりますか？

原文から直接確認できる不利益は次のとおりです。

- **違反事件としての処理。** 法務部の案内は、F-4の就業制限範囲に違反すると違反事件の処理対象になると書いています。出入国事犯は、調査の結果、犯罪の確証を得たときに、罰金に相当する犯則金の納付を書面で通告できます。犯罪の情状が禁錮以上の刑にあたると認められれば、すぐに告発されます。どちらになるかは違反の程度によります。
- **更新の不許可。** 案内には、法律に違反したF-4は在留期間更新許可が制限されることがあるとあり、F-4の非就業誓約書にも、違反すると犯則金処分や更新不許可などの処罰を受けうると案内を受けた旨の文言があります。
- **許可条件違反。** 地域特化同胞(F-4-R)が許可条件に違反すると、在留資格の取消し、更新の抑制、違反事件の処理などの措置が続きます。法律は、許可条件違反を理由に在留許可を取り消したり変更したりできると定めています。このとき法務部長官は本人を呼んで意見を聴くことができ、出席日の7日前までに理由と日時・場所を知らせなければなりません。許可が取り消された人には出国命令が出ることがあります。
- **後から続く制限。** 出入国管理法違反で処分された犯則金の総額が700万ウォン以上になると、合計がそこに達した時点の犯則金を納め終えた日から3年間、F-4の資格付与などで制限対象になります。韓国中央ボランティアセンターの実績確認書で6か月以上にわたり100時間以上のボランティアが確認できれば、この期間は1年に短縮されます。罰金の総額が700万ウォン以上の場合も、同じく3年の制限です（2026年10月時点、法務部の滞在案内マニュアル）。

雇用主にどんな責任が及ぶかは別の問題です。外国人雇用の一般的な規定は[不法雇用の事業主の処罰](/ja/blog/illegal-employer-penalty)で見られます。本人の立場では、職場が「F-4なら何でもできる」と言ったとしても、誓約書では本人が制限職業に就かないと書く形なので、責任は自分に来うると考えて動くのが安全です。

不法就労や在留資格外の活動に対する一般的な処分は、[資格外活動の処分の案内](/ja/blog/unauthorized-activity-disposition-2026)と[不法就労の処罰の案内](/ja/blog/illegal-employment-penalty)にあります。

## 5. すでに制限分野で働いたなら、この順番で

1. **していた仕事がどの職業にあたるかを整理します。** 肩書きではなく実際の業務(配達を含むか、清掃の範囲、警備に巡回が入るか)を書き出し、上の表と告示の一覧に当てはめます。許容される職業だったなら、実は問題がないこともあります。
2. **地域の例外にあたるかを確認します。** 居所と勤務地がモデル地域に属していたか、同じ広域自治体の中だったかを確かめます。
3. **仕事は許容される職種に移します。** 制限職業を続けながら説明するのは不利です。転職があったなら、雇用契約書と給与の記録で、いつから変わったかを残してください。
4. **勤務の事実を証拠にまとめます。** 雇用契約書、給与の入金記録、健康保険の加入記録、勤務期間と形態が分かる資料です。説明が必要になったときの基準になります。
5. **更新の時期を確認します。** 在留期間は満了前に更新を申請しなければならないので、調査中でも満了日を逃さないでください。
6. **通告書や出頭要求書が届いたら、まず期限を確認します。** 犯則金の通告書は受け取った日から15日以内に納めなければならず、この期間に納めないと官署の長が告発する仕組みです(告発前に納めれば告発されません)。
7. **H-2の経歴があるなら、在留資格外活動許可の対象かを見ます。**

## 6. 行政士にお任せいただけること

F-4の在留期間更新や在留資格外活動許可などの申請書類の作成と提出代行、違反の経緯を説明する疎明書・意見書の作成、勤務の証拠資料の整理と翻訳をお手伝いします。調査段階の対応や、告発後の刑事裁判での弁護は行政士の業務範囲外のため、お受けしていません。

自分の仕事が制限分野かどうか迷うときは、職業名と実際の業務を整理してご相談ください。電話02-363-2251、メールhelp@lawinkorea.com、相談時間は平日09:30~17:30です。サンシャイン行政士事務所(선샤인행정사사무소)が承ります。
