在韩国长期停留的外国人，需要在入境后90天内办理外国人登录。不少人以为公司、学校或家人会帮忙办，结果错过了日期。本文整理未办外国人登录时适用的条文、罚款、与强制驱逐的关系，以及现在该做的顺序。

## 核心要点

- 打算自入境之日起停留**超过**90天的，须在入境之日起90天内，到居留地管辖的出入境·外国人机关办理外国人登录（第31条第1款）。
- 违反登录义务，可处1年以下徒刑或1000万韩元以下罚金（第95条第7项），多数情况下以罚款通告处分了结。基准额按延误时间从20万韩元到1000万韩元（截至2026年10月，施行规则附表7）。
- 违反第31条也属于强制驱逐事由（第46条第1款第12项）。
- 现在仍然需要办理登录，延误越久，基准额档位可能越高。

## 1. 外国人登录的期限是什么时候？

第31条第1款规定，外国人自入境之日起停留超过90天的，须在**入境之日起90天内**，向居留地管辖的地方出入境·外国人机关负责人办理外国人登录。外交人员等法律规定的部分人员除外，90天以内出境的短期访问也不适用。

入境后新取得居留资格（第23条），或获批居留资格变更而使停留自入境日起超过90天的，须在**获得该许可时**登录（第31条第3款、第4款）。这种情况以获批时间为准，不必等到第90天。

申请依施行令第40条第1款，需向居留地管辖机关提交外国人登录申请书、护照以及法务部令规定的材料。外国人登录证的发放·补发依施行规则第72条第10项收取手续费。法务部居留指南（2026年9月）还说明，持可就业居留资格的人在办理登录时，须申报职业和年收入。

## 2. 不登录会受到什么处罚？

第95条第7项规定，违反第31条登录义务的人，处1年以下徒刑或1000万韩元以下罚金（截至2026年10月）。这是刑罚条款，违反者即成为出入境事犯，案件按一般出入境事犯处理。

- 出入境事犯案件，没有出入境·外国人机关负责人的告发，不能提起公诉（第101条第1款）。
- 机关负责人经调查确认犯罪事实后，可以书面通告缴纳相当于罚金的金额，即罚款（第102条第1款）。
- 须自收到通告书之日起15日内缴纳（第105条第1款），按通告缴纳后，同一案件不会再被处罚（第106条）。

## 3. 罚款是多少？

基准额由施行规则[附表7]按违反登录义务的期间（超过登录期限的时间）规定（截至2026年10月）。

| 延误时间 | 罚款基准额 |
|---|---|
| 不满1个月 | 20万韩元 |
| 1个月以上不满3个月 | 50万韩元 |
| 3个月以上不满6个月 | 100万韩元 |
| 6个月以上不满1年 | 200万韩元 |
| 1年以上不满2年 | 500万韩元 |
| 2年以上 | 1000万韩元 |

这是**基准额**。可综合年龄与环境、违法动机与结果、承受能力、违法次数等，在基准额的二分之一范围内减轻或加重（施行规则第86条第2款），法务部长官也可以免除通告处分（第103条第2款）。档位由延误时间决定，所以要准确整理入境日、登录期限和实际登录日。

## 4. 会被强制驱逐吗？

第46条第1款列举了强制驱逐对象，其中第12项是"违反第31条外国人登录义务的人"。也就是说，除罚款外，还可能成为强制驱逐程序的对象。至于是否真的被驱逐，由机关综合延误时间、原因和之后的居留表现判断。具有永居资格的人，除第46条第2款规定的部分例外，不会被强制驱逐。

即使认为符合第46条第1款各项，对愿意自费自愿出境的人，也可以作出出境命令（第68条第1款第1项）。想比较选择，可以参考[外国人自愿出境指南](/zh/blog/foreigner-voluntary-departure-2026)。

## 5. 现在该做的顺序

1. **确认入境日。**通过护照上的入境章或出入境事实证明，算出准确的入境日和第90天。
2. **向居留地管辖的出入境·外国人机关预约。**需要外国人登录申请书、护照以及法务部令规定的材料。不同居留资格所需材料不同，请以机关指引为准。
3. **整理延误的原因。**入境后等待居留资格变更、材料延误、住院治疗等，如实记录并收集证明。
4. **收到出席要求书或通告书要守住期限。**罚款通告书以自收到之日起15日内缴纳为准。

## 6. 可以委托行政士办理哪些事项？

可以委托检查并填写外国人登录申请材料、代为提交，撰写说明延误经过的陈述书·意见书，整理并翻译证明材料。被告发后的侦查·刑事审判辩护不属于行政士的业务范围，我们不承接。

如果已经超过90天，先确认今天就能办理的登录手续。若已收到通告书或出席要求书，请核对日期，并一起检查剩余期限和说明材料。
